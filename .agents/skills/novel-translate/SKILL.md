# novel-translate

ทำงานด้วย **คำสั่งเดียว** (รันด้วย Node 24 ไม่ใช่ Bun — WebSocket ของ Bun ต่อ Playwright CDP ไม่ติด) — สคริปต์ทำทุกอย่างเอง (คุม Chrome → ดึงบท → DeepSeek แปล → อัปเดตคลัง → บันทึก)

## ขั้นตอน (เร็วที่สุด)

1. รันทันที ไม่ต้องสำรวจโค้ดหรือไฟล์ก่อน:
   ```bash
   cd D:/work_pame/my_novel/tools/novel-reader && node translate.ts <args>
   ```
   | ผู้ใช้พูดว่า | args |
   |---|---|
   | "แปลบทนี้" / ไม่ระบุ | (ว่าง) |
   | "แปล 5 บท" | `--n 5` |
   | "แปลต่อ" / "ต่อจากเดิม" 3 บท | `--continue --n 3` |
   | ให้ลิงก์บทมา | `--url <ลิงก์> --n <N>` |
   | มีหลายเรื่อง ต่อเรื่องที่ระบุ | `--continue --book <รหัสเรื่อง> --n <N>` |
   | ดูเรื่องทั้งหมด | `--list` |

   ถ้า N > 10 ใช้ `timeout: 600000` (ประมาณ 20–40 วิ/บท)

2. ส่ง stdout (สรุปบท + ตัวละครใหม่ + path reader.html) ให้ผู้ใช้เป็นภาษาไทยสั้นๆ แล้วจบ
   - **ห้าม** Read ไฟล์บทใน `library/*/chapters/` หรือพิมพ์เนื้อหาคำแปลออกมา — ช้า เปลือง และไม่จำเป็น ผู้ใช้อ่านเองจาก reader.html

## Error ที่เจอบ่อย

- `ต่อ Chrome ที่พอร์ต 9222 ไม่ได้` → บอกผู้ใช้ดับเบิลคลิก `tools/novel-reader/open-chrome.cmd` (หรือรันให้: `cmd //c start "" D:/work_pame/my_novel/tools/novel-reader/open-chrome.cmd`) แล้วเปิดหน้าบทไว้
- `ติด Cloudflare` → ให้ผู้ใช้กดยืนยันในหน้า Chrome แล้วสั่งใหม่
- `ดึงเนื้อหาบทไม่ได้` → เว็บใหม่/โครงหน้าเปลี่ยน: เพิ่ม adapter ใน `tools/novel-reader/sites.ts` (pattern เดียวกับ `shuba69`)

## คลังตัวละคร

`library/<bookId>/glossary.json` — key = ชื่อจีน, ช่อง `th gender role self called speech relations`
- ผู้ใช้สั่งแก้ (เช่น "ซูเหนียนเป็นผู้หญิง") → แก้ JSON ช่องนั้นตรงๆ และใส่ `"locked": true` เพื่อไม่ให้ AI เขียนทับ
- ถามว่ามีใครบ้าง → อ่าน glossary.json แล้วสรุปเป็นตาราง (อ่านไฟล์นี้ได้ ไม่ใช่เนื้อหานิยาย)

## ตรวจคุณภาพ

- ทุกครั้งที่แปลเสร็จ สคริปต์จะตรวจบทที่เพิ่งแปลเองอัตโนมัติ (ผลอยู่ท้าย stdout ใต้ "ผลตรวจ:") ส่งต่อให้ผู้ใช้ตามนั้น
- ตรวจทั้งเล่มเอง: `node translate.ts --check` (ไม่ต้องเปิด Chrome)
- แก้อัตโนมัติ: จีนปน, อังกฤษหลุด, กู/มึง (ให้ AI เลือก นาย/เธอ ตามเพศคนฟัง), บาท→หยวน, "หกสิบหมื่น"→"หกแสน"
- ห้ามแทน กู/มึง ด้วย regex แบบไม่ดูบริบทเอง — เคยทำให้ "ตระกูล" กลายเป็น "ตระฉันล"

## คลังกลาง (แฟนฟิค)

- `tools/novel-reader/canon/harry-potter.json` — ชื่อ/คาถาตามวิกิไทย + ชื่อจีนฉบับแปลจีน
- เรื่องแฟนฟิคแฮร์รี่ พอตเตอร์ใหม่: `node translate.ts --seed canon/harry-potter.json --book <id>` (เติมคลัง + แก้ชื่อในบทที่แปลแล้ว)
