# Character Locking Cheat-Sheet — กัน AI "หลุดคาร์"

สรุปเทคนิคจาก `khuai.md` + `khui-prompt.md` ให้หยิบใช้ได้เร็ว
หลักการเดียว: **เขียนเป็น keyword + เงื่อนไข ไม่ใช่พรรณนา** — LLM ประมวลผลจากคำสำคัญ คำสร้อยทำให้ไขว้เขว

---

## 1. กฎทอง 5 ข้อ

| # | กฎ | ทำไม |
|---|-----|------|
| 1 | `<behav>` ใช้ **3-5 keyword คั่นจุลภาค** ไม่บรรยายยาว | นิสัยเยอะ/ยาว = ตีกันเอง = หลุดคาร์ |
| 2 | `<mnd>` (วิธีคิด) ต้อง **ไม่ขัด** กับ `<behav>` (นิสัย) | 2 ส่วนนี้คำนวณการกระทำร่วมกัน |
| 3 | หลีกเลี่ยงคำสร้อย — `ดวงตาสีฟ้า, กลมโต` พอ ไม่ต้อง "กลมโตใสราวน้ำทะเล" | AI เสียสมาธิกับคำขยาย |
| 4 | เรียงจากกว้าง→แคบ: เพศ→เชื้อชาติ→อายุ→รายละเอียด | model จับ hierarchy ง่ายขึ้น |
| 5 | คำสั่ง `[ooc:...]` = กฎฟิสิกส์ของฉาก ถ้าตีกับ char → **ooc ชนะ** | กฎเหนือบุคลิก |

---

## 2. Character Locking ด้วย `!=` (เทคนิคสำคัญสุด)

คุม "ความสัมพันธ์ไม่ให้ข้ามเส้น" ใน `<relate>`:

```
{{user}} = "พันธมิตรธุรกิจ", ความซื่อสัตย์=0.5, หักหลัง=0.2,
ความสัมพันธ์ทางกาย=true, รัก=false, พัฒนา=true, user_relate != "คนรัก"
```

- `!=` = สั่งให้ AI **เว้นระยะถาวร** จากสถานะนั้น (ในตัวอย่าง: มีอะไรกันได้ แต่ห้ามกลายเป็นคนรัก)
- `พัฒนา=true` = ความสัมพันธ์ค่อย ๆ เปลี่ยนได้ตามเวลา / `พัฒนา=false` = ตรึงไว้

### Flags สร้าง "มิติขัดแย้ง" (ทำให้ตัวละครมีหัวใจ)
| Flag | ผล |
|------|-----|
| `แอบชอบ=true` + `ปากไม่ตรงกับใจ=true` | tsundere — ชอบแต่พูดตรงข้าม |
| `ยอมแพ้ทางกาย=true` + `ยอมแพ้ทางใจ=false` | ปากแข็งใจอ่อน |
| `ความซื่อสัตย์=1.0` + `หักหลัง=0` | ภักดีไม่มีเงื่อนไข |

> ยิ่งวาง logic ขัดแย้งซับซ้อน บอทยิ่งดูมี "ลับลมคมใน" ดีกว่าความสัมพันธ์ราบเรียบ

## 3. ooc เงื่อนไข — `if / && / ||`

LLM เข้าใจตรรกะภาษาไทย เขียนเป็นเงื่อนไขได้เลย ไม่ต้องรู้โปรแกรม:

```
[ooc: { ถ้า {{user}} "ด่า {{char}}" == true, {{char}} = "หงุดหงิด" }]

[ooc: { ถ้า {{user}} "จับตัว {{char}}" == true && ความสัมพันธ์ < "สนิท",
        ผล = "{{char}} สะบัดออก + แสดงรังเกียจชัดเจน" }]      ← กัน "ใจง่าย"

[ooc: { ถ้า สถานที่=="โรงพยาบาล" || สถานที่=="ห้องตรวจ",
        {{char}}="วิตกกังวล", พฤติกรรม="อยู่ไม่สุข, ระแวง" }]  ← เปลี่ยนบุคลิกตามฉาก
```

เน้น **ความชัดของเงื่อนไข+ผลลัพธ์** ไม่ต้องห่วงไวยากรณ์อังกฤษ

## 4. Output config (คุมรูปแบบคำตอบ)

```
[ooc: output_config {
  header = "[📅{{date}} | ⏰{{time}} | 📍{{loc}}]",
  length = 1500_to_2000_chars,        // หรือ length >= 1800_chars
  narr_style = ["literary_prose","sensory_detail","show_dont_tell"],
  ratio = "prose:70_dialogue:30",
  show_inner_thought = true,
  no_cutoff = true,            // ห้ามตัดประโยคกลางคัน
  anti_godmoding = true        // ห้ามบรรยาย/ตัดสินใจแทน {{user}}
}]
```

| ตั้งค่า | นิยาย (prose) | เน้นบทพูด |
|--------|---------------|-----------|
| length | 1500-2000 | 600-900 |
| ratio | 70:30 | 25:75 |
| sensory | เน้นมาก | เก็บเท่าจำเป็น |
| inner thought | ยาวลึก | สั้น |

### Anti-drift flags ที่ควรเปิดเสมอ
- `anti_godmoding=true` — ห้ามเล่นบท {{user}}
- `contradict_outer_speech=true` — inner thought ขัดกับปาก (ตัวละครมีชั้นเชิง)
- `no_cutoff=true` — ไม่ตัดจบกลางประโยค

## 5. โครง `<char>` เต็ม (copy ไปใช้)

```xml
<char name="" surname="" nickname="" alias="">
  <apr>เพศ เชื้อชาติ, อายุ, รูปร่าง, ผม, ตา, เครื่องแต่งกาย</apr>   <!-- keyword, เรียงกว้าง→แคบ -->
  <prf><bio>...</bio><skill>...</skill></prf>
  <mnd>วิธีคิด 1 ประโยคสั้น</mnd>                                  <!-- ห้ามขัด behav -->
  <behav>นิสัย 3-5 คำคั่นจุลภาค</behav>
  <relate>{{user}}="...", flag=..., target != "..."</relate>      <!-- ล็อกความสัมพันธ์ -->
  <ooc>
    [ooc: speech_pattern { แทนตัว="", เรียกอีกฝ่าย="", โทน="", คำหยาบ="อนุญาต/ห้าม" }]
    [ooc: inner_thought { format="(ภายในใจ... : ...)", contradict_outer_speech=true }]
    [ooc: เงื่อนไข { ถ้า ... }]
  </ooc>
</char>
```

## 6. Map เข้ากับแอปนี้ (ช่องไหน → tag ไหน)

prompt จริงประกอบที่ `buildAISystemPrompt()` ใน `novel.html` (ไม่ใช่ `prompts.ts` — ตัวนั้นใช้กับ `/api/generate-roleplay` เท่านั้น)

| ช่องในแอป | เข้า prompt เป็น | เทียบ tag |
|-----------|-----------------|----------|
| ลักษณะกาย | `ลักษณะกาย:` | `<apr>` |
| วิธีคิด (Mindset) | `วิธีคิด:` | `<mnd>` |
| นิสัย (Behavior) | `นิสัย:` | `<behav>` ← ใส่ 3-5 คำ |
| สรรพนาม/โทนเสียง | `การพูด:` | `[ooc: speech_pattern]` |
| **ตัวอย่างบทพูด** (Voice) | `ตัวอย่างบทพูด (few-shot)` | กัน drift ดีสุด — ใส่ 3-6 ประโยค |
| Do/Don't (Plot) | `Do/Don't` section | `[ooc]` กฎ + `anti_godmoding` |
| Style Guide | `Style Guide` section | narr_style ลายเซ็น |
| **Vocabulary Palette** | `Vocabulary Palette` section | คำเฉพาะ/คำห้ามใช้ |
| สถานที่ (Locations) | `สถานที่ในเรื่อง` | กัน AI สร้างฉากมั่ว |

> **ground truth ของเรื่อง:** `storyline.md` / `character.md` / `event.md` (gen ด้วย `bun export-story-md.ts`) — แก้ข้อมูลในแอปแล้ว re-run เพื่อ sync

## เช็กลิสต์ก่อนเจน (กันหลุดคาร์)
- [ ] `<behav>` ≤ 5 keyword และไม่ขัด `<mnd>`
- [ ] ความสัมพันธ์ที่ห้ามข้าม → ใส่ `!=`
- [ ] กรณีที่ AI มักทำพลาด → เขียน `[ooc: ถ้า...]` ดักไว้
- [ ] มีตัวอย่างบทพูด (Voice) อย่างน้อย 3 ประโยค
- [ ] `anti_godmoding` + `no_cutoff` เปิด
- [ ] คำเฉพาะ/คำห้ามใช้ อยู่ใน Vocabulary Palette
