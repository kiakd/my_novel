## Premise
ชายหนุ่มคนหนึ่งตื่นมาในที่แปลกประปลาด และพบว่าตนเองมีพลังวิเศษเกี่ยวกับภาพวาด
## ⚙️ กฎของโลก / World Rules & Lore (ห้ามเปลี่ยน)
ระบบ Rank พลัง: F < E < D < C < B < A < S < SS (SS คือสูงสุดในปัจจุบัน)
พลังจิต = ทรัพยากรหลักของทุกพลัง ถ้าหมดหรือฝืนเกินระดับจะเกิด "บาดเจ็บทางจิตวิญญาณ" อาจถึงตาย
อาร์ตี้ ครีเอชัน (Arty Creation): วาดภาพสิ่งมีชีวิต → มีชีวิตจริง ระยะขึ้นกับพลังจิตที่ใช้ ระดับ C ปัจจุบัน
สล็อตอัญเชิญ: กรวาดภาพฮีโร่แล้วอัญเชิญออกมาได้เป็นผู้รับใช้ที่ผูกพัน ปัจจุบันมีโฟล์เทียร์ในสล็อต
เทคโนโลยีในโลก: สมาร์ทโฮม, โฮโลแกรม HUD, บัตรดิจิทัลนำทาง, ลิฟต์ smart, อาวุธพลังงาน, AI ผู้ช่วย
สถาบันฮีโร่แห่งอัคนี: 12 ชั้น + ชั้นใต้ดิน B1-B5 สนามฝึก ห้องทดลองพลัง รับนักเรียน Rank D ขึ้นไป
นักเรียน/ตัวละครในโลกนี้: มี mutant, semi-human, และมนุษย์ธรรมดาที่มีพลัง
ระบบข่าวสารฮีโร่: เครือข่ายข่าวสาธารณะที่ติดตามกิจกรรมฮีโร่ทุกคน
Candy Mafia: แก๊งวายร้ายเดิมที่โฟล์เทียร์ปราบแล้ว 2 ปีก่อน
## 🗂️ Vocabulary Palette — คำเฉพาะ / คำห้ามใช้
ใช้คำตรงเหล่านี้ในฉาก R18 (ห้ามเลี่ยงไปคำสุภาพ/เปรียบเปรย):
• อวัยวะชาย: ควย, หัวควย, หำ, ลูกอัณฑะ
• อวัยวะหญิง: หี, จิ๋ม, รูหี, เม็ดละมุน (คลิตอริส), หัวนม, เต้านม
• การกระทำ: เย็ด, สอดใส่, กระแทก, ทิ่ม, บด, ครูด, ดูด, เลีย, อม, ถู, ขย่ม
• ของเหลว/สภาพ: น้ำเงี่ยน, น้ำหล่อลื่น, เปียกแฉะ, น้ำแตก, เสร็จ, อสุจิ
• เสียงคราง: อ๊ะ, อื้อ, ครางหวีด, ฮึก — ใช้ให้เป็นธรรมชาติ ไม่ซ้ำคำเดิมรัวๆ
คำห้ามใช้ (เลี่ยงเมื่อไหร่ = ผิดกฎ): ปลายของเขา, ลำของเขา, ของเขา, ที่นั่น, จุดนั้น, สิ่งนั้น, ของลับ, แก่นกาม, น้ำรัก(ซ้ำๆ), แดนสวรรค์
## 🎯 Do / Don't — ทิศทางเรื่อง (กฎที่ต้องปฏิบัติเสมอ)
โทนเรื่อง: สดใส ขี้เล่น light novel — ไม่จริงจัง ไม่ดาร์ก
✗ ห้าม plot twist หนัก (ศัตรู เปิดเผยความลับ ทรยศ) โดยไม่ได้สั่ง
✗ ห้ามเพิ่มตัวละครใหม่โดยไม่สั่ง
✗ ห้ามให้กรพูดจาเย็นชา จริงจัง dominant หรือออกคำสั่งแบบเจ้านาย
✗ ห้ามเปลี่ยน Rank / lore / กลไกพลังโดยไม่สั่ง
✗ ห้ามเพิ่ม drama หนักโดยไม่สั่ง
✓ กรต้องพึมพำ/แซว/มีมุขในใจทุกฉาก ทั้งปกติและ R18
✓ โฟล์เทียร์ตอบสนองแบบเขิน/แก้มแดง/กัดริมฝีปาก — ไม่เย็นชา
✓ เมียะพูดเยอะ ร่าเริง โตนพูดน้อย ณาเงียบแต่น่ารัก
✓ ฉากโลกต้องมีรายละเอียด tech ปนพลัง อย่างน้อย 1-2 จุดต่อฉาก
✓ บรรยากาศโดยรวมต้องสดใส มีอารมณ์ขัน
