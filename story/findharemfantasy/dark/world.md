# world.md — กฎโลก + กฎตรา (เส้นมืด) · วางคู่ทุก prompt

> โลก/สถานที่/พลัง = **ใช้ร่วมกับเส้นหลัก** (เต็มที่ [../02-worldbuilding.md](../02-worldbuilding.md)) · ไฟล์นี้คือเวอร์ชันย่อให้ context ครบใน 1 หน้า

## โลก เอลดรา (ย่อ)
- แฟนตาซีกึ่งยุคกลาง มีเอลฟ์/มนุษย์/เผ่าอื่น ป่าโบราณ + อาณาจักร
- **ยุคพันธนาการ:** อดีตมนุษย์ใช้ "ตราทาส" กดขี่เอลฟ์/เผ่าอื่น → เอลฟ์ **เกลียด/กลัวตราทาสที่สุด** (ปมแกนลิเอน่า)
- พลัง 3 สายของโลก: **กำลังภายใน · เวทย์มนตร์ · พลังจิต** — ตราพระเจ้าของเคนอยู่ "เหนือ/นอก" ทั้งสาม

## ⭐ ตราทาสสมบูรณ์ — พลังพระเจ้า (กลไกแกน)
เคนข้ามมิติมาพร้อม "ตรา" ของพระเจ้า ไม่ใช่เวทของโลกนี้:
1. **กาย/การกระทำเชื่อฟังเด็ดขาด** — คำสั่งเคนต่อร่างกาย/การกระทำของผู้ถูกตี ทำตามเสมอ **ไม่ว่าค่าใจติดลบแค่ไหน** (ไม่มี gate ไม่มีปฏิเสธเชิงกาย)
2. **ใจ/คำพูด/ท่าที/ความคิด = อิสระเต็มที่** — ด่า สาปแช่ง เกลียด ร้องไห้ คิดต้านได้หมด → **"กายจำยอม แต่ใจไม่ยอม"**
3. **ทำร้ายเจ้าของตรา (เคน) ไม่ได้** — แม้ค่าใจ −100 ก็ลงมือทำร้ายเคนไม่ได้ (ตราปกป้องอัตโนมัติ)
4. **พันธะดึงให้อยู่ใกล้** — ห่างเกินรัศมีจะเจ็บ/อ่อนแรงทั้งคู่ → บังคับอยู่ด้วยกัน
5. **เคนยังคุมตราไม่เชี่ยว** (เพิ่งได้) — แต่เส้นมืด: **กล้าทดลองขอบเขตมันอย่างเย็นชา**
6. **ยืมเวทผู้ถูกตีผ่านพันธะ** ได้บางส่วน (เคนไร้พลังของตัวเอง)
7. **ค่าใจ (rel −100..100)** = มาตรวัดความสัมพันธ์เท่านั้น ไม่ gate คำสั่ง · ตราสว่างเมื่อสูง/หรี่เมื่อต่ำ (สัญญาณภาพ ไม่ลดอำนาจ)

## ดราม่าเอนจิน (เส้นมืด)
> เคนถืออำนาจที่ผู้แข็งแกร่งที่สุดของโลกก็ขัดไม่ได้ — และ **เลือกใช้มันเต็มที่**
> ความมัน/ตึง = ผู้ถูกกระทำที่ทรงพลังสุดต้องยอมทางกาย แต่ต้านสุดใจ · ราคาทางใจเป็นของจริง (ต่างจากเส้นหลักที่เคน "เลือกไม่ใช้")
