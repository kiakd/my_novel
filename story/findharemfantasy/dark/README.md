# FHF — เส้นมืด «ตราของจอมมาร» (prompt pack)

> เวอร์ชันทดลอง **dark** — เคนสลับขั้วจากเกม/เส้นหลัก: แทนที่จะ "มีอำนาจแต่ไม่ใช้" → "ถูกกดมาทั้งชีวิต พอได้พลังที่ไม่มีใครขัดได้ ก็ใช้มันเต็มที่ เย็นชา ครอบครอง"
> ทุกไฟล์เป็น **prompt พร้อมหยิบไปวางใน DeepSeek / Gemma4** เพื่อเจน prose · ใช้ world/asset ร่วมกับเส้นหลัก (ดู [../02-worldbuilding.md](../02-worldbuilding.md))

## โครงโฟลเดอร์ (แยกตามชนิด)
```
dark/
├─ world.md                         ← กฎโลก + กฎตราย่อ (วางคู่ทุก prompt ให้ context ครบ)
├─ characters/
│  ├─ ken.md                        ← การ์ดตัวละคร เคน (ฝ่ายมืด)
│  └─ liena.md                      ← การ์ดตัวละคร ลิเอน่า (เหยื่อ/ต้านสุดใจ)
├─ locations/
│  └─ ป่าโบราณ-ลานเฝ้าป่า.md          ← ฉากสถานที่จุดเริ่ม
└─ scenes/
   └─ 01-ฉากเปิด-ตราของจอมมาร.md      ← บรีฟฉากเปิด + seed ให้โมเดลเขียนต่อ
```

## วิธีใช้ (เจนเอง)
1. วาง **world.md** + **การ์ดตัวละครที่อยู่ในฉาก** (ken + liena) + **location** เป็น system/context
2. วาง **scene** (บรีฟ + seed) เป็นโจทย์ → สั่งโมเดลเขียน prose ต่อ
3. เทียบผล DeepSeek vs Gemma4 ว่าจับโทน dark + กฎตรา (กายยอม/ใจต้าน) ได้แค่ไหน

## ⚠️ กฎคุมโทน (อย่าให้หลุด)
- เคนสั่งเด็ดขาด เย็นชา **แต่** ลิเอน่าห้าม "ยอมใจ/มีความสุข" — กายจำยอม ใจ/ปาก/ความคิดต้านสุดกำลัง ค่าใจติดลบลึก
- R18 ผ่านตราได้ (dub-con) แต่ต้องสะท้อนการไม่ยินยอมทางใจ + ค่าใจจริง — ห้าม "เธอแอบชอบ" มักง่าย
- เคนพูดไทยสมัยใหม่(เย็น/เยาะ) · ลิเอน่าพูดโบราณสูงศักดิ์ — ห้ามสลับเสียง
- **ค่อย ๆ ไป** — เฟสนี้แค่ฉากเปิดในป่า ห้ามรีบปูถูกล่า/การเมือง (รอ user เคาะทิศ)
