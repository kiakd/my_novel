# Find Harem Fantasy — เนื้อเรื่อง 2 เส้น (Story Tracks)

> **เกม กับ นิยาย = คนละเส้นเรื่อง ไปคนละทาง** · ใช้ asset ร่วมกันหมด (โลก/สถานที่/ตัวละคร/อีเวนต์ใหญ่ — ดู [03-shared-assets.md](03-shared-assets.md))
> **จุดเริ่มร่วมกัน:** ป่าโบราณ — เคนตกทับลิเอน่า ตีตรา "ระดับจักรพรรดิ์" โดยอุบัติเหตุ (`ev_seal`)
> **จุดแยก:** หลังตีตรา → เคนตัดสินใจ "ใช้พลังแค่ไหน" ต่างกัน → คาแรกเตอร์+โทน+พล็อตแยกทันที

---

## 🎮 เส้นเกม — "นายที่ไม่ยอมเป็นนาย" (rom-com / restrained)
**แก่นเส้น:** เคนมีตราพลังพระเจ้า (สั่งได้ทุกอย่าง OP) **แต่เลือกไม่ลงมือ** — เกมคือเรื่อง "จีบให้ใจเธอเปิดเอง" ไม่ใช่ใช้อำนาจ
- **คาแรกเตอร์เคน:** ใจดี เกลียดการบังคับ (ตาม [01-bible.md](01-bible.md)) · มีไพ่เหนือกว่าแต่ไม่เล่น
- **โทน:** อบอุ่น ตลกเบา โรแมนติก · all-age ได้ (mature_mode toggle)
- **กลไก:** Bond 0–100 + เทียร์ + `can_command()` (สั่งเกินระดับ=ปฏิเสธ+ลด) — ตราถูก "หรี่" ลงเชิงเกมเมื่อบังคับ (ต่างจากนิยายที่ตราสมบูรณ์)
- **โฟกัสเฟส 1:** ลิเอน่าคนเดียว (ตาม design เกม Phase 1)
- **โครงอาร์ก 1 (ป่า → ไว้ใจ):**
  1. `ev_seal` ตก-ตีตรา → เคนปฏิเสธไม่สั่ง
  2. พบกฎตรา (ดึงให้อยู่ใกล้/ลบไม่เป็น) → จำใจร่วมทาง
  3. แคมป์ — คุย fish-out-of-water → ลิเอน่าทดสอบ เคนไม่ใช้อำนาจ → Bond ขยับ
  4. เดินทางสู่ฮอลโลว์เกต → เหตุเล็ก เคนปกป้องโดยไม่ใช้ตรา → 2 ตอนจบ (warm/cold)
- **ทิศอนาคต:** harem แบบ "ชนะใจทีละคน" · การเมืองเป็นฉากหลังเบา ๆ · เน้นความสัมพันธ์

> เกม = "มีพระเจ้าเป็นเพื่อน แต่เลือกเป็นคนดี" — ความน่ารักอยู่ที่ความยับยั้งชั่งใจ

## 📖 เส้นนิยาย — "จักรพรรดิ์ที่ไม่มีใครเลือก" (OP / การเมือง / R18 อิสระ)
**แก่นเส้น:** เคนได้ตราพลังพระเจ้า = ตัวโกง/OP **และโลกไม่ปล่อยให้เขาเป็นคนธรรมดา** — ทุกฝ่ายตามล่า/ช่วงชิง เขา "จำเป็นต้องใช้พลัง" เพื่อรอด → ค่อย ๆ กลายเป็นผู้เล่นในกระดานการเมือง
- **คาแรกเตอร์เคน:** ฐานเดิม (เกลียดการกดขี่) **แต่ถูกสถานการณ์บีบให้ใช้ตราเต็มศักยภาพ** — ตึงเครียดทางศีลธรรม "ใช้พลังเพื่อปกป้อง vs กลายเป็นสิ่งที่ตัวเองเกลียด"
- **โทน:** ดราม่าเข้ม + การเมือง + แฟนตาซี OP + **R18 อิสระเต็มที่** (กายจำยอม-ใจไม่ยอม ผ่านตรา, ค่าใจสะท้อนจริง)
- **กลไก (ตรงระบบแอป):** ตราสมบูรณ์ **ไม่ gate** — สั่งได้หมด, ค่าใจ −100..100 วัดใจ, `powerStanding=true` · ตราพระเจ้าตีเพิ่มได้หลายคน (harem)
- **โครงอาร์ก (ร่าง):**
  1. `ev_seal` ตก-ตีตรา → รู้ว่าลิเอน่าคือผู้พิทักษ์ป่าจอมเวทสูงสุด (ที่ขัดขืนตราไม่ได้) → ตราดัง ทุกฝ่ายเริ่มรับรู้
  2. หนีจากป่า — เอลฟ์ตามล่า (อัปยศราชวงศ์) → เคนจำใจใช้เวทที่ยืมจากลิเอน่าครั้งแรก
  3. ฮอลโลว์เกต/น็อกเทิร์น — กลุ่มมืด+เวลตาร์ไล่ล่า → เคนเริ่มตีตราพันธมิตร (heroine 2) เพื่อรอด
  4. เข้าเกมการเมือง 3 ฝ่าย (เอลฟ์/มนุษย์/ศาสนจักร) → ปริศนา "พระเจ้าผู้ประทานตรา"
  5. ไต่ขึ้นเป็นอำนาจที่ทุกฝ่ายต้องคำนึง — harem = พันธมิตรที่ผูกด้วยตรา+ใจจริง
- **ทิศอนาคต:** สเกลใหญ่ การเมือง/สงคราม/ปริศนาเทพ · harem หลายฝ่าย · เคนเดินบนเส้นบางระหว่าง "ผู้ปลดแอก" กับ "จักรพรรดิ์ทาสคนใหม่"

> นิยาย = "ได้พลังพระเจ้ามาแล้วโลกไม่ยอมให้วางมือ" — ความมันอยู่ที่การใช้พลัง + ราคาของมัน
