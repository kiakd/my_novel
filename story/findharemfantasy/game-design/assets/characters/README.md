# 📁 รูปตัวละคร — แยกโฟลเดอร์ "หนึ่งคน = หนึ่งโฟลเดอร์"

วางรูปของตัวละครแต่ละคนใน **โฟลเดอร์ของตัวเอง** เพื่อไม่ให้ปนกัน
เกมจะไปหยิบรูปจากพาธ: `assets/characters/<ไอดีตัวละคร>/<ไอดี>_<สีหน้า>.png`

## ตัวละครใน Phase 1
| ตัวละคร | ไอดี | โฟลเดอร์ |
|---------|------|----------|
| ลิเอน่า (เอลฟ์) | `liena` | [liena/](liena/) ← วางรูปที่นี่ |

## เพิ่มตัวละครใหม่ในอนาคต (เช่น สาวคนที่ 2)
1. สร้างโฟลเดอร์ใหม่ตามไอดี เช่น `assets/characters/mei/`
2. ใส่รูป 6 สีหน้าโดยตั้งชื่อขึ้นต้นด้วยไอดีนั้น เช่น `mei_neutral.png`
3. คัดลอก README จากโฟลเดอร์ liena มาปรับชื่อ

## ข้อกำหนดรูป (ใช้กับทุกตัวละคร)
- ไฟล์ **PNG พื้นหลังโปร่งใส**
- ภาพครึ่งตัว/เต็มตัว · ทุกสีหน้าควรเป็น **ท่าเดียวกัน เปลี่ยนแค่หน้า** (วางทับกันได้พอดี)
- แนะนำสูงด้านยาว ~1000–1500 px (เกมจะย่อให้พอดีจอเอง)
- ชื่อไฟล์ **ตัวพิมพ์เล็กทั้งหมด** ห้ามเว้นวรรค (ใช้ขีดล่าง)
