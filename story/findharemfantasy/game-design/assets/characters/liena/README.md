# ลิเอน่า (liena) — วางรูปสีหน้าที่นี่

เกมจะหยิบรูปตามชื่อไฟล์ด้านล่าง **เป๊ะ ๆ** (ตัวพิมพ์เล็ก, .png, พื้นหลังโปร่ง)
ถ้ายังไม่มีรูป เกมจะข้ามไป (เล่นได้ปกติ แต่ไม่เห็นตัวละคร)

## ไฟล์ที่ต้องมี (6 สีหน้า)
| ชื่อไฟล์ (วางตรงนี้) | ใช้ตอนไหน |
|----------------------|-----------|
| `liena_neutral.png`   | ปกติ/นิ่ง |
| `liena_angry.png`     | โกรธ/หยิ่ง (ช่วงต้นเรื่อง) |
| `liena_surprised.png` | ตกใจ (ตอนโดนตีตรา) |
| `liena_blush.png`     | เขิน/หน้าแดง (พันธะเริ่มขึ้น) |
| `liena_sad.png`       | เศร้า/กังวล |
| `liena_smile.png`     | ยิ้ม/อ่อนลง (ตอนจบ warm) |

## หมายเหตุดีไซน์
- ผมเงิน/ทองอ่อน, หูแหลมเอลฟ์, ตาเขียวมรกต/ฟ้า · ชุดนักเดินทางเอลฟ์โทนเขียว-น้ำตาล
- **ตราทาส:** ออกแบบลายเวทเรืองแสง วางตำแหน่งคงที่ (หลังมือ/ต้นคอ/ไหล่ เลือก 1)
- รายละเอียดเต็ม: [../../../docs/phase-1-design/03-heroine-เอลฟ์.md](../../../docs/phase-1-design/03-heroine-เอลฟ์.md)
