# รูปแบบไฟล์บท (.json) — สำหรับคนเขียนบท

บทแต่ละตอนเป็นไฟล์ JSON 1 ไฟล์ใน `dialogues/` เช่น `liena_opening.json`
เกมจะโหลดตามชื่อที่ตั้งใน `GameState.current_dialogue`

> 💡 มือใหม่: คัดลอก `liena_opening.json` เป็นแม่แบบแล้วแก้เนื้อหาได้เลย
> ⚠️ JSON ห้ามมีคอมเมนต์ และต้องมี `,` คั่นถูกต้อง (ลองวางใน jsonlint.com เช็กก่อนได้)

## โครงสร้างรวม
```json
{
  "start": "ไอดีโหนดแรก",
  "nodes": {
    "ไอดีโหนด": { ... },
    "ไอดีโหนด2": { ... }
  }
}
```

## ฟิลด์ของแต่ละโหนด (node)
| ฟิลด์ | จำเป็น | ความหมาย |
|-------|--------|----------|
| `speaker` | ใช่ | ใครพูด: `"narration"` (บรรยาย), `"player"` (ตัวเอก), `"liena"` (ตัวละคร) |
| `text` | ใช่ | ข้อความ · ใส่ `{player_name}` เพื่อแทนชื่อผู้เล่นได้ |
| `emotion` | ไม่ | สีหน้าตัวละคร: `neutral` `angry` `surprised` `blush` `sad` `smile` (ใช้กับ liena) |
| `bg` | ไม่ | เปลี่ยนพื้นหลัง เช่น `"bg_field"`, `"bg_camp"` (ชื่อไฟล์ใน assets/backgrounds/) |
| `bgm` | ไม่ | เปลี่ยนเพลงพื้นหลัง เช่น `"main_theme"` (ไฟล์ใน assets/audio/bgm/) — เล่นวนลูป |
| `sfx` | ไม่ | เล่นเสียงเอฟเฟกต์ครั้งเดียว เช่น `"impact"` (ไฟล์ใน assets/audio/sfx/) |
| `bond` | ไม่ | ปรับค่าพันธะตอนเข้าโหนดนี้ เช่น `{ "liena": 5 }` |
| `next` | ใช่* | ไอดีโหนดถัดไป หรือ `"END"` เพื่อจบบท (*ใช้เมื่อ "ไม่มี" choices) |
| `choices` | ใช่* | รายการตัวเลือก (*ใช้แทน next เมื่อให้ผู้เล่นเลือก) |

## ฟิลด์ของตัวเลือก (choice)
| ฟิลด์ | จำเป็น | ความหมาย |
|-------|--------|----------|
| `text` | ใช่ | ข้อความปุ่มตัวเลือก |
| `bond` | ไม่ | ปรับพันธะเมื่อเลือกอันนี้ เช่น `{ "liena": 10 }` |
| `next` | ใช่ | ไปโหนดไหนต่อ หรือ `"END"` |

## กติกาค่าตัวเลข (อ้างอิง)
- พันธะ (Bond) = **0–100** ต่อตัวละคร · ลิเอน่าเริ่มที่ **20**
- ตอนจบ: พันธะ ≥ **40** = ตอนจบ warm, ต่ำกว่า = cold (ตั้งใน `game_state.gd`)
- รายละเอียดดีไซน์เต็ม: [../docs/phase-1-design/04-ฉากเปิดเกม.md](../docs/phase-1-design/04-ฉากเปิดเกม.md) และ [05](../docs/phase-1-design/05-ระบบเกม-phase1.md)

## ตัวอย่างสั้น
```json
{
  "start": "a",
  "nodes": {
    "a": { "bg": "bg_camp", "speaker": "liena", "emotion": "smile", "text": "สวัสดี {player_name}", "next": "b" },
    "b": { "speaker": "liena", "emotion": "blush", "text": "จะถามอะไรข้าไหม?", "choices": [
        { "text": "เธอชอบอะไร?", "bond": { "liena": 5 }, "next": "END" },
        { "text": "ไม่มีอะไร", "next": "END" }
    ]}
  }
}
```
