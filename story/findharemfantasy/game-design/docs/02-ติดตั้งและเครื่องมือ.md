# ติดตั้งและเครื่องมือ (Godot 4 + VR)

## 1. โปรแกรมที่ต้องลง
| โปรแกรม | ใช้ทำอะไร | ฟรีไหม |
|---------|-----------|--------|
| **Godot 4.x** (เวอร์ชัน .NET หรือธรรมดา) | เอนจินทำเกม | ฟรี |
| **Visual Studio Code** (มีอยู่แล้ว) | เขียนสคริปต์ | ฟรี |
| **Git** | เก็บประวัติโค้ด (สำคัญมาก กันงานหาย) | ฟรี |
| โปรแกรมวาด/แต่งภาพ (Krita, Photopea) | ทำภาพตัวละคร 2D | ฟรี |

### Godot เวอร์ชันไหน?
- ใช้ **Godot 4.3 ขึ้นไป** — รองรับ VR (OpenXR) มาในตัว
- ภาษาเขียนสคริปต์: แนะนำ **GDScript** สำหรับมือใหม่ (คล้าย Python เรียนง่าย)
  - ไม่ต้องใช้ C# ก็ได้ ยกเว้นอยากใช้จริง ๆ

## 2. ตั้งค่า VR ใน Godot 4 (ทำตอนเฟส VR เท่านั้น)
Godot 4 รองรับ VR ผ่านมาตรฐานชื่อ **OpenXR** ซึ่งทำงานกับแว่นเกือบทุกยี่ห้อ (Meta Quest, Valve Index, HTC Vive ฯลฯ)

ขั้นตอนคร่าว ๆ (รายละเอียดไว้ทำตอนเฟส 4):
1. ใน Godot เปิด **Project > Project Settings > XR > OpenXR > Enabled = On**
2. ลง addon **Godot XR Tools** จาก Asset Library (ช่วยเรื่องมือจับ, การเดิน, UI ใน VR)
3. ต้องมีแว่น VR + ซอฟต์แวร์ของแว่น (เช่น SteamVR หรือ Meta Quist Link) เปิดอยู่บนเครื่อง
4. ถ้าเล่นบน **Meta Quest แบบไร้สาย** ต้อง export เป็นแอป Android (ยากขึ้นอีกนิด ทำทีหลังได้)

### ฮาร์ดแวร์ที่ต้องมีสำหรับทดสอบ VR
- แว่น VR สักตัว (Meta Quest 2/3 เป็นตัวเลือกคุ้มสุดสำหรับมือใหม่)
- การ์ดจอที่แรงพอ (ถ้าเล่นแบบต่อสาย PC VR)
- ถ้ายังไม่มีแว่น: **ทำเฟส 1-3 บนจอปกติไปก่อนได้เลย** ไม่ต้องรีบซื้อ

## 3. ตั้งค่า Git (ทำตั้งแต่วันแรก)
ในโฟลเดอร์โปรเจกต์ ให้รัน:
```
git init
```
แล้วสร้างไฟล์ `.gitignore` สำหรับ Godot (มี template สำเร็จใน Godot docs) เพื่อไม่เก็บไฟล์ชั่วคราว

> **ทำไมสำคัญ:** ถ้าแก้เกมแล้วพัง คุณย้อนกลับได้ ไม่ต้องเริ่มใหม่

## 4. แหล่งเรียนรู้แนะนำ (มือใหม่)
- เอกสารทางการ Godot: https://docs.godotengine.org
- Godot XR (VR) docs: ค้นหา "Godot OpenXR" ในเอกสารทางการ
- ระบบ Dialogue: ลองหา addon **Dialogue Manager** (Godot Asset Library) — ทำบทพูดเกมจีบสาวได้ง่ายมาก
