## ⭐ กฎทองของโปรเจกต์ (ย่อ — ฉบับเต็มใน /CLAUDE.md)
1. **อ่าน INDEX นี้ก่อนเสมอ** เพื่อหาไฟล์ที่เกี่ยว แล้วเปิดเฉพาะไฟล์นั้น
2. **MVP มาก่อน** — Phase 1 ทำแค่ เข้าเกม→คุย→เซฟ→จบ ของเสริม (⬜) ใส่ทีหลัง
3. **Bond = 0–100** ต่อตัวละคร, เปลี่ยนผ่าน `GameState.add_bond()` เท่านั้น
4. **ข้อมูลอยู่ใน GameState ที่เดียว** ฉากแค่อ่าน/เขียน (เผื่อต่อ 3D/VR/simulation)
5. ตั้งชื่อไฟล์โค้ด/asset เป็น `ตัวพิมพ์เล็ก_มีขีดล่าง`
6. เนื้อหา intimate (tier 40+) = gate ด้วย `mature_mode`, **อยู่นอกขอบเขต Phase 1**
