# แผนงานทีละเฟส (Roadmap)

แนวคิด: **ทำให้เล่นจบได้ตั้งแต่เฟสแรก แล้วค่อยเพิ่มความอลังการ** ห้ามกระโดดไป VR ก่อน

---

## เฟส 0 — เตรียมตัว (1-2 วัน)
- [ ] ลง Godot 4.3+, VS Code, Git
- [ ] สร้างโปรเจกต์ Godot เปล่า แล้ว `git init`
- [ ] ทำหน้าจอแสดงข้อความ "Hello" ให้ขึ้นได้ (พิสูจน์ว่าทุกอย่างทำงาน)
- 🎯 **เป้า:** เปิดเกมเปล่าแล้วเห็นข้อความบนจอ

## เฟส 1 — เกมจีบสาวแบบ 2D บนจอปกติ (สำคัญสุด) ⭐
ยังไม่แตะ 3D หรือ VR เลย โฟกัสที่ "เกมสนุก"
- [ ] ระบบบทสนทนา: ตัวละครพูด, มีชื่อ, มีภาพหน้า (ใช้ addon Dialogue Manager)
- [ ] ระบบตัวเลือก: ผู้เล่นเลือกคำตอบได้ 2-3 ตัวเลือก
- [ ] ค่าความสัมพันธ์ (affection points): เลือกถูกใจเธอ คะแนนขึ้น
- [ ] ตัวละครสาว **1 คน** + บทพูดสั้น ๆ ~5 นาที + ตอนจบ 2 แบบ (ชอบ/ไม่ชอบ)
- [ ] เมนูเริ่มเกม + บันทึก/โหลดเกม
- 🎯 **เป้า:** เพื่อนเล่นจบได้ 1 รอบบนจอคอม

## เฟส 2 — ขยายเนื้อหา (จีบได้หลายคน)
- [ ] เพิ่มตัวละครเป็น 3 คน (harem) แต่ละคนนิสัยต่างกัน
- [ ] ระบบวัน/ตารางเวลา (เลือกว่าวันนี้จะไปหาใคร)
- [ ] เหตุการณ์พิเศษเมื่อความสัมพันธ์ถึงระดับหนึ่ง
- [ ] เพิ่มเพลง/เสียงประกอบ
- 🎯 **เป้า:** เกมมีความ "เล่นซ้ำได้" เลือกจีบคนละคนได้

## เฟส 3 — สร้างโลก 3D (ยังเล่นบนจอปกติ)
จุดนี้คือสะพานไปสู่ VR
- [ ] สร้างฉาก **ห้อง 3D** ง่าย ๆ (พื้น ผนัง เฟอร์นิเจอร์ ใช้ asset ฟรีได้)
- [ ] เอาภาพตัวละคร 2D มาวางเป็น **billboard** (Sprite3D ที่หันหน้าเข้ากล้องเสมอ) ในห้อง
- [ ] ย้ายระบบบทสนทนาจากเฟส 1 มาเล่นในฉาก 3D
- [ ] กล้องเดินดูรอบห้องได้ด้วยเมาส์/คีย์บอร์ด
- 🎯 **เป้า:** เดินเข้าห้องไปคุยกับเธอได้ บนจอปกติ

## เฟส 4 — เปิด VR (OpenXR) 🥽
ตอนนี้ค่อยใส่ VR ลงในฉาก 3D ที่ทำไว้แล้ว
- [ ] เปิด OpenXR ใน Project Settings + ลง Godot XR Tools
- [ ] เปลี่ยนกล้องปกติเป็น **XROrigin3D + XRCamera3D**
- [ ] ทดสอบใส่แว่นแล้วมองรอบห้อง เห็นตัวละครลอยอยู่ตรงหน้า
- [ ] ทำ UI บทสนทนาให้ลอยในอากาศแบบ VR (world-space UI)
- [ ] (ออปชัน) ใส่การจับ/ชี้ด้วยมือ controller
- 🎯 **เป้า:** ใส่แว่นแล้วรู้สึก "นั่งคุยกับเธอในห้อง"

## เฟส 5 — ขัดเกลา & ปล่อย
- [ ] อัปเกรดตัวละครเป็น **Live2D** ให้ขยับ/กระพริบตา (ถ้าต้องการ)
- [ ] ปรับ performance ให้ลื่นใน VR (VR ต้องการ 72-90 fps)
- [ ] ทำเมนู/หน้าจอให้ใช้งานได้ทั้งจอปกติและ VR
- [ ] เก็บบั๊ก + export เกม
- 🎯 **เป้า:** มีเกมที่แชร์ให้คนอื่นเล่นได้

---

## กฎเหล็กของมือใหม่
1. **เฟส 1 ต้องเสร็จก่อน** ห้ามข้ามไปทำ 3D/VR เพราะอยากเห็นของเท่ ๆ
2. ทุกเฟส **ต้องเล่นได้** ก่อนไปเฟสถัดไป
3. ติดอะไรนานเกิน 1-2 วัน ให้ลดสเกลลง อย่าฝืน
