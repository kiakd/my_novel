# โลกและเนื้อเรื่อง (World & Lore)

## โลกของเกม
- ชื่อโลก (ชั่วคราว): **เอลดรา (Eldra)** — โลกแฟนตาซีที่มีเอลฟ์ มนุษย์ และเผ่าอื่น ๆ
- ยุคสมัย: กึ่งยุคกลางแฟนตาซี มีเวทมนตร์ ป่าใหญ่ อาณาจักรเอลฟ์ในป่าโบราณ
- ความตึงเครียดในโลก: ในอดีตมี "ยุคพันธนาการ" ที่มนุษย์เคยใช้ **ตราทาส** กดขี่เผ่าอื่น → เอลฟ์จึง **เกลียดและกลัวตราทาสเป็นพิเศษ** (สำคัญต่อปมของ heroine)

## พลังตราทาส (Core Mechanic ของเนื้อเรื่อง)
ตัวเอกข้ามมิติมาพร้อม "พลัง" ที่ไม่เคยมีใครในโลกนี้มี:

### ตราทาสคืออะไร
- ตัวเอกสามารถ "ตีตรา" (เกิดเป็นสัญลักษณ์เรืองแสงบนผิวอีกฝ่าย) สร้าง **พันธะ (Bond)** ระหว่างตัวเอกกับผู้ถูกตี
- พันธะให้ผลทางเวท: รับรู้ความรู้สึกกันได้เลือน ๆ, แบ่งปันพลัง, ป้องกันอันตรายบางอย่าง

### กฎเหล็กของพลัง (= หักมุมที่ทำให้เป็นเกมจีบสาว)
1. ตราวัดด้วยค่า **พันธะ (Bond) 0–100** ต่อตัวละครหนึ่งคน
2. **"สั่งได้เป็นขั้นตามระดับพันธะ"** — คำสั่งแต่ละแบบมี "ระดับขั้นต่ำ" ที่ต้องถึงก่อนถึงจะสั่งได้
   - พันธะต่ำ: สั่งได้แค่เรื่องเล็ก ๆ ไม่เป็นภัย / สั่งเกินระดับ = เธอปฏิเสธ + พันธะลด + ตราหรี่
   - พันธะสูง: ปลดล็อกคำสั่งที่ใกล้ชิด/ส่วนตัวมากขึ้น และเธอ "เต็มใจ" ทำตาม
   - (รายละเอียดขั้นและตัวเลข ตั้งค่าได้เอง ดู [05-ระบบเกม-phase1.md](05-ระบบเกม-phase1.md))
3. ตราที่พันธะสูงพอจะเปลี่ยนจาก *ตราทาส* → *ตราพันธะ (Bond Seal)* ที่เท่าเทียมกัน ไม่ใช่เจ้ากับทาส
4. ตัวเอก **ยกเลิกตราได้** ถ้าต้องการ (ใช้ในตอนจบบางแบบเพื่อพิสูจน์ความจริงใจ)

> หัวใจ: การบังคับเกินระดับใจของเธอ "ไม่ได้ผล" (ถูกปฏิเสธ + พันธะลด)
> แต่เมื่อพันธะสูงพอ คำสั่งที่ครั้งหนึ่งทำไม่ได้ จะกลายเป็นสิ่งที่เธอเต็มใจ → ตัวเอกจึงต้อง "จีบ" ให้ถึงระดับนั้นเอง
> ค่าพันธะ (Bond) = ทั้งความสัมพันธ์ และความสว่าง/อำนาจของตรา

## เส้นเรื่องเปิด (Opening Premise)
1. ตัวเอกอยู่โลกเดิม → จู่ ๆ มี **ประตูมิติ** เปิดขึ้น (ขนาดราว **2 เมตร**) ดูดตัวเข้าไป
2. ตัวเอก **ตกลงมาจากท้องฟ้า** ในโลกเอลดรา
3. บังเอิญ **ตกทับเอลฟ์สาว** ที่อยู่ด้านล่างพอดี
4. ตอนกระแทกกัน พลังของตัวเอก (ที่เพิ่งตื่นจากการข้ามมิติ) **ทำงานเองโดยไม่ตั้งใจ** → เกิด **ตราทาส** บนตัวเอลฟ์สาว
5. ทั้งคู่ตกใจ: เธอมีตราทาสที่เผ่าเอลฟ์รังเกียจที่สุด ส่วนเขาก็ไม่รู้ว่าตัวเองทำอะไรลงไป
6. → จุดเริ่มของความสัมพันธ์ที่ "เริ่มจากอุบัติเหตุ" และต้องค่อย ๆ คลี่คลาย

## ปมที่ใช้ขับเนื้อเรื่อง Phase 1
- เอลฟ์สาวอยากให้ลบตรา แต่ตัวเอก **ลบไม่เป็น** (ยังคุมพลังไม่ได้)
- ตรา "ดึง" ให้สองคนอยู่ใกล้กัน (ห่างไกลเกินไปจะเจ็บ/อ่อนแรง) → บังคับให้ต้องเดินทางด้วยกัน
- เป้าหมายร่วม: หาวิธีเข้าใจ/ควบคุมตรา → ระหว่างทางความสัมพันธ์ก่อตัว

## หมายเหตุโทนเนื้อหา
- คงโทน **โรแมนติก-คอเมดี้** ตราเป็นกลไกผูกพันเชิงแฟนตาซี ไม่เน้นแง่กดขี่/รุนแรง
- ให้ heroine มีอำนาจต่อรองและความเป็นตัวของตัวเองเสมอ (เธอไม่ใช่ของที่ถูกครอบครอง) — ทั้งสนุกกว่าและน่าลุ้นกว่า
