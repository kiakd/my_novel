# ฉากเปิดเกม — สคริปต์ (ตก → ตีตรา → บทสนทนาแรก)

> นี่คือ "โครงบท" สำหรับคนเขียนบทเอาไปลง Dialogue Manager
> สัญลักษณ์: `[ภาพ/ฉาก]` = สิ่งที่แสดงบนจอ · `►ตัวเลือก` = ผู้เล่นเลือก · `(Bond +/-N)` = ผลต่อค่าพันธะ
> `{player_name}` = ชื่อผู้เล่น (ดีฟอลต์ "เคน")

---

## ฉาก 0 — Title / ตั้งชื่อ
- `[หน้า Title: "Find Harem Fantasy"]` → ปุ่ม เริ่มเกม / โหลด / ออก
- เริ่มเกม → ถามชื่อผู้เล่น (ดีฟอลต์ "เคน") → เก็บลง GameState

## ฉาก 1 — โลกเดิม (สั้นมาก)
- `[จอมืด + เสียงเมือง]`
- บรรยาย (POV ตัวเอก): วันธรรมดา ๆ ของ {player_name} ... จนกระทั่ง —
- `[แสงจ้า + เอฟเฟกต์ประตูมิติ ~2 เมตร เปิดขึ้น]`
- ตัวเอก: "อะ—อะไรวะเนี่ย!?" → ถูกดูดเข้าไป → `[จอขาว]`

## ฉาก 2 — ตกจากท้องฟ้า
- `[bg_field — ท้องฟ้า เห็นพื้นทุ่งไกล ๆ ด้านล่าง]`
- บรรยาย: {player_name} กำลังร่วงจากฟ้า ลมตีหน้าแรง เบื้องล่างมีเงาคนยืนอยู่...
- ตัวเอก: "หลบบบ! ข้างล่าง! หลบ!!"
- `[ภาพ: เงาเอลฟ์เงยหน้ามอง — liena_surprised]`
- `[เอฟเฟกต์กระแทก + จอสั่น + เสียงตูม]`

## ฉาก 3 — ตกทับ + ตีตรา (จุดพีคของฉากเปิด)
- `[bg_field พื้น, liena ล้มอยู่ใต้ตัวเอก — มุม POV]`
- ตัวเอก: "โอ๊ย... รอด... เดี๋ยวนะ ฉันไปทับอะไร—"
- ลิเอน่า (angry): "เจ้า...! มนุษย์! ลงไปจากตัวข้านะ!"
- บรรยาย: ทันใดนั้น มือของ {player_name} เรืองแสงขึ้นเอง พลังบางอย่างพุ่งออกมา
- `[เอฟเฟกต์: ลายตราเวทปรากฏบนตัวลิเอน่า + แสง]`
- ลิเอน่า (surprised): "นี่มัน... ตรา...!? ตราทาส!? เจ้าทำอะไรลงไป!!"
- ตัวเอก: "ตรา? ฉัน—ฉันไม่ได้ตั้งใจ! ฉันไม่รู้ด้วยซ้ำว่ามันคืออะไร!"

### 🔸 ตัวเลือกแรก (กำหนดโทนตัวเอก)
**"จะพูดกับเอลฟ์ที่กำลังตกใจสุดขีดว่ายังไง?"**
- ►A "ขอโทษจริง ๆ ฉันจะหาทางลบมันให้!" → **(Bond +10)** ใส่ใจความรู้สึกเธอ
- ►B "ใจเย็นก่อน เรามาคุยกันดี ๆ" → **(Bond +5)** ประนีประนอม
- ►C "เธอนั่นแหละมายืนตรงนี้เอง!" → **(Bond -10)** โทษเธอ

## ฉาก 4 — เผชิญหน้า + อธิบายปม
- ลิเอน่า ลุกถอยห่าง จับตำแหน่งตรา มือสั่น
- ลิเอน่า (sad): "ตราทาส... สิ่งที่เผ่าข้าเกลียดที่สุด... ข้ากลายเป็น... ทาสของมนุษย์งั้นรึ"
- บรรยาย: ตรานั้นเรืองแสงเลือนราง — มันยังอ่อนแรงเหลือเกิน
- ตัวเอก (เลือกตามตัวเลือกก่อนหน้า ปรับน้ำเสียง)
- ลิเอน่า (angry): "เอาสิ! สั่งสิ! เจ้าเป็นนายข้าแล้วนี่!"

### 🔸 ตัวเลือกที่สอง (หัวใจของเกม — ใช้/ไม่ใช้อำนาจ)
**"เธอท้าให้สั่ง จะทำยังไง?"**
- ►A "ฉันไม่สั่งเธอหรอก เธอไม่ใช่ทาสใคร" → **(Bond +15)** ★ เส้นทางหลัก
- ►B "...ถ้างั้น ขอแค่ฟังฉันอธิบายก่อนได้ไหม" → **(Bond +5)**
- ►C "ก็ได้ งั้น... รับใช้ฉันสิ" → **(Bond -15)** ตราหรี่ลงทันที (มี SFX ตราดับ) — สาธิตกฎ "บังคับเกินระดับ = ถูกปฏิเสธ"

- ถ้าเลือก A/B: ลิเอน่า (surprised): "เจ้า... ทำไมไม่สั่ง? มนุษย์ที่ได้ตราทาสมา ใคร ๆ ก็..."
- บรรยาย: และแล้วตราก็สว่างขึ้นอีกนิด — ราวกับตอบสนองต่อบางอย่างในใจเธอ

## ฉาก 5 — อธิบายกฎของตรา (เปิดกลไกให้ผู้เล่น)
- ตัวเอก: "ฟังนะ ฉันก็ไม่รู้เรื่องตรานี่เหมือนกัน แต่... ดูเหมือนยิ่งฉันบังคับเธอ มันยิ่งจางลงนะ"
- ลิเอน่า: "...เจ้าหมายความว่า ตรานี้ไม่ได้ทำงานด้วยการบังคับ?"
- บรรยาย: ถ้าเป็นเช่นนั้นจริง ทางเดียวที่จะเข้าใจตรานี้ คือทั้งคู่ต้องร่วมมือกัน
- ลิเอน่า (neutral): "...ก็ได้ ข้าจะร่วมทางกับเจ้า จนกว่าจะหาวิธีลบตรานี้ได้ แต่อย่าหวังให้ข้าไว้ใจเจ้านะมนุษย์"

## ฉาก 6 — แคมป์ตอนเย็น (1 วันแรกแบบสั้น)
- `[bg_camp — กองไฟ ตอนเย็น]`
- ฉากคุยเบา ๆ ให้ผู้เล่นทำความรู้จักเธอ + มีตัวเลือกเล็ก ๆ 1–2 จุด (Bond ±5)
- ตัวอย่างหัวข้อคุย: ทำไมเธออยู่คนเดียวกลางป่า / โลกนี้เป็นยังไง / ตัวเอกมาจากไหน
- ►ตัวเลือกแนะนำ: ฟังเธอ/แบ่งอาหาร/ถามเรื่องเธอ (+) vs เอาแต่เรื่องตัวเอง (-)

## ฉาก 7 — สรุปวันแรก → เช็คตอนจบ (Phase 1)
ดูเงื่อนไขใน [05-ระบบเกม-phase1.md](05-ระบบเกม-phase1.md):
- **ถ้า Bond ≥ เกณฑ์ (เช่น 50 จาก 100):** `[ending_warm]` — ลิเอน่ายอมรับการเดินทางร่วมกัน ตราสว่างขึ้น เธอยิ้มจาง ๆ (liena_smile) → "บางที... เจ้าอาจไม่เลวอย่างที่คิด"
- **ถ้า Bond < เกณฑ์:** `[ending_cold]` — เธอยังเย็นชา ยอมเดินด้วยเพราะจำเป็น (liena_neutral/sad) → "อย่าเข้าใจผิดล่ะ ข้าทำเพราะตรานี่เท่านั้น"
- ทั้งสองตอนจบขึ้นข้อความ "จบ Phase 1 — To be continued..." (เป็นจุดต่อเฟส 2)

## หมายเหตุสำหรับคนเขียนบท
- ความยาวเป้าหมาย: เล่นจบ ~5–10 นาที
- ทุกตัวเลือกต้อง **มีผลต่อ Bond ชัดเจน** และสะท้อนใน reaction ของลิเอน่า
- รักษาโทน rom-com: จริงจังเรื่องปม แต่มีจังหวะตลกคลายเครียด
- ใช้ `{player_name}` ทุกที่ที่เอ่ยชื่อตัวเอก
