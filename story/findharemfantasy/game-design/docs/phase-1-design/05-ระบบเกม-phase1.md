# ระบบเกม Phase 1 (สำหรับคนเขียนโค้ด)

ขอบเขต: ทำให้ฉากเปิด ([04-ฉากเปิดเกม.md](04-ฉากเปิดเกม.md)) เล่นจบได้ พร้อมค่าพันธะและตอนจบ 2 แบบ

## 1. ค่าพันธะ (Bond) — ตัวแปรหลัก  [สเกล 0–100]
- เก็บใน Autoload `GameState` ต่อตัวละคร เช่น `bond["liena"] = 20`
- **ช่วงค่า: 0–100** (clamp ไม่ให้หลุดกรอบ)
- ค่าเริ่มต้นของลิเอน่า = **20** (ตราเพิ่งติดจากอุบัติเหตุ มีพันธะพื้นฐานบาง ๆ)
- เปลี่ยนค่าเมื่อผู้เล่นเลือกตัวเลือก (ดูค่ากำกับในไฟล์ 04 — ตอนนี้ใช้สเกล ±5/±10/±15)
- (ออปชัน) แสดงตราบนจอให้ "สว่างตาม Bond" — ทำทีหลังได้

### เกณฑ์ตอนจบ
```
ถ้า bond["liena"] >= 40   -> ending_warm  (เธอเริ่มไว้ใจ)
มิฉะนั้น                   -> ending_cold  (เธอยังเย็นชา)
```
> เส้นทางที่เลือก "ดี" ตลอด: 20 +10 +15 +5 = 50 → warm · เลือกแย่: ตก่ำกว่า 40 → cold
> ปรับเลข 40 ได้หลังเทสต์จริง

## 1.5 ระบบคำสั่ง (Command / Permission) — "สั่งได้เป็นขั้น"
หัวใจของพลังตราทาส: คำสั่งแต่ละแบบมี **"ระดับพันธะขั้นต่ำ"** ที่ต้องถึงก่อนถึงจะสำเร็จ
- **ตั้งค่าตัวเลขเองได้ทั้งหมด** (เก็บเป็น config/dictionary แก้ง่าย)
- สั่ง "ในระดับที่ถึงแล้ว" → เธอเต็มใจทำตาม (อาจ +Bond เล็กน้อย)
- สั่ง "เกินระดับ" → เธอปฏิเสธ + **Bond ลด** + ตราหรี่ (กฎหลักของเกม)

### ตารางขั้นเริ่มต้น (ปรับได้)
| ระดับ Bond | ชื่อขั้น | ตัวอย่างคำสั่งที่ปลดล็อก |
|-----------|---------|------------------------|
| 0–19 | เย็นชา (Wary) | (สั่งไม่ได้เลย — บังคับ = พันธะลด) |
| 20–39 | ยอมรับ (Acquaint) | "มานี่", "นั่งลง", "ถือของให้หน่อย" |
| 40–59 | ไว้ใจ (Trust) | "จับมือ", "เล่าเรื่องตัวเองหน่อย", "พาไปดูที่ลับ", "สามารถออรัลเซ็กได้ เปิดใจ" |
| 60–99 | ใกล้ชิด (Close) | "สามารถสั่ง sex ได้ ฉากโรแมนติก ไม่เขินอาย ยอมรับการกระทำของ ผู้เล่นได้ แต่ไม่สามารถสังที่ไม่ชอบได้" |
| 100 | คนรัก (Lover) | "สั่งได้ทุกอย่าง เล่นได้ทุกคำสั่งหรือสนทนาที่มี สามารถยอมรับทุกอยางที่ ผู้เล่นต้องการ จุดนี้ถือว่าให้ผู้เล่นสนุกได้เต็มที่แล้ว |

> **เรื่องเนื้อหาผู้ใหญ่:** ตัวละครทั้งหมดเป็น **ผู้ใหญ่** คำสั่งขั้นสูง (80+) ที่ออกแนว intimate ให้ทำเป็น
> **ฟีเจอร์ที่เปิด/ปิดได้ใน Settings** (mature mode toggle) เผื่อทำเวอร์ชัน all-age ด้วย — ออกแบบโครงให้รองรับไว้
> **Phase 1 (MVP):** ยังไม่ต้องทำคำสั่งครบทุกขั้น — ทำแค่ "กลไกพื้นฐาน" 1–2 คำสั่งง่าย ๆ พอให้เห็นว่าระบบทำงาน (เช่น ขั้น 20 "มานี่") ที่เหลือค่อยเติมเฟสถัดไป

## 2. ระบบบทสนทนา (Dialogue)
- แนะนำใช้ addon **Dialogue Manager** (Godot Asset Library) — รองรับตัวเลือก, ตัวแปร, เงื่อนไข
- บทเก็บเป็นไฟล์ `.dialogue` ใน `dialogues/` เช่น `liena_opening.dialogue`
- ตัวเลือกเรียกฟังก์ชันปรับ Bond ได้ตรง ๆ เช่น `do GameState.add_bond("liena", 2)`
- ใช้ตัวแปรชื่อผู้เล่น `{player_name}` แทนค่าจาก GameState

## 5. ตัวอย่างโครง GameState (autoload)
```gdscript
# scripts/globals/game_state.gd  (ตั้งเป็น Autoload ชื่อ GameState)
extends Node

var player_name: String = "เคน"

# พันธะ 0–100 ต่อคน (ลิเอน่าเริ่มที่ 20 จากตราที่ติดโดยอุบัติเหตุ)
var bond: Dictionary = { "liena": 20 }

# ระดับพันธะขั้นต่ำของแต่ละคำสั่ง — ตั้งค่าเองได้ตรงนี้
var command_req: Dictionary = {
    "come_here": 20,   # มานี่
    "sit_down": 20,    # นั่งลง
    "hold_hand": 40,   # จับมือ
    "hug": 60,         # กอด
    "change_outfit": 80,  # คำสั่งขั้นใกล้ชิด (gate ด้วย mature_mode)
}
var mature_mode: bool = false   # เปิด/ปิดคำสั่งขั้นผู้ใหญ่ใน Settings

func add_bond(who: String, amount: int) -> void:
    bond[who] = clampi(bond.get(who, 0) + amount, 0, 100)

# คำสั่งนี้ "สั่งได้ไหม" ณ ระดับพันธะปัจจุบัน
func can_command(who: String, cmd: String) -> bool:
    var req: int = command_req.get(cmd, 999)
    if req >= 80 and not mature_mode:
        return false
    return bond.get(who, 0) >= req

func get_ending() -> String:
    return "ending_warm" if bond.get("liena", 0) >= 40 else "ending_cold"

func save_game() -> void:
    # TODO: เขียน player_name, bond, mature_mode ลงไฟล์ (ConfigFile / JSON)
    pass

func load_game() -> void:

    pass
```
> ตัวอย่างใช้งานในบท: ถ้าผู้เล่นสั่ง "มานี่" → เช็ก `GameState.can_command("liena","come_here")`
> ถ้า `true` เธอทำตาม (+Bond) / ถ้า `false` เธอปฏิเสธ (-Bond, ตราหรี่)
