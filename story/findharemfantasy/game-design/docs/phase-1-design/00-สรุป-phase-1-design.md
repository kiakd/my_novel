# Phase 1 — Design Document (ฉบับรวม)

> เป้าหมาย Phase 1 (ดู [แผนงาน](../03-แผนงานทีละเฟส.md)): เกมจีบสาว 2D เล่นจบได้ 1 รอบ
> ตัวละครสาว **1 คน (เอลฟ์)** + บทเปิดเกม ~5–10 นาที + ตอนจบ 2 แบบ

## โทนและธีม
- แนว: **แฟนตาซี isekai (ข้ามโลก) + จีบสาว/ฮาเร็ม**
- จุดขายหลัก: ตัวเอกมี **"พลังตราทาส"** ที่ผูกพันธะกับผู้อื่น โดย —
  > **กลไกสำคัญ:** สั่งได้ "เป็นขั้นตามระดับพันธะ (Bond 0–100)" — พันธะยิ่งสูง ยิ่งปลดล็อกคำสั่งที่ใกล้ชิดขึ้น และเธอเต็มใจทำตาม / สั่งเกินระดับใจเธอ = ถูกปฏิเสธ + พันธะลด
  > → เกมจึงไม่ใช่เรื่อง "ครอบครอง" แต่เป็นเรื่อง "ค่อย ๆ จีบให้พันธะถึงระดับที่เธอเปิดใจเอง"
  > (ระดับขั้น/ตัวเลขปลดล็อก ตั้งค่าเองได้ — ดู [05-ระบบเกม-phase1.md](05-ระบบเกม-phase1.md))
- โทนอารมณ์: อบอุ่น + ตลกเบา ๆ + โรแมนติก (ไม่ใช่ดาร์ก/รุนแรง)

## ขอบเขต Phase 1 (ทำแค่นี้ ห้ามเกิน)
- ✅ เอลฟ์ 1 คน
- ✅ ฉากเปิด (ตก → ตีตรา → บทสนทนาแรก)
- ✅ 1 "วัน" ของเนื้อเรื่อง (สั้น ๆ) หลังตีตรา
- ✅ ค่าพันธะ (Bond) ขึ้น/ลงตามตัวเลือก
- ✅ ตอนจบ 2 แบบ (พันธะสูง = เธอเริ่มไว้ใจ / พันธะต่ำ = เธอยังเย็นชา)
- ❌ ยังไม่ทำ: ตัวละครคนที่ 2, ระบบวันหลายวัน, ฉาก 3D/VR (ไว้เฟสถัดไป)

## สิ่งที่งานสายอื่นต้องส่งมอบใน Phase 1
- **คนเขียนบท:** บทตามไฟล์ 04 ลงใน Dialogue Manager

- **คนเขียนโค้ด:** ระบบไฟล์ 05 (Bond meter, ตัวเลือก, save/load, ตอนจบ)
