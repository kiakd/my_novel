# Heroine คนแรก — เอลฟ์สาว

## ข้อมูลตัวละคร
- ชื่อ (ชั่วคราว): **ลิเอน่า (Liena)** — เปลี่ยนได้ ใช้เป็นชื่ออ้างอิง
- เผ่า: ไฮเอลฟ์ (High Elf) จากป่าโบราณ
- อายุ (ดูภายนอก ~18–20 / จริง ๆ อายุมากตามแบบเอลฟ์)
- บทบาท: heroine คนแรก, คนที่ถูกตีตราในฉากเปิด

## บุคลิก (Personality)
- **ภายนอก:** หยิ่งทะนง มีศักดิ์ศรี ระแวงมนุษย์ ปากแข็ง (tsundere เอนทางเย็นชา)
- **ภายใน:** จริง ๆ เหงา แบกความรับผิดชอบของเผ่า อ่อนโยนกับสิ่งมีชีวิตเล็ก ๆ
- **ปมเฉพาะตัว:** เผ่าเอลฟ์เกลียด "ตราทาส" ที่สุด → การมีตราบนตัวคือเรื่องน่าอับอาย/หวาดกลัวสำหรับเธอ
- **เส้นพัฒนา (arc) ใน Phase 1:** จากโกรธ/รังเกียจ → งง ๆ ว่าทำไมตัวเอกไม่ใช้ตราสั่งเธอ → เริ่มแคลงใจในอคติของตัวเอง → ยอมเดินทางด้วยกัน (จุดเริ่มความไว้ใจ)

## จุดเด่นด้านการเขียนบท
- มุก: เธอคอย "เผลอ" ออกคำสั่งให้ตัวเอกทำตาม (ในฐานะเอลฟ์สูงศักดิ์) แต่ตราดันทำให้ **ตัวเอกต่างหากที่เป็นเจ้าของตรา** → สลับขั้วตลก ๆ
- ความน่าลุ้น: ตัวเอกมีอำนาจ "สั่ง" ได้ตามทฤษฎี แต่เลือกไม่ทำ → ทุกครั้งที่ไม่ใช้อำนาจ เธอจะแปลกใจและค่อย ๆ ไว้ใจ

## สเปกภาพ 2D (สำหรับคนวาด)

### รูปลักษณ์
- ผมยาวสีเงิน/ทองอ่อน, หูแหลมยาวแบบเอลฟ์, ตาสีเขียวมรกตหรือฟ้า
- รูปร่างสูงเพรียว ท่าทางสง่า
- ชุด: ชุดนักเดินทางเอลฟ์ โทนเขียว/น้ำตาล/ขาว มีลายใบไม้ ผ้าคลุมเบา ๆ
- **จุดสำคัญ — ตราทาส:** ออกแบบสัญลักษณ์ตรา (ลายเวทเรืองแสง) วางตำแหน่งที่เห็นได้ เช่น **หลังมือ / ต้นคอ / ไหล่** (เลือก 1 ตำแหน่งให้คงที่) — ตราจะเรืองแสงอ่อนตอนพันธะต่ำ และสว่างขึ้นเมื่อพันธะสูง

### สีหน้า/อารมณ์ที่ต้องวาด (Phase 1 ขั้นต่ำ 6 แบบ)
ใช้ระบบ visual novel (ภาพครึ่งตัว เปลี่ยนสีหน้าได้):
1. **neutral** — ปกติ/นิ่ง
2. **angry** — โกรธ/หยิ่ง (ใช้เยอะช่วงต้น)
3. **surprised** — ตกใจ (ตอนโดนตีตรา, ตอนตัวเอกไม่ใช้อำนาจ)
4. **blush** — เขิน/หน้าแดง (ช่วงพันธะเริ่มขึ้น)
5. **sad** — เศร้า/กังวล (ตอนพูดถึงปมเรื่องตรา)
6. **smile** — ยิ้ม/อ่อนลง (รางวัลตอนพันธะสูง)

### ข้อกำหนดไฟล์ภาพ
- ภาพครึ่งตัว/เต็มตัว พื้นหลังโปร่ง (PNG)

- ถ้าเป็นไปได้ ออกแบบให้ **เปลี่ยนเฉพาะหน้า** (ตัว/ท่าเดิม) เพื่อง่ายต่อการทำ + อนาคตอัปเป็น Live2D ได้
