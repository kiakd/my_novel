# โครงสร้างโปรเจกต์ (จัดโฟลเดอร์ยังไง)

จัดไฟล์ให้เป็นระเบียบตั้งแต่แรก จะได้ไม่งงตอนเกมโตขึ้น

## โครงสร้างที่แนะนำ
```
findharemfantasy/
├── docs/                  ← เอกสารวางแผน (โฟลเดอร์นี้)
├── project.godot          ← ไฟล์โปรเจกต์หลักของ Godot
├── .gitignore
│
├── assets/                ← ของดิบ: ภาพ เสียง โมเดล
│   ├── characters/        ← ภาพตัวละครสาว 2D (แยกโฟลเดอร์ต่อคน)
│   │   ├── aoi/
│   │   └── mei/
│   ├── backgrounds/       ← ภาพพื้นหลัง 2D
│   ├── rooms_3d/          ← โมเดลห้อง 3D, เฟอร์นิเจอร์
│   ├── audio/             ← เพลง bgm/ เสียงเอฟเฟกต์ sfx
│   └── ui/                ← ปุ่ม กรอบ ไอคอน
│
├── scenes/                ← ฉาก (.tscn) ของเกม
│   ├── main_menu.tscn     ← เมนูเริ่มเกม
│   ├── dialogue_2d.tscn   ← ฉากคุยแบบ 2D (เฟส 1)
│   ├── room_3d.tscn       ← ห้อง 3D (เฟส 3)
│   └── room_vr.tscn       ← ห้องเวอร์ชัน VR (เฟส 4)
│
├── scripts/               ← โค้ด GDScript (.gd)
│   ├── globals/           ← ตัวจัดการกลาง (autoload)
│   │   ├── game_state.gd   ← เก็บค่าความสัมพันธ์, วันที่, เซฟ
│   │   └── audio_manager.gd
│   ├── dialogue/          ← ระบบบทสนทนา
│   └── characters/        ← พฤติกรรมตัวละคร
│
└── dialogues/             ← ไฟล์บทพูด (.dialogue ถ้าใช้ Dialogue Manager)
    ├── aoi_day1.dialogue
    └── mei_day1.dialogue
```

## หลักการจัดไฟล์
- **assets = ของดิบ** (ภาพ เสียง) / **scenes = ฉากที่ประกอบแล้ว** / **scripts = โค้ด**
- ตั้งชื่อไฟล์เป็น **ตัวพิมพ์เล็ก_มีขีดล่าง** (เช่น `main_menu.tscn`) — กันปัญหาตอน export ข้ามระบบ
- แยกของแต่ละตัวละครเป็นโฟลเดอร์ของตัวเอง พอเพิ่มคนใหม่จะง่าย

## ตัวที่ควรเป็น "Autoload" (Singleton)
ตั้งใน Project Settings > Autoload — เป็นตัวที่เข้าถึงได้ทุกที่ในเกม:
- `GameState` — เก็บค่าความสัมพันธ์ของสาวแต่ละคน, วันปัจจุบัน, ระบบเซฟ/โหลด
- `AudioManager` — เล่นเพลง/เสียงจากที่ไหนก็ได้

## เคล็ดลับเรื่องการแยก 2D / 3D / VR
ออกแบบให้ **ระบบเกม (ค่าความสัมพันธ์ บทพูด) แยกออกจากการแสดงผล**
- ระบบเกมอยู่ใน `scripts/globals/game_state.gd` → ไม่รู้ว่าเป็น 2D หรือ VR
- ฉาก 2D, 3D, VR แค่ "ดึงข้อมูลจาก GameState มาแสดง" คนละแบบ

ทำแบบนี้แล้ว เวลาเพิ่ม VR (เฟส 4) คุณไม่ต้องเขียนระบบความสัมพันธ์ใหม่ แค่ทำฉากใหม่ที่ดึงข้อมูลเดิม
