# สเปกงาน 3D Art (Low-Poly) — สำหรับคนปั้นโมเดล

> เอกสารนี้คือ "กติกากลาง" ให้ทุกคนปั้นโมเดลไปในทิศทางเดียวกัน
> สไตล์เป้าหมาย: **Low-poly สไตล์ไลซ์ (stylized)** สีสด ขอบสะอาด เหมาะกับเกมจีบสาวอนิเมะใน VR
> เอนจินปลายทาง: **Godot 4 + VR (OpenXR)** — ทุกข้อในนี้ตั้งมาเพื่อให้ลื่นบนแว่น VR

---

## 0. สิ่งที่ต้องท่องให้ขึ้นใจ (อ่านก่อนปั้น)
1. **สเกลต้องจริง:** 1 หน่วยใน Blender/Godot = **1 เมตรจริง** — สำคัญที่สุดสำหรับ VR ถ้าสเกลผิดผู้เล่นจะเมา/รู้สึกแปลก
2. **Low-poly จริง ๆ:** เน้นรูปทรงสะอาด ใช้สีบอกรายละเอียดแทนการเพิ่มเหลี่ยม
3. **VR กิน performance 2 เท่า** (เรนเดอร์ตาซ้าย-ขวา) → งบ poly/วัสดุต้องประหยัด
4. ส่งไฟล์เป็น **glTF (.glb)** เสมอ — เป็นฟอร์แมตที่ Godot รักที่สุด

---

## 1. สเกลและหน่วย (Units & Scale)
- หน่วย: **เมตร** (Metric). ใน Blender ตั้ง Unit Scale = 1.0, Length = Meters
- แกนขึ้น: ปั้นใน Blender ใช้ **Z-up** แล้ว export glTF จะแปลงเป็น Y-up ให้เอง (Godot เป็น Y-up) — ใช้ค่า export ดีฟอลต์
- ระยะอ้างอิงสำหรับเช็กสเกล (เอาไว้วางเทียบตอนปั้น):
  | ของ | ขนาดจริงโดยประมาณ |
  |-----|-------------------|
  | ความสูงระดับสายตาผู้เล่น (นั่ง) | ~1.2 ม. |
  | ความสูงระดับสายตาผู้เล่น (ยืน) | ~1.6 ม. |
  | ประตู | สูง 2.0 ม. กว้าง 0.9 ม. |
  | โต๊ะ | สูง 0.75 ม. |
  | เก้าอี้ (ที่นั่ง) | สูง 0.45 ม. |
  | เตียงเดี่ยว | 2.0 × 1.0 ม. |
  | ตัวละครสาว (อ้างอิง) | สูง ~1.6 ม. |
- **ทุกโมเดลต้องนำเข้า Godot แล้วขนาดถูกทันทีโดยไม่ต้อง scale** (scale ใน Godot = 1,1,1)

## 2. จุดหมุน (Pivot / Origin)
- วาง origin ของวัตถุไว้ที่ **จุดที่มันสัมผัสพื้น กึ่งกลางฐาน** (เช่น เก้าอี้ origin อยู่กลางขาเก้าอี้บนพื้น)
- ของที่แขวน/ติดผนัง → origin อยู่ที่จุดสัมผัสผนัง
- ห้อง (environment) → origin อยู่ที่ **กึ่งกลางพื้นห้อง (0,0,0)**
- **Apply transform** (location/rotation/scale) ทุกชิ้นก่อน export

## 3. งบ Polygon (Triangle Budget)
นับเป็น **สามเหลี่ยม (tris)** ไม่ใช่ quad ขอให้อยู่ในกรอบนี้:
| ประเภท | งบ tris ต่อชิ้น | หมายเหตุ |
|--------|----------------|----------|
| Prop เล็ก (แก้ว, หนังสือ, ตุ๊กตา) | 50 – 300 | |
| Prop กลาง (เก้าอี้, โคมไฟ, ลำโพง) | 300 – 1,000 | |
| เฟอร์นิเจอร์ใหญ่ (เตียง, ตู้, โซฟา) | 1,000 – 3,000 | |
| โครงห้อง (พื้น+ผนัง+เพดาน) | 1,000 – 4,000 | |
| **รวมทั้งฉากห้อง 1 ฉาก** | **≤ 50,000 tris** | เป้าเพื่อ VR ลื่น 90fps |
- หลีกเลี่ยง: ขอบมนที่ใช้เหลี่ยมเยอะ, น็อต/รอยต่อเล็ก ๆ ที่ปั้นเป็นเรขาคณิต → ใช้ texture/สีแทน
- ไม่ต้องทำ LOD ในเฟสแรก (low-poly อยู่แล้ว)

## 4. Topology
- ใช้ quad เป็นหลักตอนปั้น, สามเหลี่ยมได้เฉพาะจุดที่จำเป็น
- ไม่มี n-gon (เหลี่ยมเกิน 4 ด้าน) ในชิ้นงานส่งจริง
- ลบหน้าที่มองไม่เห็น (เช่น ใต้เตียง, หลังตู้ติดผนัง) เพื่อประหยัด
- เชื่อม vertex ที่ควรเชื่อม (no doubles) — รัน Merge by Distance ก่อนส่ง

## 5. UV และ Texture
สไตล์ low-poly แนะนำ 2 แนวทาง (เลือกให้สม่ำเสมอทั้งโปรเจกต์):
- **แนะนำ A — Color Palette Atlas:** ใช้ texture สีเดียว 1 รูปเล็ก (เช่น 256×256) เป็น "จานสี" แล้ว UV ทุกชิ้นไปแตะช่องสีที่ต้องการ → ทั้งฉากใช้ texture เดียว ประหยัด draw call สุด ๆ (เหมาะ VR มาก)
- แนวทาง B — Texture แยกชิ้น: ถ้าต้องมีลวดลาย ใช้ texture ขนาด **≤ 512×512** ต่อชิ้น
- รูปแบบไฟล์ texture: **PNG** (หรือ WebP)
- ไม่ต้องทำ normal map ในเฟส low-poly (ไม่จำเป็นและกิน performance)

## 6. Material
- ใช้ **PBR แบบเรียบง่าย** หรือ unshaded ก็ได้ตามสไตล์
- **จำนวน material ต่อฉากให้น้อยที่สุด** (ตั้งเป้า ≤ 5 material ทั้งห้อง) — แต่ละ material = 1 draw call โดยประมาณ
- ตั้งชื่อ material ชัดเจน เช่น `mat_room_atlas`, `mat_glass`
- ของที่ใส (แก้ว, หน้าต่าง) แยก material โปร่งใสไว้ต่างหาก

## 7. Lighting / Collision (ฝั่ง modeler เตรียมให้)
- **อย่า** ฝังแสง (baked light) มาในโมเดล — แสงจัดใน Godot
- เว้น UV channel 2 ไว้ให้ Godot ทำ lightmap เอง (Godot generate ให้ได้ตอน import ไม่ต้องทำมือ ถ้าไม่ถนัด)
- Collision: ไม่ต้องปั้น collider แยก — เราจะสร้างใน Godot จากรูปทรงง่าย ๆ (box/มือ) เอง แต่ขอให้รูปทรงโมเดล "ไม่ซับซ้อนเกินจำเป็น" เพื่อให้ทำ collider ง่าย

## 8. การตั้งชื่อไฟล์ & object
- ไฟล์: `ตัวพิมพ์เล็ก_มีขีดล่าง.glb` เช่น `chair_wood.glb`, `room_bedroom.glb`
- ชื่อ object/mesh ใน Blender ก็ใช้รูปแบบเดียวกัน
- หมวดหมู่ prefix:
  | prefix | หมวด | ตัวอย่าง |
  |--------|------|----------|
  | `room_` | โครงห้อง/สภาพแวดล้อม | `room_bedroom.glb` |
  | `furn_` | เฟอร์นิเจอร์ | `furn_bed.glb`, `furn_desk.glb` |
  | `prop_` | ของตกแต่งเล็ก | `prop_mug.glb`, `prop_plushie.glb` |
- วางไฟล์ส่งใน `assets/rooms_3d/` (ดู [04-โครงสร้างโปรเจกต์.md](04-โครงสร้างโปรเจกต์.md))

## 9. รายการ Asset ชุดแรกที่ต้องปั้น (เฟส 3)
เป้าหมายเฟส 3 คือ **"ห้องนอนหนึ่งห้อง"** ให้ผู้เล่นเดินเข้าไปคุยกับตัวละครได้:
- [ ] `room_bedroom` — โครงห้อง: พื้น 4×4 ม. ผนัง 3 ด้าน เพดานสูง 2.6 ม. มีหน้าต่าง 1 บาน ประตู 1 บาน
- [ ] `furn_bed` — เตียงเดี่ยว
- [ ] `furn_desk` — โต๊ะทำงาน
- [ ] `furn_chair` — เก้าอี้
- [ ] `furn_shelf` — ชั้นวางของติดผนัง
- [ ] `furn_rug` — พรมกลางห้อง (ช่วยกำหนดจุดที่ตัวละครยืน)
- [ ] `prop_lamp` — โคมไฟตั้งโต๊ะ
- [ ] `prop_plushie` ×2 — ตุ๊กตา (เพิ่มความน่ารัก)
- [ ] `prop_books` — กองหนังสือ
- [ ] `prop_window_light` (ออปชัน) — ระนาบแสงจากหน้าต่าง

### จุดวางตัวละคร (สำคัญสำหรับ VR)
- ออกแบบห้องให้มี **"จุดที่ตัวละครสาวจะยืน/นั่ง"** อยู่ห่างจากจุดผู้เล่นประมาณ **1.2–2.0 ม.** และอยู่ในระดับสายตา
- ตัวละครจะเป็น **ภาพ 2D (billboard)** ในเฟสนี้ (ดู [01-เลือก-2d-หรือ-3d.md](01-เลือก-2d-หรือ-3d.md)) → modeler **ไม่ต้องปั้นตัวคน** แค่เผื่อพื้นที่ว่างให้ป้ายภาพยืนได้สวย ๆ

## 10. Checklist ก่อนส่งงานแต่ละชิ้น
- [ ] สเกลจริง (1 unit = 1 m), apply transform แล้ว
- [ ] origin อยู่จุดสัมผัสพื้น/ผนังถูกต้อง
- [ ] tris อยู่ในงบตามตารางข้อ 3
- [ ] ไม่มี n-gon / ไม่มี vertex ซ้อน / ลบหน้าที่มองไม่เห็นแล้ว
- [ ] material/texture ตามกติกาข้อ 5–6
- [ ] ตั้งชื่อไฟล์ & object ตามข้อ 8
- [ ] export เป็น `.glb` แล้วลองลากเข้า Godot เห็นขนาด/สีถูกต้อง
