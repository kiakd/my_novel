# Find Harem Fantasy — Bible (ฉบับนิยาย · เฟส ลิเอน่า)

> เจ้าของ: แอป novel · POV บุคคลที่ 3 limited ติดตามเคน · R18 อิสระ · ตราทาส = "สมบูรณ์แบบจากพระเจ้า"
> ใช้คู่กับ [00-novel-bridge-plan.md](00-novel-bridge-plan.md) · ฟิลด์ออกแบบให้แปลงเป็น meta.json ได้

## โลก (World / Lore)
- **เอลดรา (Eldra)** — โลกแฟนตาซีกึ่งยุคกลาง มีเวทมนตร์ เอลฟ์ มนุษย์ และเผ่าอื่น ป่าโบราณ + อาณาจักรเอลฟ์
- **ยุคพันธนาการ:** อดีตมนุษย์เคยใช้ "ตราทาส" กดขี่เผ่าอื่น → เอลฟ์ **เกลียด/กลัวตราทาสที่สุด** (ปมแกนของลิเอน่า)
- **ตราทาส 2 ชนิด:**
  - *ตราทาสปกติ (ของโลกเอลดรา)* — มนุษย์ในอดีตใช้ บังคับได้บางส่วน มีช่องโหว่ ทาสยังทำร้าย/ขัดขืนได้ในบางกรณี
  - *ตราทาสสมบูรณ์ (ของเคน — ได้จากพระเจ้าตอนข้ามมิติ)* — **ดูกฎเต็มด้านล่าง** ต่างจากตราปกติโดยสิ้นเชิง

## ⭐ ตราทาสสมบูรณ์ (Core Mechanic) — พลังพระเจ้า
> ตรา = พลังจากพระเจ้า **สูงสุดในตัวเอง** ไม่ขึ้นกับสถานะผู้ถูกตี (ดูระบบพลัง 3 สาย + ตรา [02-worldbuilding.md §2](02-worldbuilding.md))
> เคนตีตราแรกพลาดโดน **ลิเอน่า ผู้พิทักษ์ป่าจอมเวทสูงสุดของเรื่อง** → แม้เธอแข็งแกร่งที่สุดก็ขัดขืนพลังพระเจ้าไม่ได้ = OP/ตัวโกง (ตีได้หลายคน harem + ยืมเวทผ่านพันธะ + ดังทางพลัง → ถูกตามล่า)

ตราที่เคนได้มา "สมบูรณ์แบบ" — เป็นของพระเจ้า ไม่ใช่เวทของโลกนี้:
1. **กาย/การกระทำต้องเชื่อฟังเด็ดขาด** — คำสั่งของเคนต่อ "ร่างกาย/การกระทำ" ของผู้ถูกตี ทำตามเสมอ **ไม่ว่าค่าใจ (rel) จะติดลบแค่ไหน** (ไม่มี gate, ไม่มีปฏิเสธเชิงกาย)
2. **ใจ/คำพูด/ท่าที/ความคิด = อิสระเต็มที่** — ด่า ประชด เกลียด ร้องไห้ คิดต่อต้านได้หมด → "กายจำยอมแต่ใจไม่ยอม"
3. **ทำร้ายเจ้าของตรา (เคน) ไม่ได้** — แม้ rel = −100 ลิเอน่าก็ลงมือทำร้ายเคนไม่ได้ (ตราปกป้องเจ้าของอัตโนมัติ)
4. **ตรา "ดึง" ให้อยู่ใกล้** — ห่างเกินรัศมีหนึ่งจะเจ็บ/อ่อนแรงทั้งคู่ → บังคับให้เดินทางด้วยกัน
5. **เคนยังลบ/คุมตราไม่เป็น** (เพิ่งได้มา) — เป้าหมายร่วม: หาทางเข้าใจ/ควบคุม/ลบตรา
6. **ค่าใจ (rel −100..100)** = มาตรวัด "ความสัมพันธ์/ใจ" เท่านั้น **ไม่ใช่ตัว gate คำสั่ง** — ตราสว่างขึ้นเมื่อ rel สูง หรี่ลงเมื่อ rel ต่ำ (เป็นสัญญาณภาพ ไม่ลดอำนาจ)

> **ดราม่าเอนจิน:** เคนมีอำนาจสมบูรณ์ "สั่งได้ทุกอย่าง" แต่ **เลือกไม่ใช้บังคับ** (เพราะเกลียดการกดขี่) → ลิเอน่างงว่าทำไมมนุษย์ที่ถือตราไม่สั่งเธอ → อคติเริ่มสั่นคลอน → rel ไต่ขึ้นเอง
> **map ฝั่งแอป (chat-mode/stateCard):** `power` = ตราทาสสมบูรณ์ · `powerStanding = true` · `rel` มาตรวัดใจ
> **divergence จากเกม:** เกม `can_command()` gate ด้วย bond · นิยายไม่ gate — ตอน export ต้องแปลง (ฉาก "เคนเลือกไม่สั่ง" → choice ในเกม)

## ความสัมพันธ์ (relation)
- **เคน ↔ ลิเอน่า:** เคนเป็นเจ้าของตราทาสสมบูรณ์เหนือลิเอน่า (โดยอุบัติเหตุ) — แต่เลือกไม่ใช้บังคับ · ลิเอน่าเริ่มจากรังเกียจ/หวาดตรา ค่อย ๆ งุนงงในความไม่ใช้อำนาจของเคน

## styleGuide (ลายเซ็นการเขียน)
- โทน **rom-com แฟนตาซี + ดราม่าปมตรา** — อบอุ่น/ตลกเบา/โรแมนติกเป็นฐาน แต่ R18 อิสระเต็มที่เมื่อถึงฉาก
- บุคคลที่ 3 limited ติดตามเคน — เห็นความคิด/มุมเขา, ตัวอื่นเห็นจากภายนอก
- **fish-out-of-water:** เคนเสียงสมัยใหม่ปะทะโลกเอลฟ์ (มุกศัพท์/ค่านิยมต่างยุค) · ลิเอน่าเสียงโบราณสูงศักดิ์
- หัวใจทุกฉาก: **อำนาจที่ไม่ถูกใช้** — ความน่าลุ้นอยู่ที่เคนถือไพ่เหนือกว่าแต่เลือกไม่เล่น
- มาตรวัดใจ (rel) ขยับตามเหตุการณ์จริง+นิสัยลิเอน่า (guard สูง บวกยาก)

## dontList (ทิศทาง/ข้อห้าม)
- **เคนเลือกไม่ใช้ตราบังคับลิเอน่าให้ขัดใจเธอ** เป็นค่าเริ่ม (หัวใจเรื่อง) — ใช้ตราเฉพาะ beat สำคัญ/จำเป็น และต้องมีน้ำหนัก/ลังเลเสมอ
- ลิเอน่า **ทำร้ายเคนไม่ได้** (ตราปกป้อง) — rel ติดลบแสดงออกแค่ "คำพูด/ความคิด/ท่าที" เท่านั้น
- ลิเอน่า **guard สูง ห้ามใจอ่อน/ยอมเร็วเกินเหตุ** — ความสัมพันธ์ต้องได้มาด้วยเหตุการณ์จริง
- ฉาก R18 **เกิดผ่านตราได้ (กายยอม) แม้ rel ต่ำ** แต่ลิเอน่าต้านทาง "ใจ/คำพูด" ตามจริง + rel สะท้อนความรู้สึกจริง (กายจำยอม ใจไม่ยอม) — ไม่ใช่เธอยินดีทันที
- เคน **พูดไทยสมัยใหม่** · ลิเอน่า **พูดโบราณสูงศักดิ์** — ห้ามสลับ/ปนเสียง
- เฟสนี้ **ลิเอน่าคนเดียว** — ห้ามดันตัวละคร/เผ่าอื่นเข้ามาเป็นแกน
- ห้ามลืมว่าเคนเป็น "คนธรรมดา" — ไม่เก่งเวท/รบ แก้สถานการณ์ด้วยหัวคิด/มุก ไม่ใช่พลัง
