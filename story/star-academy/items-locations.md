## A) ไอเทม — ยุคเปล (ตอน 1 + แฟลชแบ็ก/เสียงในหัว)

**สายพ่วงสีส้ม + ปลั๊กสามตา + ฮีตเตอร์อบชิ้นงาน (orange extension cord)**
- keys: สายพ่วง, ปลั๊กสามตา, ฮีตเตอร์, ต้นเพลิง
- text: สายพ่วงชั่วคราวเสื่อมสภาพเลี้ยงพัดลมห้องเก็บวัสดุไวไฟ — จุดที่ภูมิแจ้งซ่อมสองรอบแล้วโดนดอง 94 วัน ปลายสายมีปลั๊กสามตาที่กะเย็นเสียบฮีตเตอร์อบชิ้นงานทิ้งไว้หลังชั้นวาง = ต้นเพลิงจริง (ภูมิดึงเฉพาะปลั๊กพัดลม = ลดโหลด ไฟไม่ได้เกิดจากมือเขา)
- always: false · priority: 8

**ถังดับเพลิงหมดอายุตรวจ**
- keys: ถังดับเพลิง, หมดอายุ
- text: ถังตัวแรกที่ภูมิคว้าหมดอายุตรวจมาสองเดือน (เขาเป็นคนเขียนใบแจ้งเรื่องนี้เองด้วย) พ่นได้ครึ่งถัง — ชิ้นส่วนของ irony "เอกสารที่เขาทำถูกแล้วระบบเมิน"
- always: false · priority: 4

**แท็บเล็ตประจำกะ + ระบบแจ้งซ่อม**
- keys: แท็บเล็ต, ใบแจ้งซ่อม, รอพิจารณางบประมาณ
- text: แท็บเล็ต (ศัพท์ยุคเปลเท่านั้น — Style Note ข้อ 1) ใช้เปิดใบงานสถานะ "รอพิจารณางบประมาณ 94 วัน" — รากนิสัยภูมิ "อ่านเอกสารทุกบรรทัด" ที่อ้างย้อนได้ทั้งเรื่อง
- always: false · priority: 6

**เครื่องมือช่างของภูมิ**
- keys: ประแจหกเหลี่ยม, แม่แรงมือ, ไฟฉาย
- text: ประแจหกเหลี่ยม (เบอร์ห้า/เบอร์หก — มุกเปิดเรื่องกับก้อง), แม่แรงมือที่ใช้งัดชั้นเหล็กช่วยก้อง, ไฟฉายคาบปาก — ของสามัญโรงซ่อมยุคเปล ใช้ในแฟลชแบ็กได้
- always: false · priority: 3

**คลังในหัวภูมิ (ความรู้ยุคเปล)**
- keys: เรือดำน้ำสงครามเย็น, เกมซิมการบิน, เกมวางแผนรบ, silent running
- text: หนังสือประวัติศาสตร์เรือดำน้ำสงครามเย็น (คั่นครึ่งเล่มบนหัวเตียง), เกมซิมูเลเตอร์การบิน, เกมวางแผนรบ, ไซไฟเก่า — "ตำราที่โลกนี้ทำหาย" ตาม world-bible หมวด 0 ข้อ 2 ทุกการใช้ต้องมีต้นทุน (ข้อ 4)
- always: false · priority: 9

## B) ไอเทม — โลกอนาคต (ปรากฏแล้ว ep001–004)

**โน้ตกระดาษ "อย่าบอกใคร"**
- keys: โน้ต, กระดาษจริง, อย่าบอกใคร
- text: กระดาษจริงแผ่นเดียวฉีกจากสมุดของแม่ธัญ ลายมือหวัดๆ บรรทัดเดียว "ถ้าตื่นมาแล้วจำไม่ได้ — อย่าบอกใคร" ธัญเขียนล่วงหน้าก่อนคืนซิงก์ช็อก ภูมิพบในถาดลิ้นชักข้างเตียง medbay (ep001) ปัจจุบันภูมิเก็บไว้ — กระดาษจริงในโลกนี้ = สัญญาณ "ไม่ไว้ใจเครือข่าย" (world-bible 6)
- always: false · priority: 10

**สมุดกระดาษของแม่ธัญ**
- keys: สมุดของแม่, สมุดกระดาษ
- text: สมุดกระดาษจริงของแม่ธัญ (เสียเมื่อธัญ 9 ขวบ) ที่ธัญเก็บไว้ — ต้นทางของแผ่นที่ฉีกเป็นโน้ต ตัวสมุดยังอยู่ในข้าวของของธัญ (ตำแหน่งจัดเก็บยังไม่เข้าฉาก — ใช้เมื่อ outline ระบุ)
- always: false · priority: 6

**แท็บ (อุปกรณ์ส่วนตัว)**
- keys: แท็บ, อันดับคาดการณ์, แจ้งเตือน
- text: อุปกรณ์ประจำตัวทุกคน (ศัพท์โลกอนาคต — ห้ามเรียกแท็บเล็ต) มีรุ่นถือและรุ่นข้อมือ ใช้รับประกาศกระดานเมริต/ใบเหลือง/ข้อความ และแสดง "อันดับคาดการณ์" เรียลไทม์ — แจ้งเตือนค้างเด้งได้ถ้าไม่แตะแท็บ
- always: true · priority: 8

**แผ่นเขียน (ฟิล์มโน้ตดิจิทัล)**
- keys: แผ่นเขียน, ฟิล์มโน้ต, ลำดับไล่เช็กก่อนบิน
- text: ของเขียนทั่วไปของยุคนี้ — ฟิล์มดิจิทัลใช้ซ้ำ ไม่มีนัยพิเศษ (ตรงข้ามกระดาษจริงซึ่งเป็นธงแดงเงียบๆ) · **บรรทัดกำกับ (canon ep006 — ปิดข้อตึง world-bible 6)**: การจดลำดับไล่เช็กก่อนบินด้วยลายมือบนแผ่นเขียน = **ธรรมเนียมนักเรียนการบิน** (ลายมือเป็นทักษะที่เมมเพล็กซ์ฝังให้ทุกคน — ธรรมเนียมนี้คือการ "เขียนเองให้มือจำ" ของสาย Helm) ไม่ขัดกับความหายากของลายมือในชีวิตทั่วไป และไม่ใช่ธงแดงแบบกระดาษจริง — แผ่นลายมือธัญในกล่องของธัญคือของชิ้นนี้
- always: false · priority: 4

**แจ็กเก็ตนักเรียน + ถาดของส่วนตัว medbay**
- keys: แจ็กเก็ตนักเรียน, ถาดมาตรฐาน, ลิ้นชักข้างเตียง
- text: ระเบียบ medbay: ของส่วนตัวผู้ป่วยหมดสติถูกเทกระเป๋าทำ inventory เป็นรายการ (จดเป็นชิ้น ไม่อ่านเนื้อหา) ใส่ถาดมาตรฐานไว้ลิ้นชักข้างเตียง — เส้นทางที่ทำให้โน้ตถึงมือภูมิโดยไม่มีใครอ่าน
- always: false · priority: 5

**บัตรผ่านเขต**

- always: false · priority: 4

**กระป๋องโปรตีนสกัดเนื้อจริง**

- text: เอกสารที่ออร์โซเซ็น แจ้งสถานะ "ปรับเทียบภายใต้การติดตามแพทย์ 90 วัน" + วันหมดอายุธง + นัดตรวจฝ่ายประสาท + บรรทัด "ความเบี่ยงเบนถูกตีความเป็นการฟื้นตัว ไม่ธงอัตโนมัติ" — ภูมิอ่านครบสามรอบ (ep002) จึงรู้ว่ามีหน้าต่างปลอดภัยนับถอยหลัง

- text: หนังสือทางการเด้งขึ้นแท็บภูมิเช้าวันสี่ (ep003): ถ้าอันดับทางการ ณ สิ้นเดือนต่ำกว่า 350 → ลดชั่วโมงซิมหนึ่งชั้นปีก เกณฑ์เป็นรายเคส ห้ามอ้าง 350 เป็นกฎสากล วงรับรู้: แท็บเจ้าตัว + จอครูประจำสาย + ทะเบียน/แฟ้มแพทย์ — ภูมิไม่บอกใครใน ep001–010
