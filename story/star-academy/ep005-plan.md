## 0) สรุปตอนในหนึ่งย่อหน้า

ผลจับคู่ดวลสุ่มข้ามชั้นปีกออก: ภูมิ (ทองแดง 289) เจอ **ทาลอส เบรย์** ปีกเงินอันดับ 138 — บินตรงๆ แพ้แน่ เขาจึงเล่นเกมที่โลกนี้ลืมไปแล้ว: เกมความร้อน — เร่งหนีให้เงาความร้อนเด่น แล้วดับเครื่องทั้งลำ ลอยเฉื่อยแกล้งตายกลางกลุ่มซากจำลองแบบเรือดำน้ำยุคเก่า ("silent running") รอเบรย์กวาดพื้นที่ตามตำราเข้ามาในระยะ แล้วจุดเครื่องล็อกยิงจบ — สนามทั้งโถงอึ้ง · ราคา (กฎ anti-เก่งเวอร์): กรรมการชี้ว่า "ดับระบบทั้งลำ" อ่านได้สองทางเท่านั้น — ยานขัดข้อง หรือโกง เพราะ *ท่านี้ไม่มีในคลังยุทธวิธี* — ผลเมริตถูกอายัดรอสอบสวน · ปิดตอนในห้องสอบสวน: คาร์เวอร์ไล่ทุกคนออก เหลือสองคน — "บอกครูมาซิ ไอ้ท่าเมื่อกี้ — นายไปเอามาจากไหน"

- ธีม "ของเก่าแก้โจทย์ใหม่" ของตอน: **world-bible หมวด 0 ข้อ 2** (ตำราที่โลกนี้ทำหาย — ประวัติศาสตร์เรือดำน้ำสงครามเย็น) + กฎ "การรบคือเกมความร้อน" (world-bible 4.2)
- ต้นทุนตามข้อ 4 (ห้ามชนะฟรี): ชนะ = โดนกล่าวหาโกงทันที + แฟ้มถูกเปิดเพิ่มอีกชั้นในจังหวะที่โซลกำลังอ่านแฟ้มเขาอยู่แล้ว
- กฎรอยต่อ v2.5: **ฉาก 1 ต้องรับ hook ep004 (ประกาศดวลสุ่มข้ามชั้นปีก = ปม T-09 ครบกำหนดตอนนี้)** — เปิดตอนที่ผลพวงของประกาศนั้นโดยตรง

## 2) ตัวเลข canon ที่ต้องปรากฏ (ห้ามเพี้ยนแม้แต่หลักเดียว — บทเรียน ep004: ห้ามตัวเลขกำกวมทุกจุด)

1. **อันดับทางการภูมิ = 289** (ทองแดงกลาง) ตลอดตอน — ไม่มีประกาศทางการใหม่ในตอนนี้
2. **คู่ดวล: ทาลอส เบรย์ — ปีกเงิน อันดับ 138 ของรุ่นปี 2** (canon ใหม่ วินเคาะในแผนนี้) — ระยะห่าง 151 อันดับ ให้ภูมิอ่านเป็นภาษาช่าง ("เครื่องคนละรุ่น คนละชั่วโมงบิน")
3. บันไดคะแนนคาบ (ต่อจาก ep004: 545 · 11/20): คาบวันสาม **~555 · อันดับคาบ 11/20** → คาบวันสี่ **~560 · อันดับคาบ 10/20 — แตะครึ่งบนของกระดานคาบครั้งแรก** (กระดาน 20 คน ครึ่งบน = 1–10) — beat นี้เขียนเงียบๆ ไม่เกินสามประโยค ห้ามฉลอง
4. ค่าซิงก์ระหว่างดวล (ขึ้นกระดานหลังจบ): **เฉลี่ย ~75% แกว่ง 71–78%** — สูงสุดเท่าที่ชื่อนี้เคยทำ แต่ยังต่ำกว่า baseline ธัญเดิม 620/84% (ห้ามให้ใครเอ่ยเทียบ baseline ตรงๆ — อนุญาตเฉพาะเสียงคิดภูมิ)
5. ผลดวล = **ชนะ** — แต้ม/สเกลคะแนนดวล **ไม่มีตัวเลข canon: ห้ามแต่งเลขคะแนนดวลทุกชนิด** ผลที่ขึ้นแท็บคือสถานะตัวอักษร: *"ผลการดวล: อยู่ระหว่างตรวจสอบ"* — เลขคาดการณ์บนแท็บ **ไม่ขยับ** ระหว่างอายัด (ระบบแขวนผลไว้ทั้งก้อน)
6. แถบวินัยความร้อน: ยกแรกภูมิโดนต้อนจนแถบ **ขึ้นเหลือง** หนึ่งครั้ง (callback ep002 — เขาจงใจให้เหลืองเพื่อเด่นบนเซนเซอร์) — ห้ามถึงแดง ห้ามแต่งสีระดับใหม่

- **จุดประสงค์**: รับ hook ประกาศดวล (T-09) → เปิดผลจับคู่ → ตั้งเดิมพันของตอน: แพ้ = อันดับ/ใบเหลืองเสี่ยง, ชนะแบบเด่น = แฟ้มยิ่งถูกอ่าน
- **เหตุการณ์ตามลำดับ**:
  1. เช้าวันหนึ่ง โรงอาหาร — ทั้งสถาบันคุยเรื่องเดียว: ดวลสุ่มข้ามชั้นปีก (รับบรรยากาศต่อจากประกาศคืนวันเจ็ด — **ห้ามเขียนว่า "เมื่อกี้/เมื่อคืนนี้เพิ่งประกาศ" ให้เป็น "ประกาศเมื่อคืนวันเจ็ด"**)
  2. ผลจับคู่เด้งกลางวง: *อาร์เดล, ธัญ (ทองแดง 289) — เบรย์, ทาลอส (เงิน 138) · ดวลบ่ายวันห้า* — จาโรอ่านออกเสียงก่อนเจ้าตัว แล้วเงียบไปครึ่งจังหวะ (มุกค้างคอ — สัญญาณว่าคู่นี้ไม่ตลก)
  3. ข้อมูลเบรย์ผ่านปากจาโร (โหมดพ่อค้าข่าว — **ห้ามเปิดราคา/อัตราต่อรองพนันทุกชนิด** ของตอน 9): ปีกเงินตัวจริง บินตามตำราครบ ชั่วโมงซิมมากกว่าภูมิเป็นเท่าตัว
  4. มีราเตือนแบบขั้น 1 — ห่วงแบบยื่นทางเลือก ไม่สั่ง (โทนเดียวกับ voiceExample: *"อย่าฝืนนะ … เธอไม่ต้องรีบพิสูจน์อะไรกับใคร"* — ห้ามลอกประโยคนี้ตรงตัว): แพ้ปีกเงินไม่มีใครว่า อย่าฝืนถ้าคลื่นยังกวนหัว — ภูมิรับปากกลางๆ
  5. ปิดฉากเสียงคิดภูมิ: เขาไล่เลขแบบช่าง — แพ้ = คาดการณ์ร่วง ใบเหลืองรออยู่สิ้นเดือน ("ราวสัปดาห์ครึ่ง") / ชนะ = ทั้งสถาบันจำหน้า แล้วที่ medbay แฟ้มเขาก็ยังเปิดอยู่ — *โจทย์นี้ไม่มีคำตอบในคลังของใครทั้งนั้น* **(แก้รอบหมวด D: "ตึกการแพทย์" → "medbay" ตาม Style Note R1 ข้อ 3 — เสียงคิด/ภาษาปากใช้ medbay)**
- **ตัวละครในฉาก**: ภูมิ (POV), จาโร, มีรา · **ข้อห้ามประจำฉาก**: ทีโบห้ามมีบทพูด (เป็นต้นทางข่าวลือได้) · มีราห้ามทดสอบ/ห้ามถามเจาะ · ห้ามเอ่ยใบเหลือง/350/โซลเป็นคำพูด (เสียงคิดเท่านั้น) · ห้ามเบรย์เข้าฉาก
- **ตัวเลข canon**: 289 (ทางการ) · 138 (เบรย์) · กำหนดดวลบ่ายวันห้า
- **อารมณ์-จังหวะ**: เสียงอึงทั้งโรงอาหารตัดกับความเงียบของภูมิ — จบที่การคำนวณเย็นๆ

### ฉาก 2 — "การบ้านของช่าง" (~400 คำ)
- **จุดประสงค์**: ปูเหตุผลกลไกของ silent running ให้ครบ *ก่อน* ดวล (กันชนะแบบปาฏิหาริย์) + เก็บบันไดคะแนนคาบสองคาบ
- **เหตุการณ์ตามลำดับ**:
  1. คาบวันสาม/วันสี่ ห้องซิม B เขียนรวบเป็นมอนทาจสั้น: ลายใหม่นิ่งขึ้นต่อเนื่อง — วันสาม ~555 (11/20), วันสี่ ~560 (10/20 — **แตะครึ่งบนครั้งแรก** เขียนเงียบๆ ≤3 ประโยค ห้ามใครแสดงความยินดี ภูมิเองยังไม่ทันรู้สึก เพราะหัวเขาอยู่ที่วันห้า)
  2. การบ้านกลางคืนในห้องเดี่ยว: ภูมิไล่กติกาดวลบนแท็บแบบคนอ่านเอกสารทุกบรรทัด (นิสัย canon) — พบช่อง: กติกาตัดสินที่ "การล็อกยิงสำเร็จ" ไม่ได้บังคับว่ายานต้องติดเครื่องตลอด
  3. เสียงคิดถึงคลังในหัว (หมวด A): หนังสือเรือดำน้ำสงครามเย็นคั่นครึ่งเล่มบนหัวเตียงยุคเปล — เรือที่ช้ากว่า เงียบกว่า ชนะเรือที่เร็วกว่าได้เพราะ *เลือกจะหายไปจากหูของศัตรู* · ผูกกับกฎโลกนี้: การรบคือเกมความร้อน เซนเซอร์ตามลายความร้อน — เครื่องที่ดับคือเครื่องที่มองไม่เห็น
  4. ต้นทุนของแผน (ต้องเขียนชัด — ห้ามให้แผนดูฟรี): ดับเครื่องทั้งลำ = เสียการขยับ ถ้าเบรย์ยิงสุ่มถูกมุม เขาหลบไม่ได้เลย และค่าซิงก์จะฟ้องทุกความลังเล — *แผนนี้ใช้ได้ครั้งเดียวกับคนที่ไม่เคยเห็นมัน*
  5. ปิดฉาก: เขาจดแผนลงสมุดเล่มใหม่ในหัว (ภาพ canon ep001–003) — หมวดใหม่: "วิธีแพ้ให้ถูกจังหวะ ก่อนจะชนะ"
- **ตัวละครในฉาก**: ภูมิคนเดียว (เพื่อนร่วมคาบนิรนามฉากหลัง) · **ข้อห้ามประจำฉาก**: คาร์เวอร์ห้ามมีบทพูด/ห้ามทักเรื่องลาย (เก็บไว้ฉาก 5) · ห้ามแฟลชแบ็กยุคเปลเต็มฉาก (ภาพหนังสือ = เสียงคิด ไม่ใช่แฟลชแบ็ก) · ห้ามซ้อมท่า silent running ในคาบ (ความลับของแผนต้องสดถึงวันห้า)
- **ตัวเลข canon**: ~555 (11/20) · ~560 (10/20)
- **อารมณ์-จังหวะ**: มอนทาจงานช่างเรียบๆ → ค่ำคืนวางแผนที่นิ่งแบบคนเปิดตำราเก่า — จบด้วยความตึงเบาๆ

### ฉาก 3 — "คำตอบนอกคลัง" (~1,000 คำ · แกนตอน — ฉากใหญ่สุด)
- **จุดประสงค์**: beat หลักของ saga-plan ตอน 5 — ชนะปีกเงินด้วย silent running ต่อหน้าทั้งสถาบัน · โชว์ธีมข้อ 2 ในสนามที่วัดได้ พร้อมราคาที่งอกทันทีท้ายฉาก
- **เหตุการณ์ตามลำดับ**:
  1. บ่ายวันห้า ตึกซิม — บรรยากาศงานพิเศษ: คู่ดวลไล่ขึ้นจอใหญ่โถงทีละคู่ นักเรียนอัดแน่น (มีรา/จาโรอยู่ในโถง — **ไม่มีบทพูดทั้งคู่ในฉากนี้**) ภูมิเข้าแคปซูล เบรย์ทักก่อนเข้าหนึ่งประโยคแบบนักกีฬา (บทพูดได้ 1–2 ประโยค เช่นทำนอง *"บินให้เต็มที่นะ ฉันดูเทปซ้อมนายแล้ว — นายน่าสนใจ"* — เขียนใหม่ได้ในโทนนี้)
  2. ยกแรก — ตำราทำงาน: เบรย์เหนือกว่าทุกมิติ ต้อนภูมิเข้ามุม แถบวินัยความร้อนภูมิขึ้นเหลืองจากการหนี (callback ep002) ภูมิเสียเปรียบชัดบนจอ — **ต้องให้ผู้อ่านเชื่อก่อนว่าบินตรงๆ แพ้แน่** (ห้ามย่อช่วงนี้เหลือประโยคเดียว)
  3. จุดสลับเกม: ภูมิเร่งเครื่องหลักเต็มคันหนีเข้าเขตกลุ่มซากจำลอง — จงใจให้เงาความร้อนเด่นที่สุดบนเซนเซอร์เบรย์ (เหตุผลกลไกในเสียงคิด: อยากให้เหยื่อมองเห็นชัดๆ ก่อนหายตัว) แล้ว **ดับเครื่องยนต์หลัก ตัดระบบขับเคลื่อนทั้งหมด** — เหลือเครื่องวัดชั้นกลไกแค่สามตัว: เข็มทิศเฉื่อย มาตรความเร่งสองชุด เซ็นเซอร์อุณหภูมิเครื่องยนต์ดิบ (อ่านการเย็นตัวของเครื่อง *ตัวเอง* เท่านั้น) — ลอยเฉื่อยไปกับซาก **(แก้รอบหมวด D: ตัด "มาตรความดัน" ออกจากฉากนี้ตามคำเคาะบก. — ฉาก 3 อนุญาตสามตัวนี้เท่านั้น)**
  4. ช่วงเงียบ (หัวใจฉาก — ให้พื้นที่เท่ากับช่วง "นิ่งแบบสมาธิช่าง" ของ ep004 ฉาก 3): ความมืดครึ่งจอ เสียงหายใจตัวเอง ความร้อนยานค่อยๆ ตก — เสียงคิดภูมิหนึ่งวาบถึงเรือดำน้ำยุคเก่า: ลูกเรือทั้งลำนั่งเงียบใต้ทะเล ฟังเสียงใบจักรศัตรูผ่านหัว — *พันสองร้อยปีผ่านไป เกมนี้ยังกติกาเดิม* · ความเสี่ยงต้องเต้นอยู่บนหน้ากระดาษ: เขาขยับไม่ได้ ถ้าโดนตอนนี้คือจบ
  5. เบรย์ทำตามตำรากวาดพื้นที่ (เขียนผ่านสิ่งที่ภูมิ *คำนวณ* — dead reckoning ล้วน: ตำแหน่ง/จังหวะการกวาดที่เขาท่องจากแพตเทิร์นตำราปีหนึ่ง + นาฬิกานับในหัว + ตำแหน่งตัวเองจากเข็มทิศเฉื่อย/มาตรความเร่ง — **ห้ามมีเครื่องวัดใดตรวจจับยานเบรย์ได้ระหว่างดับเครื่อง**: ยานที่ตัดระบบไม่มีเซนเซอร์ active — นี่คือหัวใจความเสี่ยงของท่า ไม่ใช่จุดอ่อนของแผน · ไม่ใช่มุมมองเบรย์): แพตเทิร์นการกวาดสม่ำเสมอเหมือนลอกจากหน้าหนังสือ — ภูมิรอจังหวะที่เส้นทางกวาดพาเบรย์ผ่านจุดอับ → จุดตัวขับดันรอง (เย็น เงียบ) ปรับมุมทีละนิด → เครื่องหลักติดระยะประชิด — ล็อกยิงสำเร็จ จบดวล
  6. ออกจากแคปซูล: โถงทั้งตึก **เงียบก่อน แล้วค่อยระเบิด** (จังหวะเดียวกับกระดานผล ep004 แต่กลับด้าน — คราวนี้เสียงดังใส่เขาตรงๆ) — จอใหญ่ขึ้นค่าซิงก์ *เฉลี่ย 75% (แกว่ง 71–78)* — และบรรทัดผลขึ้นค้างว่า **"ผลการดวล: อยู่ระหว่างตรวจสอบ"** ก่อนใครทันได้ฉลอง
- **ตัวละครในฉาก**: ภูมิ (POV), ทาลอส เบรย์ (บทพูด ≤2 ประโยค), เสียงประกาศระบบ, มีรา/จาโร/เพื่อนร่วมรุ่นนิรนาม (ฉากหลังไม่มีบทพูด) · **ข้อห้ามประจำฉาก**: **เคย์ดาห้ามปรากฏทุกรูปแบบ** (เธอดูเทปนอกฉาก — ของตอน 8) · ห้ามเปิดมุมมอง/เสียงคิดเบรย์ · ห้ามเครื่องวัดนอกลิสต์หมวด C · ห้ามฝูง/สัญญาณจริง/ลางใดๆ · ห้ามแฟลชแบ็กธัญ · ห้ามภูมิหลุดประโยคเต็มภาษายุคเปล
- **ตัวเลข canon**: 75% (71–78) · แถบเหลืองหนึ่งครั้ง · ห้ามเลขคะแนนดวล
- **อารมณ์-จังหวะ**: เปิดอึกทึก → ยกแรกหายใจไม่ทัน → ดับเครื่อง: โลกเงียบ ประโยคสั้นลงเรื่อยๆ → ระเบิดกลับที่โถง → ตัดจบเย็นๆ ที่คำว่า "ตรวจสอบ"

### ฉาก 4 — "ไม่มีในคลัง" (~450 คำ)
- **จุดประสงค์**: เก็บต้นทุนตามกฎ anti-เก่งเวอร์ — ข้อกล่าวหา + อายัดผล · ตั้งน้ำหนักให้ hook ฉาก 5
- **เหตุการณ์ตามลำดับ**:
  1. เย็นวันห้า — กรรมการสองนายเรียกภูมิจากโถง: คำชี้แจงข้อสังเกตอ่านจากแท็บ (บทพูดกรรมการรวม ≤4 ประโยค): การดับระบบขับเคลื่อนทั้งลำกลางดวลตีความได้สองทาง — ยานขัดข้อง (ผลโมฆะ) หรือการแทรกแซงซิม (โกง) — เพราะ *รูปแบบนี้ไม่ปรากฏในคลังยุทธวิธีของสถาบัน* → ผลเมริตอายัดรอสอบสวน
  2. ปฏิกิริยาภูมิ: ไม่เถียง — เสียงคิดแปลเป็นภาษาคนของเขา: *ระบบไม่มีช่องให้กรอกคำว่า "ตำราเก่ากว่าคลัง" — เอกสารผิดช่อง เรื่องเลยกลายเป็นความผิด* (โทนตลกร้ายคนโดนระบบดองใบแจ้งซ่อม — ห้ามฟูมฟาย ห้ามโวยใส่กรรมการ)
  3. เบรย์เดินมาหาก่อนแยกย้าย — หนึ่งประโยคสุดท้ายของเขา (จบเพดานบทพูด): พยักหน้าแบบนักบินต่อนักบิน ทำนอง *"ขัดข้องบ้าอะไร — นายล่อให้ฉันเดินเข้าไปเอง"* แล้วเดินจากไป — คนแพ้กลับเป็นพยานฝ่ายเดียวกัน (จุดมนุษย์ของฉาก)
  4. จาโรเดือดแทน อยากไปเถียงกรรมการ — ภูมิห้าม (เสียงต่ำของจาโรไม่ต้องใช้ — เก็บสวิตช์นั้นไว้เรื่องใหญ่กว่านี้) · มีราอยู่ขอบฉาก สบตาเขาครั้งเดียว ไม่พูด (ผู้เล่าห้ามเปิดความคิดเธอ)
  5. ปิดฉากเสียงคิด: สิ่งที่เขากลัวไม่ใช่ข้อหา — แต่คือคำว่า "สอบสวน" แปลว่ามีคนจะเปิดทุกอย่างของเขาดูอีกรอบ ในเดือนที่หมอคนหนึ่งอ่านแฟ้มเขาค้างไว้อยู่แล้ว
- **ตัวละครในฉาก**: ภูมิ (POV), กรรมการนิรนามสองนาย, เบรย์ (1 ประโยค), จาโร, มีรา (ไม่มีบทพูด) · **ข้อห้ามประจำฉาก**: คาร์เวอร์ยังห้ามเข้าฉาก (เก็บการปรากฏตัวให้ฉาก 5) · ห้ามตัดสิทธิ์/ลงโทษใดๆ เกิดขึ้นจริงในฉากนี้ (แค่อายัดรอสอบสวน) · ห้ามใครเอ่ยชื่อโซล · จาโรห้ามพูดเรื่องพนัน
- **ตัวเลข canon**: สถานะ "อยู่ระหว่างตรวจสอบ" — เลขคาดการณ์ไม่ขยับ
- **อารมณ์-จังหวะ**: ชัยชนะที่ถูกริบกลับกลางอากาศ — อึน เย็น มีมุกแห้งหนึ่งจุด จบที่ลางหนัก

### ฉาก 5 — "เหลือสองคน" (~500 คำ · ปิดตอน + hook)
- **จุดประสงค์**: วาง hook ปิดตอนตาม beat: คาร์เวอร์ปิดห้องสอบสวน + ประโยค canon — เปิดประตูเข้าตอน 6 ("ครูกับช่าง")
- **เหตุการณ์ตามลำดับ**:
  1. ค่ำวันห้า ห้องสอบสวนข้างห้องควบคุมตึกซิม (กายภาพตามหมวด 4 ข้อ 3 — ห้ามเติม): กรรมการสองนาย + คาร์เวอร์ นั่งดูเทปดวลวนบนจอผนัง — เทปหยุดซ้ำตรงวินาทีที่เครื่องทั้งลำดับ
  2. กรรมการไล่คำถามเชิงหาเรื่องผิด (ขัดข้องหรือแทรกแซง) — ภูมิตอบสั้นเรียบแบบช่างให้การ ("ผมดับเครื่องเองครับ ตามกติกาไม่มีข้อห้าม") — ยิ่งตอบนิ่ง ห้องยิ่งอึดอัด
  3. คาร์เวอร์นั่งเงียบมาทั้งฉาก เคาะนิ้วโลหะลงโต๊ะหนึ่งครั้ง — แล้วพูดสั้นๆ กับกรรมการว่าขอคุยกับนักเรียนตามลำพังในฐานะครูประจำสาย (อำนาจครูประจำสาย — ไม่ต้องอธิบายระเบียบเพิ่ม) — กรรมการออก ประตูปิด
  4. ความเงียบหนึ่งจังหวะยาว — คาร์เวอร์ไม่เปิดแฟ้ม ไม่ดูจอ มองภูมิตรงๆ ครั้งแรก
  5. **ประโยคปิดตอน (canon — ใช้ตรงตัว):** *"บอกครูมาซิ ไอ้ท่าเมื่อกี้ — นายไปเอามาจากไหน"* — **ตัดจบทันทีที่ประโยคนี้ ห้ามมีปฏิกิริยา/คำตอบ/เสียงคิดภูมิต่อท้ายแม้แต่ประโยคเดียว** (คำตอบคือฉากเปิด ep006)
- **ตัวละครในฉาก**: ภูมิ (POV), คาร์เวอร์, กรรมการสองนาย (ออกกลางฉาก) · **ข้อห้ามประจำฉาก**: คาร์เวอร์ห้ามเอ่ยเฮลิออน/เรื่องส่วนตัว/คำว่า "เพลง" ทุกกรณี (ของตอน 6 และตอน 20) · ห้ามเซ็น/ตัดสินผลใดๆ ในตอนนี้ · ห้ามภูมิเริ่มเล่าเรื่องบันทึกยุคเปล (ของ ep006) · โซล/เคย์ดา/เรย์ฮานห้ามถูกเอ่ยชื่อ
- **ตัวเลข canon**: ไม่มีเลขใหม่ — ห้ามสรุปเลขอันดับใดๆ ในฉากนี้
- **อารมณ์-จังหวะ**: ห้องแคบ เทปวนเงียบๆ คำถามราชการ → คนอื่นออกหมด อุณหภูมิเปลี่ยน — จบแบบ cliff ที่คำถามของครู
