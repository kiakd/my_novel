# Canon Q&A — "Star Academy"

## รอบที่ 1 — คำถามก่อนเขียนตอน 1–3 (แพรวา → วิน, 10 มิ.ย. 2026)

ทุกคำตอบถูกผนวกเข้าไฟล์หลักแล้ว (ระบุตำแหน่งท้ายข้อ) — แท็กในไฟล์หลัก: **(QA-1)**

**1. ครอบครัวภูมิ** — พ่อแม่แยกทางตอนเขา 6 ขวบ แม่มีครอบครัวใหม่ (ติดต่อปีละครั้ง) พ่อเสียจากอุบัติเหตุหน้างานก่อสร้างตอนเขา 15 (รากของ "ไม่ทิ้งคนหน้างาน") · คนเลี้ยง = **ลุงทอง** เจ้าของโรงกลึง ยังมีชีวิต อายุ 61 — คนเดียวที่รอเขาอยู่ · ไม่มีแฟน (เลิกเพราะกะดึก ~2 ปีก่อน) → โทน: มีคนรอหนึ่งคน เจ็บจริงแต่ไม่ฟูมฟาย → `characters.md 1.1`

**2. รุ่นน้อง+สาเหตุไฟ** — รุ่นน้อง = **ก้อง (Kong)** ชาย 19 นศ.ฝึกงาน ปวส.ช่างอากาศยาน พูดเร็ว ถามเยอะ เรียก "พี่ภูมิ" ติดปาก · สาเหตุไฟ canon: ไฟฟ้าลัดวงจรสายพ่วงชั่วคราวของพัดลมระบายห้องเก็บวัสดุไวไฟ — จุดที่ภูมิเคยเขียนใบแจ้งซ่อมแล้วโดนดอง (irony จงใจ — อ้างย้อนได้ทั้งเรื่อง) → `characters.md 1.1`

**3. ไทม์ไลน์** — ธัญหมดสติ 4 วัน · ภูมิตื่นเย็น "วันเจ็ด" ตรงรอบประกาศ (312 = ทางการ) · 327 ตอน 2 = **อันดับคาดการณ์เรียลไทม์บนแท็บนักเรียน** ไม่ใช่ประกาศคนละสัปดาห์ — กระดานทางการยังอัปเดตสิ้นสัปดาห์ตาม world-bible 3.2 (กฎ "สองตัวเลข" ตั้งใหม่แล้ว) · ตอน 1–3 รวม ≈ 9 วันนับจากคืนซิงก์ช็อก → `world-bible.md 3.2` + `saga-plan.md หมายเหตุก่อนตอน 1`

**4. เวอร์ชันสาธารณะซิงก์ช็อก** — ธัญหมดสติคาแคปซูลซิมเดี่ยวชั่วโมงเสริมกลางคืน โซน C · คนพบ = เจ้าหน้าที่เวรซิม (ระบบเตือนสัญญาณชีพ — ไม่มีนักเรียนเห็น) · แพร่ทั่วรุ่นเป็น cautionary tale "ฝืนซิมช่วงพายุ" แต่เป็นข่าวเล็ก — ปฏิกิริยาตอน 2: มองแวบ/ถามแห้งๆ/มุก "ผีพายุ" จาโรล้อแรงสุดเพื่อกลบห่วง → `characters.md 1.2`

**5. หมอ medbay** — คนเซ็นปล่อย = **นพ.คาลิม ออร์โซ** แพทย์เวรทั่วไป (ทำตามแฟ้มที่ฝ่ายประสาทปิดมา ไม่รู้อะไร) · โซลปรากฏแวบเดียวเงียบๆ — ยืนอ่านแท็บหลังกระจกห้องสังเกตการณ์ สบตาครึ่งวินาทีแล้วเดินออก · **โซลห้ามมีบทพูด on-page จนตอน 8** (ฉากตรวจติดตาม) — คุมจังหวะ "เงาที่ผู้อ่านต้องอ่านผิด" → `characters.md 6`

**6. พยาบาล+มือสั่น** — (ก) **พยาบาลอีดา เรนน์ (Ida Renn)** หญิง 34 (ข) คำตอบ canon มีแล้ว — แม่ธัญป่วยเรื้อรังนอน medbay นี้ ~2 ปีก่อนเสีย ธัญวัยเด็กเฝ้าทุกวัน → กลิ่นน้ำยาฆ่าเชื้อ = ความทรงจำเชิงอารมณ์ฝังร่าง ภูมิเข้าไม่ถึง มือจึงสั่นโดยไม่รู้ที่มา · **ไม่เกี่ยวกับห้องแล็บเสาอากาศ — อย่าผูก** · บนหน้ากระดาษ 3 ตอนแรก: เขียนกำกวมสนิท เฉลยเชิงอารมณ์ช่วงตอน 11–20 ตาม outline → `characters.md 1.2, 6`

**7. โน้ต** — ลิ้นชักข้างเตียง **medbay** · เส้นทาง: ธัญเขียนล่วงหน้า พับใส่แจ็กเก็ตนักเรียน → จนท. medbay เก็บของส่วนตัวใส่ถาดมาตรฐานไว้ลิ้นชักตามระเบียบ — ไม่มีใครอ่านเพราะดูเป็นของจุกจิก · วัสดุ: กระดาษจริงฉีกจากสมุดของแม่ธัญ · กฎโลก: แผ่นเขียนฟิล์ม = ปกติ, กระดาษจริง = ฟุ่มเฟือย และลายมือบนกระดาษ = สัญญาณ "ไม่ไว้ใจเครือข่าย" ที่คนยุคนี้เข้าใจตรงกัน → `characters.md 1.2` + `world-bible.md 6`

**8. ที่พักธัญ** — **ห้องเดี่ยว** (single pod) — ปี 1 เคยอยู่ห้องคู่กับจาโร ธัญขอย้ายเมื่อ ~18 เดือนก่อน อ้าง "ต้องการสมาธิ" (เบาะแสเงียบของหลุม 18 เดือน — วางได้แบบไม่ชี้) · จาโรติดนิสัยโผล่มาไม่เคาะ · รองรับละเมอ/เก็บโน้ต/hook ตอน 6 ครบ → `characters.md 1.2`

**9. พ่อธัญ** — **รูเวน อาร์เดล (Ruven Ardell)** ชาย 47 กะหมุนเวียนวงแหวนนอก (กะ 10 วันสลับ) · ห่างเหินแบบไม่ทะเลาะ — หลังแม่เสียพ่อหนีเข้างาน คุยกันเป็นข้อความเดือนละครั้ง · ตอน 1: พ่อ **มาแล้ว** — เฝ้าคืนที่สองช่วงธัญยังไม่ฟื้น (ลาได้คืนเดียว) แล้วกลับกะ เหลือข้อความ "ฟื้นแล้วบอกด้วย ค่ารักษาพ่อจัดการแล้ว" + กระป๋องโปรตีนจริง — ปิดรูตรรกะ "พ่อไม่โผล่" · ตัวจริงเข้าฉากครั้งแรกช่วงตอน 11–20 (วินกำหนดจุด) · หมายเหตุ: ธัญแก้ผู้ติดต่อฉุกเฉินจากพ่อเป็นมีราตั้งแต่ปีก่อน → `characters.md 1.2, 6`

**10. เคาะแก้ว** — (ก) **ไม่ขัดกัน — คนละครึ่งของสัญญะเดียว**: คนยื่นเคาะสองครั้ง ("ฉันอยู่นี่") → คนรับเคาะตอบสองครั้งก่อนดื่ม ("ฉันก็อยู่") — ทั้ง outline และ characters ถูกทั้งคู่ (ข) ธัญจริงต้อง **เคาะตอบสองครั้ง** — ภูมิรับไปดื่มเฉยๆ = จุดพลาด (ค) ที่มาเปิดให้นักเขียนรู้ (ห้ามเฉลย on-page จนจุดที่ outline ระบุ): ภาษาเคาะโลหะของช่างสถานีที่ธัญได้จากพ่อ สอนมีราที่จุดชมดาวชั้นซ่อมบำรุงเดตแรก — subtext มีรา: ทุกครั้งที่เคาะแล้วเงียบ = ความเงียบที่เธอนับ → `characters.md 2`

**11. ชุดรายละเอียดคู่รัก** — ธัญเรียกมีรา **"มิ" (Mi)** / มีราเรียกธัญ **"อาร์" (Ar)** (จากอาร์เดล — มุกครูขานชื่อผิดปี 1) · ร้านประจำ = **"หม้อแรงดัน" (The Pressure Pot)** แผงบะหมี่น้ำโปรตีนถัง ตลาดเขตท่าสาม ย่านพลเรือน · ของโปรดธัญ = บะหมี่ไอน้ำสูตรเผ็ดสอง **ไม่ใส่สาหร่ายถัง** — ภูมิสั่งผิดเป็นสูตรกลางใส่สาหร่ายเพิ่ม แล้วกินหมด (มีราเห็นด้วยตา) · เครื่องดื่ม: มีรา = **ชาดำรมควันไม้ใบจริง** (กลิ่นประจำตัว — ปลูกตั้งแต่ตอน 3 รับแฟลชแบ็กตอน 7) / ธัญ = **ช็อกมอลต์เย็น** (ภูมิเผลอสั่งกาแฟดำ — เมล็ดเอ๊ะสำรอง) → `characters.md 2`

**12. เน็กซ์ลิงก์ vs ความลับ** — กฎตายตัว: เน็กซ์ลิงก์อ่านเฉพาะ **motor intent** — ระบบ/ครูเห็นแค่ "ลายมือการบิน + ค่าซิงก์ %" ไม่สแกนเนื้อความจำ (อย่างนั้นต้องเครื่องเลซประสาท medbay + คำสั่งแพทย์) · เหตุที่ไม่โดนธงอัตโนมัติ: **ธงปรับเทียบ 90 วัน** หลังเหตุการแพทย์ (โซลเซ็น) — ระบบตีความความเพี้ยนทั้งหมดเป็น "การฟื้นตัว" · ผลใช้เขียน: ความกลัวรายฉากซิม = ต่ำ (เครื่องไม่เห็น) แต่เส้นตายเงียบ = ลายใหม่ต้องนิ่งก่อนธงหมด 90 วัน + กลัวการถูกสั่งสแกนละเอียด/นัดตรวจโซล → `world-bible.md 3.3`

**13. สเปคซิมตอน 2** — แคปซูลเดี่ยวจำลองชั้นเข็ม (ใช่) · 20 แคปซูล/ห้อง ~20 คน/คาบ คาบละ 2 ชม. (ทองแดง = 4 คาบ/สัปดาห์) · โจทย์: gate run / สกัดเป้าเฉื่อย / รักษาขบวน · หน่วยวัด: **คะแนนซิม 0–1000/รอบ** + ค่าซิงก์ % — baseline ธัญเดิม ~620, ตอน 2 ภูมิ ~410 (บ๊วยคาบ) · ท้ายคาบคะแนนทุกคนขึ้น "กระดานคาบ" — **เห็นกันหมด** → `world-bible.md 3.4`

**14. ภาษา** — พูด/ฟังคอนคอร์ดคล่องแทบอัตโนมัติ (ทักษะกึ่ง muscle memory ของร่าง — ที่ช้าหนึ่งจังหวะคือเนื้อหาวิชาการ ไม่ใช่ตัวภาษา) · ในหัวคิดเป็นภาษายุคเปล · เพดานพิรุธ 3 ตอนแรก: สำนวนแปลตรงตัวแปลกๆ + คำอุทานสั้น (คนฟังไม่จำแนกว่าเป็นภาษา) — **ห้ามหลุดประโยคเต็มต่อหน้าคนอื่นก่อนกลาง arc 1** · ละเมอในห้องเดี่ยวใช้ได้ → `world-bible.md 6`

**15. เกณฑ์ 350** — ไม่ใช่กฎถาวรสถาบัน — เป็น **"ใบเหลือง" (Yellow Slip)**: กลไกคุมประพฤติวิชาการอัตโนมัติที่นักเรียนรู้จักทั่วกัน แต่ตัวเลขเกณฑ์เป็นรายเคส — 350 คือเกณฑ์เฉพาะของธัญหลังซิงก์ช็อก+อันดับร่วง (โทษ: ลดชั่วโมงซิมหนึ่งชั้นปีกจนกว่าจะฟื้น) · บทพูดอ้าง "ใบเหลือง" แบบกฎที่รู้กันได้ ห้ามอ้าง 350 เป็นกฎสากล → `world-bible.md 3.2`

**16. อำนาจตั้งชื่อย่อย** — เคาะ workflow: ตัวละคร ≤2 ฉาก / สถานที่ย่อย / ชื่อวิชา-รหัสคาบ → **แพรวาตั้งเองได้เลย** (ไทย+EN, ไม่ชน canon, ไม่ผูกสามเส้นปิด) แล้วแนบลิสต์ท้ายต้นฉบับทุกตอน — วินไม่ทักภายใน 1 รอบรีวิว = เข้า canon · เกิน 2 ฉาก = template เดิม · ชื่อที่วินตั้งรอบนี้: อีดา เรนน์, คาลิม ออร์โซ, ดาเลีย เวนน์, ก้อง, ลุงทอง, รูเวน อาร์เดล, ร้านหม้อแรงดัน, ตลาดเขตท่าสาม, HN-204, ช็อกมอลต์ → `characters.md 6`

**17. วิชาตอน 2 + ตารางเรียน** — วิชาที่ตอบช้า = **กลศาสตร์วงโคจรประยุกต์ (HN-204)** ครูเจ้าของคาบ = อ.ดาเลีย เวนน์ — จุดเด่นของฉาก: ภูมิตอบช้าแต่อธิบาย *ทำไม* ได้ (คนเมมเพล็กซ์ทำตามขั้นตอนแต่ไม่รู้ราก — ครูเอ๊ะถูกทิศ) · โครงตารางปี 2: **เช้า = ทฤษฎีรวมข้ามสาย (สามสายเรียนร่วม) / บ่าย = บล็อกสายแยก** → จาโร/มีราเข้าฉากเช้า+โรงอาหารได้ทุกวัน คาบซิมเป็น Helm ล้วน → `world-bible.md 3.5`

**18. สิทธิ์ออกเขต + ความสัมพันธ์เปิดเผย** — นักเรียนทุกชั้นปีกออกย่านพลเรือนได้หลังคาบ/วันว่าง (บัตรผ่านเขต เคอร์ฟิว 23:00) — สิทธิ์ใน 3.2 คือทรัพยากรฝึก คนละเรื่อง · medbay เยี่ยมถึง 22:00 แต่ "ผู้ติดต่อฉุกเฉิน" เฝ้าค้างได้ระหว่างผู้ป่วยไม่ฟื้น — มีราคือผู้ติดต่อฉุกเฉินของธัญ (ดูข้อ 9) · คู่รักนักเรียนไม่ผิดระเบียบ และธัญ-มีราเป็นที่รู้ทั่วรุ่น ("สาวปีกทองกับแฟนอันดับ 312" — มุกแซวที่ใช้เป็นแรงกดในตอน 3 ได้) → `world-bible.md 3.5`

**สรุปไฟล์ที่อัปเดตรอบนี้:** `world-bible.md` (3.2 สองตัวเลข+ใบเหลือง, 3.3 เน็กซ์ลิงก์+ธง 90 วัน, 3.4 คาบซิม, 3.5 ตารางเรียน/ออกเขต, หมวด 6 ภาษา+กระดาษ) · `characters.md` (1.1 ครอบครัว+ก้อง+สาเหตุไฟ, 1.2 เวอร์ชันสาธารณะ/พ่อ/ห้องเดี่ยว/มือสั่น/โน้ต/ผู้ติดต่อฉุกเฉิน, 2 ชุดรายละเอียดคู่รัก, หมวด 6 ใหม่ ทะเบียนตัวละครย่อย+workflow) · `saga-plan.md` (หมายเหตุไทม์ไลน์ตอน 1–3)

## รอบที่ 2 — คำถามก่อนเขียนตอน 1–3 ชุดสอง (แพรวา → วิน, 10 มิ.ย. 2026)

ทุกคำตอบถูกผนวกเข้าไฟล์หลักแล้ว — แท็กในไฟล์หลัก: **(QA-2)**

**1. จังหวะใบเหลืองตอน 3** — ออก **เช้าวันสี่ (ฉากเปิดตอน 3)** ไม่ใช่พร้อมประกาศเย็นวันเจ็ด: ใบเหลืองออกอัตโนมัติเมื่อทริกเกอร์ครบสอง — กลับจากเหตุการแพทย์ + อันดับคาดการณ์ร่วงเกินเกณฑ์ (คาบซิมตอน 2 ที่ทำ 410 บ๊วยคาบ = ทริกเกอร์ตัวที่สอง) — เด้งขึ้นแท็บเจ้าตัวเป็นหนังสือทางการ · เกณฑ์รายเคสตั้งจากอันดับทางการก่อนเหตุ + ระยะกันชน (312 + กันชน ≈ 350) · ประกาศเย็นวันเจ็ดแค่ *ยืนยัน* เลขทางการ 327 → ลำดับเหตุ-ผลของ beat "แรงกด 350 ขับการรื้อวิธีบินตั้งแต่ต้นตอน" ถูกต้อง ไม่กลับด้าน → `world-bible.md 3.2` + `saga-plan.md หมายเหตุตอน 1–3`

**2. ภูมิรู้เรื่องธง 90 วัน — รู้** — เอกสารปล่อยตัว (ออร์โซเซ็น) แจ้งตามระเบียบ: สถานะธง + **วันหมดอายุ** + นัดตรวจติดตามฝ่ายประสาท + บรรทัด "ความเพี้ยนของผลซิมจะถูกตีความเป็นการฟื้นตัว ไม่ธงอัตโนมัติ" (beat อนุญาต: เขาอ่านเอกสารละเอียดด้วยนิสัยคนเคยโดนใบแจ้งซ่อมถูกดอง) · สิ่งที่ *ไม่รู้*: ใครเซ็นธง / ผลสแกนจริง / มีคนปกป้องอยู่ → โทน monologue ตอน 2–3 = บินใน "ช่องผ่อนผันราชการที่นับถอยหลัง" ไม่ใช่ความมืดสนิท · ครูเห็นแค่ badge "ปรับเทียบหลังเหตุการแพทย์" — เหตุที่คาร์เวอร์สงสัยแบบครูไม่ใช่ตำรวจ → `world-bible.md 3.3`

**3. แหล่งข่าวจาโร** — สายคือ **เนล ทาร์ก (Nel Tarq)** เสมียนหน่วยทะเบียนการแพทย์ ชาย 28 ลูกหนี้ชั่วโมงซิมของจาโร: การเปิดแฟ้มซ้ำทิ้ง log ธุรการบรรทัดเดียว ("ARDELL T. — เปิดแฟ้มซ้ำ / ฝ่ายประสาท / SOL I.") ทาร์กเอามาจ่ายหนี้เป็นข่าวซุบซิบ · **โซลจงใจใช้ช่องทางทางการ** — หมอเจ้าของเคสเปิดแฟ้มซ้ำใต้ธงติดตาม = ปกติสนิท การแอบเข้าไม่ทิ้ง log ต่างหากที่เป็นพิรุธ (ยอมแลกรอยเล็กที่อธิบายได้ — ไม่หละหลวม ไม่ใช่ปล่อยข่าว แค่คุมเสมียนปากโปร่งไม่ได้) · เพดานบทกระซิบ: จาโรรู้แค่ "แฟ้มถูกดึงดูอีกรอบ + ชื่อหมอ" — ไม่แตะเนื้อหาแฟ้ม/เสาอากาศ → `characters.md 3.1, 6`

**4. ธัญรู้จักชื่อโซลไหม — ไม่รู้จัก** — โซลย้ายมาเวสเปอร์ **ปีสหพันธ์ 411 (~14 เดือนก่อนคืนซิงก์ช็อก)** ตามหลังอาสาสมัครชุดสุดท้ายเข้าโครงการ — อยู่ *ในหลุม 18 เดือน* ทั้งหมด → ความทรงจำที่ภูมิเข้าถึงได้ไม่มีชื่อ "โซล" · ปฏิกิริยาต่อ hook ตอน 3 = ความกลัวเชิงระบบล้วน ไม่มีประกายจำได้ — และห้ามให้เขาสรุปว่า "ชื่อนี้อยู่ในหลุม" ก่อนตอน 7–8 → `characters.md 3.4`

**5. ตัวเลขอ้างอิง** — (ก) ค่าซิงก์: ผ่านขั้นต่ำคาบ 70% · ปกติปี 2 "เข้ามือ" 78–88% (ดารา 93%+) · ธัญเดิม ~84% นิ่ง · ภูมิตอน 2 เฉลี่ย ~63% **แกว่ง 52–71% ในคาบเดียว** (= "ซิงก์แกว่ง" ที่คาร์เวอร์เห็น) · ตอน 3: ~68–73% แถบแกว่งแคบลงชัด (ข) คะแนนซิมตอน 3: คาบวันสี่ ~450 → คาบวันหก ~510 — ดีขึ้นหยาบๆ แต่ยังต่ำกว่า baseline 620 และมัธยฐานรุ่น → คาดการณ์แกว่ง 327–331 แล้วทางการยืนยัน 327 ไม่ขัดกัน → `world-bible.md 3.4`

**6. วงรับรู้ใบเหลือง** — ข้อมูลรายคน: เห็นเฉพาะแท็บเจ้าตัว + จอครูประจำสาย (คาร์เวอร์) + ทะเบียน/แฟ้มแพทย์ (โซล) — ไม่ขึ้นกระดานสาธารณะ · **canon ตอน 1–10: ภูมิไม่บอกใคร** — มีรา/จาโรไม่รู้ทั้งใบเหลืองและเลข 350 (จุดรู้ของมีรา วินกำหนดใน outline 11–20) → ฉากหม้อแรงดัน: มุก "สาวปีกทองกับแฟนอันดับ 312" ทำงานเป็น dramatic irony — น้ำหนักกดบนภูมิ (และผู้อ่าน) คนเดียว มีราอ่านได้แค่ "เขาเงียบผิดปกติ" → เข้ารายการเอ๊ะของเธอ → `world-bible.md 3.2` + `saga-plan.md`

**7. ชื่อย่อยยุคเปล — อนุมัติ** — ขยาย workflow ข้อ 16 ครอบคลุมชื่อย่อยยุคเปล (สายการบิน/โรงซ่อม/โรงกลึงลุงทอง/บริษัท): แพรวาตั้งเองได้ใต้เงื่อนไขเดิม + เพิ่ม (ก) ชื่อบริษัท/แบรนด์ = สมมุติทั้งหมด ห้ามแบรนด์จริง (ข) ชื่อเมือง/จังหวัด/สนามบินจริงของไทยใช้ได้ · แนบลิสต์ท้ายต้นฉบับเหมือนเดิม (ไทยเป็นหลัก + EN ทับศัพท์) → `characters.md 6`
