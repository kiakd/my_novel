## 1) ซีรัค (Zirakh) — เผ่าแมลงอวกาศ ศัตรูหลักของซากา · Tier 3 (เชิงชีวภาพ)

ชื่อที่มนุษย์ใช้: "ฝูง" (the Swarm) — "ซีรัค" มาจากเสียงคลื่นซ้ำๆ ที่จับได้ครั้งปฐมสัมผัส: *ซี-รัค, ซี-รัค*

### 1.1 ชีววิทยา
- สิ่งมีชีวิตเปลือกไคตินเสริมโลหะ (ดูดซับแร่จากสิ่งที่กิน) ไม่มี "บุคคล" — หน่วยเดี่ยวคืออวัยวะเคลื่อนที่ของสมองรวม สื่อสารด้วยคลื่นชีวประสาทระยะไกลที่มนุษย์เรียก **"เพลง" (the Song)**
- ดำรงชีพในสุญญากาศได้ (จำศีลเปลือกแข็ง) ขยายพันธุ์เร็วสุดขีดเมื่อมีมวลชีวภาพ+แร่ป้อน — ดาวหนึ่งดวงถูก "แทะ" เหลือแกนได้ใน 3–5 ปี
- **วรรณะหลัก 5 วรรณะ** (เรียกตามรหัสกองเรือสหพันธ์ — ใช้ชื่อชุดนี้เสมอ):

| วรรณะ | รูปลักษณ์/ขนาด | หน้าที่ |
|---|---|---|
| ด้วงงาน (Drone) | เท่าสุนัข | ขุด/แทะ/ลำเลียง — 90% ของฝูง |
| หอกเปลือก (Lancer) | เท่ายานชั้นเข็ม | หน่วยรบอวกาศ พุ่งชน/กรดเจาะเกราะ — คู่ปรับหลักของนักบิน |
| ช่างถัก (Weaver) | เท่ายานชั้นหอก | สร้างโครงสร้าง: รังอวกาศ, "ยานชีวะ" ลำเลียง, เปลือกหุ้มดาวเคราะห์น้อย |
| นักขับเพลง (Chorister) | เท่าฟริเกต — เปลือกโปร่งเรืองแสง | รีเลย์ "เพลง": สมองสนามรบ + ตัวแผ่คลื่นแทรกจิต (world-bible 4.5) |
| โหนดราชินี (Queen-Node) | ระดับเมือง ฝังในรังหลัก | ผลิตวรรณะ + เก็บ "คลังแพตเทิร์น" — ไม่เคยมีมนุษย์เห็นแล้วรอดกลับมา |

### 1.2 โครงสร้างรังและการรุกราน
- โครงสร้าง: **โหนดราชินี 1 → คอรัส (กลุ่มนักขับเพลง) → ฝูงสนาม** — เพลงอ่อนลงตามระยะทาง ฝูงที่ไกลรีเลย์จะ "โง่ลง" เป็นชั้นๆ
- การข้ามดาว: หลัก = **เมล็ดมืด (Dark Seed)** — กระสวยชีวะใต้แสง เหวี่ยงข้ามระบบดาวใช้เวลาเป็นสิบปี จึงดูเหมือน "ภัยช้าที่คุมได้" → มนุษย์ชะล่าใจมา 62 ปี (สำคัญ: ความเชื่อนี้จะถูกทุบใน T1 ของ saga-plan — ฝูงใช้ประตูเอออสได้)
- **ไทม์ไลน์การรุกราน (เท่าที่มนุษย์รู้ ณ ต้นเรื่อง)**: ปี 350 กินดาวเอลม์ (ปฐมสัมผัส) → ปี 350–400 กลืนแนวอาณานิคมชายขอบ 6 ระบบ → ปี 401 สมรภูมิเฮลิออน (มนุษย์แพ้ยับ เสียประตู 1 ดวง) → ปี 402–410 แนวรบนิ่ง "คุมเชิง" → ปี 410–412 เงียบผิดปกติ (ความลับเรย์ฮาน: ฝูงรวมมวลถอยไปจุดเดียว)

### 1.3 เหตุที่กลืนกินทุกอย่าง — สามชั้นความจริง (โครงสร้างการเฉลยของทั้งซากา)
1. **ชั้นที่มนุษย์เชื่อ (arc 1)**: ตั๊กแตนจักรวาล — กิน ขยายพันธุ์ ไปต่อ ไร้เหตุผล ไร้การเจรจา
2. **ชั้นที่สอง (arc 2–3)**: ฝูง *เลือก* กิน — มันเก็บ "แพตเทิร์น" ของสิ่งมีชีวิต/เทคโนโลยี/พฤติกรรมเข้าคลังก่อนกลืนเสมอ การรบของมันคือการ "ชิม" ยุทธวิธีของเหยื่อจนหมดคลัง แล้วค่อยบดขยี้ — นี่คือเหตุผลเชิงระบบที่มนุษย์แพ้: การศึกษาเมมเพล็กซ์ทำให้มนุษย์มีแพตเทิร์นซ้ำ (ธีมหลักของเรื่อง — world-bible หมวด 0 ข้อ 1)
3. **ชั้นความจริง (arc 4 — ความลับระดับลึก ห้ามใบ้ก่อนจุดที่ saga-plan กำหนด)**: ซีรัคไม่ใช่เผ่าตามธรรมชาติ — มันคือ **เครื่องมือเก็บเกี่ยว-จดหมายเหตุของเผ่าเอออส**: สร้างขึ้นเพื่อเก็บตัวอย่างชีวภาพ/อารยธรรมทั้งกาแล็กซีเข้า "คลัง" ก่อนภัยวัฏจักรบางอย่าง แต่คำสั่งหยุด (เงื่อนไขจบภารกิจ) สูญหายไปพร้อมผู้สร้าง — มันจึงเก็บเกี่ยวไม่มีวันจบ **"เพลงแม่" (Mother Song)** ที่ทุกโหนดร้องตามคือ directive ที่เพี้ยน · ผลเชิงโครงเรื่อง: ฝูง "ฆ่าให้หมด" ไม่ได้ (กระจายเกิน) แต่ "แก้เพลง" ได้ — ทางจบของซากา
- **"เสียง" ของฝูง (เงื่อนไขบรีฟ: ห้ามเป็นกำแพงไร้หน้า)**: ฝูงสื่อสารได้ — ผ่านนักขับเพลง และผ่าน *มนุษย์จำพวกตัวรับ* ที่โครงการเสาอากาศพยายามสร้าง (จุดเชื่อมเส้นธัญ) สิ่งที่มันพูดไม่ใช่ภาษาเจรจา แต่เป็นการ "จัดหมวด": มันเรียกอารยธรรมที่กำลังกินว่า *ตัวอย่างที่ต้องเก็บก่อนสูญหาย* — น่าขนลุกแบบบรรณารักษ์ ไม่ใช่แบบปีศาจ

### 1.4 จุดอ่อนเชิงระบบ (ทุกข้อมีต้นทุน — ห้ามใช้เป็นปุ่มชนะ)
1. **ตัดรีเลย์เพลง**: สังหาร/รบกวนนักขับเพลง → ฝูงท้องถิ่นถอยเป็นสัตว์สัญชาตญาณ (ยังอันตรายแต่ไม่ประสานงาน) — ต้นทุน: นักขับเพลงถูกคุ้มกันหนาแน่นสุดและคลื่นแทรกจิตแรงสุดใกล้ตัวมัน
2. **ความแหวกแพตเทิร์น**: ฝูงทำนายจาก "คลัง" — ยุทธวิธีที่ไม่เคยเห็นจะได้ผลดีมาก **ครั้งเดียวหรือสองครั้ง** แล้วถูกเก็บเข้าคลังทันที (กฎตายตัว: มุกเดิมห้ามได้ผลครั้งที่สาม — บังคับให้พระเอกต้องสดใหม่เสมอ = เครื่องยนต์ความตื่นเต้นรายตอน และกันพระเอกเทพ)
3. **ตรรกะเก็บเกี่ยว**: ฝูงให้ลำดับความสำคัญกับ "ตัวอย่างใหม่" — เบี่ยงเบนความสนใจมันได้ด้วยของที่มันไม่เคยเห็น (ใช้เชิงยุทธวิธีได้ แต่เสี่ยง: สิ่งที่มันสนใจ = สิ่งที่มันจะตามล่า)

## 2) เซเรน (Seren) — "ผู้จดจาร" · มิตรมีเงื่อนไข · Tier 3 (ขาลง)

- **ชีววิทยา**: มนุษย์รูปเพรียวสูง ผิวเปลี่ยนสีตามอารมณ์ (ระบบสื่อสารที่ซื่อสัตย์โดยชีววิทยา — โกหกยากมาก จึงพัฒนาวัฒนธรรม "พูดความจริงไม่ครบ" จนเป็นศิลปะ) อายุขัย ~600 ปี อัตราเกิดต่ำมาก — ประชากรลดลงทุกศตวรรษ: อารยธรรมที่กำลังตายอย่างสง่างาม
- **วัฒนธรรม**: ถือว่า "ความทรงจำ/เรื่องเล่า" คือทรัพย์สูงสุด — เรือนเร่ร่อน "หอจดหมายเหตุลอยฟ้า" เดินทางแลกเทคโนโลยีกับ *วัฒนธรรม* ของเผ่าอื่น (เพลง ประวัติศาสตร์ สูตรอาหาร) · มนุษย์ค้าขายกับเซเรนมา ~80 ปี — ความสัมพันธ์ดีแบบผิวเผิน
- **เทคโนโลยีเทียบสเกล**: เหนือมนุษย์ชัดเจน (เครื่องพับเร็วกว่า, วัสดุดีกว่า) แต่ **ไม่ขายอาวุธ** ให้ใครเด็ดขาด และจำนวนน้อยเกินกว่าจะเป็นกองทัพ
- **ความสัมพันธ์กับเผ่าอื่น**: มนุษย์ = คู่ค้า/แหล่งวัฒนธรรมอุดม · เคชาร์ = สงสารแต่ไม่ช่วย · ซีรัค = **หลีกเลี่ยงสัมบูรณ์** — เรือเซเรนถอนตัวออกจากระบบดาวก่อนฝูงมาถึงทุกครั้ง แม่นจนกองเรือมนุษย์ใช้ "การถอนตัวของเซเรน" เป็นสัญญาณเตือนภัยไม่เป็นทางการ (รายละเอียดสีสันที่นักเขียนใช้ได้เลย)
- **ความลับระดับลึก (เปิด arc 3)**: เซเรนรอด **วัฏจักรเก็บเกี่ยวครั้งก่อน** (หลายหมื่นปีก่อน) มาแล้ว — ไม่ใช่ด้วยการสู้ แต่ด้วยการ *ขายพิกัดอารยธรรมอื่นให้ฝูง* แลกกับการถูกข้าม ความผิดบาปนี้คือเหตุที่พวกเขาจดจารทุกอารยธรรม: เป็นการไถ่บาปต่อเผ่าที่พวกเขาชี้เป้าให้ถูกกิน — และพวกเขารู้เรื่องเอออส/เพลงแม่มากกว่าที่เคยบอกมนุษย์หลายเท่า
- **arc ของเผ่า**: คู่ค้าลึกลับ (arc 2) → แหล่งความจริงที่ต้องจ่ายราคา (arc 3) → ทางแยกศีลธรรม: จะซ้ำรอยเดิม (ชี้เป้ามนุษย์) หรือหักวงจร (arc 4–5)
- **ตัวแทนเผ่าที่จะเป็นตัวละครหลัก**: "วาร์เซน-เก้า-สาย-น้ำ" (เรียกสั้น **วาร์เซน**) — นักจดจารที่ประจำการแถบมนุษย์มา 200 ปี (รายละเอียดเพิ่มเมื่อถึง arc 2 — ผ่าน template ตัวละครใน `characters.md`)

## 3) เคชาร์ (Keshar) — "กองเรือไร้ดาว" · ศัตรู→ก้ำกึ่ง · Tier 2

- **ชีววิทยา**: สัตว์เลือดอุ่นเกล็ดขน สูง ~2 เมตร สายตานักล่า (เห็นอินฟราเรด) — วิวัฒนาการจากนักล่าฝูงบนทุ่งหญ้าดาวแรงโน้มถ่วงสูง: แข็งแรงกว่ามนุษย์ ทนจีสูงกว่า (นักบินโดยกำเนิด) แต่เปราะต่อความหนาวเย็น
- **ปูมเผ่า**: ดาวแม่ "เคช" ถูกฝูงกลืนเมื่อ ~60 ปีก่อน (ปีสหพันธ์ ~352 — ฝูงสายเดียวกับที่ชนมนุษย์) — รอดมาเป็น **กองเรือลี้ภัย ~2 ล้านชีวิต** เร่ร่อนหาบ้านใหม่ ทุกลำคือเมือง ทุกการซ่อมคือการต่อชีวิต
- **วัฒนธรรม**: ระบบ **"หนี้เกียรติ" (Honor-Debt)** — ช่วยชีวิต/ให้ของจำเป็น = เจ้าหนี้เกียรติ ผูกพันข้ามรุ่น เบี้ยวหนี้เกียรติ = ถูกขับจากกองเรือ (ตายช้าๆ ในอวกาศ) · การปล้นไม่ถือผิดศีล *ถ้าประกาศตัวก่อนปล้น* — โจรที่ซื่อสัตย์ที่สุดในกาแล็กซี
- **เทคโนโลยีเทียบสเกล**: T2 เท่ามนุษย์แต่ "เก่ากว่าและซ่อมเก่งกว่า" — ยานผีตัดต่อจากซากร้อยลำ ไร้มาตรฐานกลาง (ตรงข้ามมนุษย์สุดขั้ว: มนุษย์มาตรฐานเดียวทั้งสหพันธ์) → นักบินเคชาร์บิน "นอกคลัง" โดยธรรมชาติ — ฝูงอ่านพวกเขายากกว่ามนุษย์ แต่จำนวนน้อยเกินจะชนะ (จุดนี้คือหลักฐานในโลกว่าธีมเรื่องถูกต้อง และคือเหตุที่พวกเขาจะ "เข้าใจ" พระเอกเร็วกว่าใคร)
- **ความสัมพันธ์ปัจจุบันกับมนุษย์**: ปล้นเรือสินค้าชายแดน (เลือกเป้าไม่ฆ่าถ้าไม่จำเป็น) — สหพันธ์ตีตรา "โจรสลัดต่างดาว" ปฏิเสธคำขอตั้งถิ่นฐานมาแล้ว 3 ครั้ง (สภาประตูกลัวเสียงคอร์) → ความเกลียดนี้คือระเบิดเวลาและโอกาส: เผ่าที่เกลียดมนุษย์ที่สุด = เผ่าเดียวที่เกลียดฝูงเท่ามนุษย์
- **ความลับระดับลึก (เปิดปลาย arc 2)**: ผู้เฒ่ากองเรือเก็บ "เสียงสุดท้ายของดาวเคช" — บันทึกคลื่นวันที่ดาวถูกกลืน ในนั้นมีจังหวะของเพลงแม่ชัดที่สุดเท่าที่มีในกาแล็กซีฝั่งนี้ (กุญแจไขปริศนาที่ทั้งสำนักงานเข็มทิศและเซเรนต้องการ — เคชาร์ไม่รู้ค่าของมัน รู้แค่ว่ามันศักดิ์สิทธิ์)
- **arc ของเผ่า**: โจรชายแดน/วายร้าย arc 2 → หนี้เกียรติผูกกับพระเอก (เหตุการณ์ใน saga-plan) → พันธมิตรรบเคียงบ่าใน arc 4–5 และคำถามใหญ่ของสหพันธ์: "ชนะสงครามแล้ว ให้บ้านเขาไหม"

## 4) เอออส (Aeos) — เผ่าบรรพกาลสาบสูญ · Tier 4 · ปริศนาแกนของซากา

- **สถานะ**: สูญหายไปแล้ว ~หลายหมื่นปี — สิ่งที่เหลือ: โครงข่ายประตู, ซากสถานีในระบบดาวร้าง, และ (ความลับ) ซีรัค
- **เท่าที่มนุษย์รู้ ณ ต้นเรื่อง**: แทบศูนย์ — เรียกกันว่า "ผู้ก่อประตู" (Gatewrights) วิชาการสายหนึ่งเชื่อว่าสูญพันธุ์ อีกสายเชื่อว่า "ไปต่อ" ที่อื่น — ห้ามตัวละครใดมีข้อมูลเกินนี้ใน arc 1–2
- **ความจริงระดับซากา (ของวิน — โครงไว้กันเขียนขัด อย่าเฉลยเกินจังหวะ saga-plan)**: เอออสสร้างประตูและซีรัคเป็นระบบเดียวกัน — ประตู = เส้นเลือด, ฝูง = เครื่องเก็บเกี่ยว, จุดหมาย = "คลัง" (Archive) ที่ไหนสักแห่ง เพื่อรับมือภัยวัฏจักรที่พวกเขาเห็นล่วงหน้า แต่เอออสหายไปก่อนงานจบ — *หายไปไหน/เพราะอะไร* คือคำถามที่วินจองไว้เป็นไพ่ใบสุดท้ายของซากา (เฉลย arc 5)
- **กฎการใช้งาน**: ห้ามมีเอออสมีชีวิตโผล่ก่อน arc 5 · เทคโนโลยี T4 ใดๆ ที่พบ = ใช้แทบไม่ได้/อันตราย ไม่ใช่กล่องสมบัติอัปเกรดพระเอก

## 5) Template เจนเผ่าใหม่ (บังคับใช้ — เงื่อนไข CEO: เพิ่มเผ่าภายหลังได้โดยไม่ขัดของเดิม)

เผ่าใหม่ทุกเผ่า (ตามพล็อต CEO: "เผ่าต่างดาวอื่นโผล่มาเป็นมิตรหรือศัตรูได้เรื่อยๆ") ต้องกรอกครบ 10 ช่อง ส่งวินอนุมัติเข้าไฟล์นี้ก่อนปรากฏในต้นฉบับ:

```
1. ชื่อ (ไทย + EN) และชื่อที่มนุษย์/เผ่าอื่นใช้เรียก:
2. ชีววิทยา (รูปลักษณ์, สิ่งแวดล้อมกำเนิด, จุดแข็ง-จุดเปราะทางกายภาพ):
3. วัฒนธรรม (คุณค่าสูงสุด 1 อย่าง + ข้อห้าม 1 อย่าง — และสถาบัน/ธรรมเนียมที่งอกจากสองข้อนี้):
4. เทคโนโลยีเทียบสเกลพลัง (ระบุ Tier ตาม world-bible หมวด 5 + จุดที่เก่งกว่า/ด้อยกว่ามนุษย์อย่างละ 1):
5. ท่าทีต่อซีรัค (เคยเจอไหม / รอดมายังไง / รู้อะไรเกี่ยวกับเพลง):   ← ทุกเผ่าต้องตอบ เพราะฝูงคือแรงโน้มถ่วงของซากา
6. ความสัมพันธ์กับเผ่าที่มีอยู่ (มนุษย์ / เซเรน / เคชาร์ — ระบุ มิตร/ศัตรู/ก้ำกึ่ง + เหตุผลฝั่งเขา):
7. ผลกระทบต่อโครงเรื่องหลัก (เข้ามาเพื่อขยับเส้นไหน: สงครามฝูง / ปริศนาเอออส / การเมืองสหพันธ์ / ธีมความรู้เก่า):
8. ความลับของเผ่า (อย่างน้อย 1 + arc ที่วางแผนเปิดเผย):
9. เหตุที่เข้าฉากผ่าน conflict (กติกามะลิข้อ 4: ห้ามเปิดตัวผ่านบทบรรยาย — ระบุฉากปะทะ/ปัญหาที่พาเข้าเรื่อง):
10. ตรวจข้อห้ามชนกับ canon (ติ๊กให้ครบ):
    [ ] ไม่เกิน T3 (เกิน T3 ต้องผูกเอออสและขออนุมัติพิเศษ)
    [ ] ไม่มี FTL ไร้ประตู / สื่อสาร FTL / ย้อนเวลา (world-bible 4.1)
    [ ] ไม่มี AI เกินเพดานเป็นของประดับ (world-bible 4.3)
    [ ] ไม่ทำให้จุดอ่อนซีรัคข้อใดกลายเป็นปุ่มชนะ (หมวด 1.4)
    [ ] ไม่รู้ความจริงชั้นสาม (เอออสสร้างฝูง) เว้นแต่ saga-plan อนุญาต
    [ ] ไม่ทับบทบาทเชิงโครงสร้างของเผ่าเดิม (เซเรน=ความรู้/ความผิดบาป, เคชาร์=ผู้ลี้ภัย/เกียรติ — เผ่าใหม่ต้องเพิ่มมุมใหม่ ไม่ใช่ก๊อบ)
    [ ] ไทม์ไลน์การพบมนุษย์ไม่ขัด world-bible หมวด 1
```

> หลักออกแบบที่วินใช้ (ให้คนรุ่นหลังเจนเผ่าได้กลิ่นเดียวกัน): ทุกเผ่าในเรื่องนี้คือ "คำตอบหนึ่งแบบต่อคำถามว่า *อารยธรรมทำอะไรเมื่อรู้ว่าตัวเองจะถูกลืม*" — มนุษย์มาตรฐานทุกอย่างจนลืมวิธีคิดเอง, เซเรนจดจารคนอื่นเพื่อไถ่บาป, เคชาร์แบกบ้านไว้บนหลัง, เอออสสร้างเครื่องจดจำที่กลายเป็นปีศาจ, ซีรัคคือความทรงจำที่ลืมเหตุผลของตัวเอง — เผ่าใหม่ควรตอบคำถามเดียวกันด้วยคำตอบที่ยังไม่มีใครตอบ
