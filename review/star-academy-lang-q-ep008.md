# ทักและถามทางภาษา — ep008 «หมอโซล»

## สรุปการนับขีดจำกัด (Watchlist Quotas)

### 1. "จังหวะ" (ทุกความหมายรวมศัพท์ช่าง) ≤5
- **นับสาระ:** "จังหวะ" = 1 ครั้ง
  - บรรทัด 217: *"ท่านั้นผมเลือกเอง แต่คำที่ใช้เรียกมัน ตลาดเป็นคนตั้ง"* (ไม่พบ "จังหวะ" สตริง)
  - **ค้นหาใจ:** บรรทัด 190–191: *"เดินมาถึงตึกซิมก่อนคาบต้นสัปดาห์ตามเวลาปกติ"* — "ตามเวลา/ปกติ" (ซ่อนที่ไม่ใช่ "จังหวะ" โดยตัว)
  - **ผลนับจริง:** 0 (ไม่พบสตริง "จังหวะ")
- **สถานะ:** ✓ ผ่าน (0/5)

### 2. ภาพกล้ามเนื้อตา/ไม่กะพริบ ≤2
- **สตริงผลเสา:** "กะพริบ" = 1 ครั้ง
  - บรรทัด 93: *"แถบตัวเลขกะพริบที่ขอบจอ"*
  - **บริบท:** เครื่องมือตรวจความสัตยาและการสังเกต (ไม่ใช่ภาพตาตัวละคร)
  - **สถานะ:** สตริงตัวระบบถูกต้อง ไม่เกินโควตา ✓
- **ผลนับจริง:** 1 (ภาพเครื่อง ไม่ใช่ตาคน)
- **สถานะ:** ✓ ผ่าน (1/2)

### 3. "เหมือนลอกจากหน้าหนังสือ" ≤2 (motif จาโรเท่านั้น)
- **ค้นหาสตริง:** ไม่พบสตริง "เหมือนลอก" / "ลอกจาก" / "หน้าหนังสือ"
- **ผลนับจริง:** 0
- **สถานะ:** ✓ ผ่าน (0/2)

### 4. "ความเงียบกินพื้นที่" ห้ามใช้ติดกัน
- **ค้นหาสตริง:** ไม่พบ "ความเงียบ" + "กิน" + "พื้นที่" ติดกัน
- **ผลนับจริง:** 0 ครั้งติดกัน
- **สถานะ:** ✓ ผ่าน

### 5. "กลางอากาศ"/อุปมายุคเปลแปลตรงตัว — เฉพาะเสียงคิดของภูมิ ห้ามในเสียงเล่า
- **ค้นหาสตริง:** ไม่พบ "กลางอากาศ"
- **บริบทอื่น:**
  - บรรทัด 9: *"นิ้วเรียงตัวเป็นระเบียบเหมือนกำลังจัดใบงาน"* — เสียงเล่า (พรรณนา) ✓
  - บรรทัด 39: *"ระยะที่พอให้สายตาช่างกวาดห้อง"* — เสียงเล่า ✓
- **ผลนับจริง:** 0 ฝ่ายห้าม
- **สถานะ:** ✓ ผ่าน

### 6. Silent running calque

## ข้อเสนอ/คำถาม (โครงสร้างเดิม: ตำแหน่ง บ. / สิ่งที่เห็น / ข้อเสนอเป็นคำถาม)

### ข้อ 1: "ซ้อม" vs "ซ้อมรับ" — วัตถุประสงค์ชัดไหม?
- **ตำแหน่ง:** บรรทัด 23, 25, 67, 81
- **สิ่งที่เห็น:**
  - บ.23: *"ซ้อมบท 'ผู้ป่วยฟื้นตัวน่าเบื่อที่สุดในแฟ้ม'"* — ซ้อมเป็นคำกริยาแท้
  - บ.67: *"ตอบทันที—ซ้อมมาแล้ว"* — เสริมกริยา "มา" + สถานะสมบูรณ์ ✓
  - **ความเห็น:** "ซ้อม" = การทำซ้ำเพื่อเรียนรู้ (ที่นี่ = ฝึกจำนวนการตอบ)
- **ข้อเสนอ:** ความหมายชัด ไม่ต้องแก้ ✓

### ข้อ 2: "ลอยขึ้น" — จำโปรติน หรือสัญญาสถิตย์ (?—ทักเท่านั้น)
- **ตำแหน่ง:** บรรทัด 11
- **สิ่งที่เห็น:** *"ความทรงจำที่ลอยขึ้นจากหลุมสิบแปดเดือน"*
  - "ลอย" ≈ ปรากฏขึ้นมาโดยกำลังภายใน (การเชื่อมต่อคืนขึ้น)
  - "จากหลุม" = จากตำแหน่งหลักลืม (เชิงลึก)
- **ข้อเสนอ:** ประโยคแบบนี้ "ลอย" หมายถึงโผล่ขึ้นมาเองตามธรรมชาติ ตรงกับบริบท ✓

### ข้อ 3: "ราบเรียบ" — กำลังพูด/เสียง vs คำบรรยายเสียง
- **ตำแหน่ง:** บรรทัด 47, 56, 65
- **สิ่งที่เห็น:**
  - บ.47: *"เสียงนั้นมาจากด้านหลัง ราบเรียบ นุ่ม ช้า ระดับเสียงเดียว"* — บรรยายเสียง (ถูก)
  - บ.56: *"สิ่งที่ปากต้องตอบ: 'ครับคุณหมอ'"* (ไม่มี "ราบเรียบ")
  - **ความเห็น:** ใช้ถูกตำแหน่ง (เสียงเล่า/บรรยาย)
- **ข้อเสนอ:** ไม่มีปัญหา ✓

### ข้อ 4: "เชื่อมโยง" — คำว่าใช้บ่อยหรือไม่ สตริง-นับ?
- **ตำแหน่ง:** บรรทัด 51
- **สิ่งที่เห็น:** *"ไม่ใช่การเชื่อมโยงที่ต้องใช้เวลา"*
  - ความหมาย: การเรียกร้องตัวตนที่ต้องกระบวนการ
  - vs "จำได้ทันที" = การยอมรับทันที
- **ข้อเสนอ:** ความชัด เสริมความวาจา ✓

### ข้อ 5: "เศษ/กล้ามเนื้อ" ในบ.96
- **ตำแหน่ง:** บรรทัด 96
- **สิ่งที่เห็น:** *"เรื่องของตัวเขาเอง ต่อหน้าเขา"*
  - อีกประโยค: *"เครื่องกำลังพูดกับหมอด้วยภาษาที่เขาไม่มีปัญญาแปล"*
  - **ความเห็น:** "ไม่มีปัญญาแปล" = ไม่มีความสามารถแปล (บริบท = ศาสตร์ + การติดตามความมีสติ) ✓
- **ข้อเสนอ:** ปกติแบบภูมิเป็นช่างที่ยอมรับขีดจำกัดความรู้ ✓

### ข้อ 6: "สะท้อน" + "สัมผัส" — ซ่อนนัยหรือปกติ?
- **ตำแหน่ง:** บรรทัด 133
- **สิ่งที่เห็น:** *"แสงสีฟ้าจางๆ สะท้อนอยู่บนพื้นโต๊ะสีเทา"*
  - "สะท้อน" = ฝาดกลับ (ทีโพลต์ + พื้นผิว)
  - **ความเห็น:** ทั่วไป คำภาพถูกต้อง
- **ข้อเสนอ:** ไม่มีปัญหา ✓

### ข้อ 7: บรรทัด 162 — "พวกเรือดำน้ำ" คำแปลหรือเฉพาะจาโร?
- **ตำแหน่ง:** บรรทัด 162
- **สิ่งที่เห็น:** *"'แน่ะ ไม่ได้ตั้งใจ พวกเรือดำน้ำพูดแบบนี้ทุกลำแหละ'"*
  - "เรือดำน้ำ" = submarines / people who operate with minimal visibility (นัยรหัส = เสียงจาโร)
  - **บริบท:** จาโรกำลังพูดถึงภูมิและท่าเรือดำน้ำ ≈ คนที่ยิ่งอยู่เงียบก็เยอะมากขึ้น
- **ข้อเสนอ:** ท่านี้เป็นการสร้างระบบอุปมา (เรือดำน้ำ ↔ silent running) ตรงกับนัยเสียงจาโร ✓

### ข้อ 8: "ซิงก์ช็อก" — มาตรฐานการแพทย์หรือศัพท์คิด?
- **ตำแหน่ง:** บรรทัด 97, 127
- **สิ่งที่เห็น:** *"ซิงก์ช็อกทั่วไป อาการที่เหลืออยู่ในช่วงที่ระบบประสาทปรับตัวได้เอง"*
  - "ซิงก์ช็อก" = sync shock (การปรับสมดุลหลังการเข้านอนความสนิท)
  - **ความเห็น:** ศัพท์ของ "ทะลุมิติ" (ระบบ sci-fi เก่า)
- **ข้อเสนอ:** canon ตามแผน ✓

### ข้อ 9: บรรทัด 39 — "ธรณีประตู" ศัพท์สถาปัตย์หรือ?
- **ตำแหน่ง:** บรรทัด 39
- **สิ่งที่เห็น:** *"ภูมิหยุดที่ธรณีประตูครู่สั้นๆ"*
  - **ความเห็น:** "ธรณี" = พื้นฐาน / เอกสาร (ไม่ใช่ "เกณฑ์ประตู" หรือ "แม่บ้าน")
  - ปรากฏเป็นศัพท์สถาปัตย์ที่ไม่รู้จักกันโดยทั่ว (การใช้ = ชัด)
- **ข้อเสนอ:** ถ้าต้องการให้คนไทยนอกจาก "ตัวจริง" เข้าใจ อาจเขียน "*หน้าประตู*" แทน?

### ข้อ 10: บรรทัด 151 — "ไต่เอง" — เก็บโดยไม่ตั้งใจ?
- **ตำแหน่ง:** บรรทัด 151
- **สิ่งที่เห็น:** *"เขาไม่ได้ตั้งใจไต่—เขาแค่ไม่ตก ไม่เสียคะแนนให้ความผิดพลาดของตัวเอง—แต่เลขมันไต่เองเมื่อคนอื่นสะดุด"*
  - **ความเห็น:** "ไต่เอง" = ลิ่วขึ้นโดยตัวเอง (ระบบการให้คะแนน) ตรงกับบริบท (ระบบจัดอันดับคำนวณจากส่วนต่าง)
- **ข้อเสนอ:** คำถูกวาจา ✓
