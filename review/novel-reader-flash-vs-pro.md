- [50] โจวอวิ่น(หญิง)พูดกับถังจือชู: F "**เธอ**ว่าล่ะ" ✗ · P "ว่าไงล่ะ" ✓

## สรุป
- Pro ชนะเรื่องที่สำคัญที่สุดของนิยายแปล: คำเรียกตามเพศ/ลำดับอาวุโส และน้ำเสียงบทพูด — Flash ยังเรียกผู้ชายว่า "เธอ" ทั้งที่ GLOSSARY บอกชัด
- Flash ชนะเรื่องราคา (~1.6×) และความเร็ว (~1.5×)
- ตัวอย่างเดียว ยังสรุปเด็ดขาดไม่ได้ ควรลองอีก 2–3 ตอนต่างเรื่อง (เช่นแฟนฟิค HP 90442 / แฟนตาซี 43484)

**แปลใหม่ ตอน 1–5**
- Pro แม่นความหมายกว่า: ตอน 5 [45] Flash แปลผิด "เข้าใจผิดว่า**ฮอกวอตส์**คือทายาทแห่งห้องแห่งความลับ" · Pro "เข้าใจ**แฮร์รี่**ผิดคิดว่าเป็นทายาท…" ✓
- Flash มีคำเพี้ยน "เสียงอีกกกอื่นๆ" (ตอน 5 [29]), ใช้ "……" แบบจีน; Pro ใช้ "…"
- Pro สำนวนไทยลื่นกว่า: "ถึงฮอกวอตส์แล้วค่อยว่ากัน" (F "พอถึงฮอกวอตส์ก็คงดีเอง"), "ใจแป้ว", "ขนมกองพะเนิน"
- Pro คาถา "วินการ์—เดียม—เลวีโอซา!" ใกล้ฉบับไทยกว่า (F "วิงการ์เดียม เลวิโอซา")
- Pro พลาดเล็กน้อย: "พ่อหนูน้อยทั้งหลาย" ทั้งที่มีเฮอร์ไมโอนี่อยู่ด้วย; ชื่อบทเลขซ้ำ "บทที่ 1 1:"
- คำหลุด (จีน/อังกฤษ) เกิดทั้งคู่ ระบบแก้อัตโนมัติได้หมด; Pro ตอน 3 หลุด กู/มึง 2 บรรทัด (แก้อัตโนมัติแล้ว)
- ไม่มีหมายเหตุสำนวนทั้งคู่ (ตอน 1–5 ไม่มีสำนวนจีนแบบมีที่มาชัด)

**Pro แก้รายย่อหน้า (ตอน 6) — 6/6 ใช้ได้**
- "ไล่ฝู! เจ้าอยู่ไหน!" → "เทรเวอร์! นายอยู่ไหน!" ✓ · "หนึ่งในคณะ…" → "มีบ้านหลังหนึ่งตั้งชื่อตามเขา" ✓
- "พวกไม่เข้าพวก" → "พวกไม่เอาไหน" ✓ · "ไอ้โง่" → "โง่จริง" (สุภาพขึ้น แต่หายความเป็นคำอังกฤษ)
- คาถารอน → "เดซี่ ครีมหวาน แสงตะวัน จงเปลี่ยนหนูอ้วนตัวนี้ให้เป็นสีเหลืองพลัน" (สัมผัส ตะวัน/พลัน แต่ไม่ใช่ถ้อยคำฉบับไทยทางการ)
- "ภูเขาไท่ถล่มลงตรงหน้า" คงภาพจีนได้ แต่โหมดแก้ย่อหน้า**ยังเพิ่มหมายเหตุท้ายบทไม่ได้**

**Pro เกลาทั้งตอน (ตอน 7)** — เปลี่ยน 36/104 ย่อหน้า ส่วนใหญ่เล็กน้อย: "พ่อมดน้อย" → "พ่อมดแม่มดน้อย" (สม่ำเสมอขึ้น), "ยาผสม" → "วิชาปรุงยา" ✓, ปรับเครื่องหมายคำพูด; ถอยหลังบ้าง: 不讲道理 "ไม่มีเหตุผล" → "ไม่พูดถึงเหตุผล" ✗

**สรุปรอบ 2**: Pro แปลแม่นและลื่นกว่าจริง แต่ ~3.7× · ทางคุ้มสุดคือ Flash แปลตามปกติ + ใช้ Pro แก้เฉพาะย่อหน้าที่เจอปัญหา (ถูกมาก แก้ได้ตรงจุด)

## บทเรียนข้างเคียง
- เรียก `deepseek-flash` / `deepseek-v4-pro` ตรงๆ = เปิดโหมดคิดอัตโนมัติ → ความคิดกิน `max_tokens: 8000` หมดจนคำแปลว่าง (รอบแรกเสียไปราว 8 คำขอ × 8k token ขาออก) → translate.ts ส่ง `thinking: disabled` เป็นค่าเริ่มต้นแล้ว เปิดด้วย `--thinking low|high|max`
