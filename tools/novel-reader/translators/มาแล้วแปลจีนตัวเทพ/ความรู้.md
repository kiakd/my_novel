# ความรู้ภาพรวม: จีนยุคใหม่ (ยุค 80 – ปัจจุบัน)
หลัก: ศัพท์เฉพาะยุคให้แปลเป็นความหมายที่คนไทยเข้าใจ ถอดเสียงเฉพาะชื่อเฉพาะ ถ้าจำเป็นอธิบายสั้นๆ ในประโยคได้ (ห้ามใส่หมายเหตุผู้แปลแยก)

## ยุค 80 — ปฏิรูปเปิดประเทศ
- เศรษฐกิจเพิ่งเปิด คนเริ่มค้าขายส่วนตัว "下海" = ลาออกจากงานรัฐไปทำธุรกิจ
- 万元户 = ครัวเรือนเงินหมื่น (ร่ำรวยมากในยุคนั้น)
- 单位 = หน่วยงาน (ที่ทำงานรัฐที่ดูแลที่พัก สวัสดิการ ทั้งชีวิต) ; 铁饭碗 = ชามข้าวเหล็ก (งานมั่นคงตลอดชีพ)
- 粮票 = คูปองอาหาร ; ของมีค่าในบ้าน: จักรยาน จักรเย็บผ้า นาฬิกาข้อมือ วิทยุ
- 知青 = ปัญญาชนที่ถูกส่งไปชนบท (กลับเมืองช่วงปลายยุค 70–ต้น 80)

## ยุค 90 – 2000s
- รัฐวิสาหกิจปลดคนงานจำนวนมาก (下岗 = ถูกเลิกจ้าง) ; เมืองเศรษฐกิจพิเศษโต เช่น เซินเจิ้น
- 网吧 = ร้านเน็ต ; QQ = โปรแกรมแชตยุคนั้น ; เพจเจอร์ โทรศัพท์ฝาพับ
- ราคาบ้านเริ่มพุ่ง ซื้อบ้านช่วงนี้ = ได้เปรียบมหาศาล (เป็นมุกประจำของนิยายเกิดใหม่)

## 2010s – ปัจจุบัน
- 高考 = สอบเข้ามหาวิทยาลัย (ชี้ชะตาชีวิต) ; 985/211 = กลุ่มมหาวิทยาลัยชั้นนำ (แปลว่า "มหาวิทยาลัยกลุ่ม 985")
- 微信 = วีแชต ; 淘宝 = เถาเป่า ; 外卖 = สั่งอาหารเดลิเวอรี ; 直播 = ไลฟ์สด ; 996 = ทำงาน 9 โมงถึง 3 ทุ่ม 6 วัน
- 相亲 = นัดดูตัว ; 彩礼 = ค่าสินสอด ; 户口 = ทะเบียนบ้าน (มีผลต่อสิทธิ์เรียน/ทำงานในเมือง)
- 打工人 = มนุษย์เงินเดือน/คนหาเช้ากินค่ำ ; 内卷 = การแข่งขันกันจนเหนื่อยเปล่า

## เงินและตัวเลข
- 元/块 = หยวน ; 万 = หมื่น, 十万 = แสน, 百万 = ล้าน (ตามกฎหลัก)
