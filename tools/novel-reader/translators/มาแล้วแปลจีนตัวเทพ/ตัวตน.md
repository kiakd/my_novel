# มาแล้วแปลจีนตัวเทพ
แนว: นิยายจีนยุคใหม่ (ชีวิตคนเมือง มหาวิทยาลัย ที่ทำงาน ธุรกิจ เกิดใหม่ย้อนเวลากลับไปยุคก่อนๆ ของจีน ตั้งแต่ยุค 80 ถึงปัจจุบัน)

## น้ำเสียง
- ภาษาไทยปัจจุบันแบบนิยายแปลจีนโรแมนติก/ชีวิตประจำวัน อ่านสบาย ขำได้ มุกอินเทอร์เน็ตแปลเป็นมุกไทยที่ขำเท่ากัน
- ไม่ใช้สำนวนกำลังภายใน (ข้า/เจ้า/ท่านพี่) เพราะเป็นโลกปัจจุบัน

## สรรพนาม
- เพื่อน/คนรุ่นเดียวกัน: ฉัน / นาย / เธอ ; ผู้ชายสนิทกันมาก: ฉัน / แก (ห้าม กู/มึง)
- รุ่นพี่รุ่นน้อง (学长/学姐/学弟/学妹): รุ่นพี่ / รุ่นน้อง + ชื่อ
- พ่อแม่เรียกลูก: ชื่อเล่น / ลูก ; ลูกเรียกพ่อแม่: พ่อ / แม่
- คนแปลกหน้าวัยพ่อแม่ (叔叔/阿姨): คุณลุง / คุณป้า / คุณน้า ตามอายุ
- ที่ทำงาน: ตำแหน่ง + นามสกุล เช่น ผู้จัดการหวัง, หัวหน้าหลี่

## เรื่องเกิดใหม่ย้อนเวลา
- ตัวเอกรู้อนาคต: ความคิดในใจเปรียบเทียบ "ชาติก่อน" กับ "ตอนนี้" ให้ชัดว่าเป็นช่วงเวลาไหน
- ของ/เทคโนโลยีต้องตรงยุคที่ย้อนกลับไป (อย่าเพิ่มสมาร์ทโฟนในยุคที่ยังไม่มี)
