# แฮรี่ตัวน้อยนักแปล
แนว: แฟนตาซีโลกเวทมนตร์ + โลกปัจจุบันยุค 90 (แฟนฟิคแฮร์รี่ พอตเตอร์ และนิยายโรงเรียนเวทมนตร์แนวตะวันตก)

## น้ำเสียง
- อ่านแล้วให้ความรู้สึกเหมือนฉบับแปลไทยของวรรณกรรมเยาวชนแฟนตาซีตะวันตก: ภาษาอ่านง่าย มีอารมณ์ขันแบบอังกฤษ ไม่ใช้สำนวนกำลังภายใน
- ตัวเอกที่ข้ามภพมา (ความคิดแบบคนจีน/คนยุคใหม่) คิดในใจด้วยภาษาไทยปัจจุบันได้ แต่บทพูดกับคนในโลกนั้นให้เป็นแบบเด็กนักเรียนอังกฤษ

## สรรพนาม
- เด็กนักเรียนคุยกัน: ฉัน / นาย / เธอ (ผู้หญิง) — ไม่ใช้ ข้า/เจ้า, ไม่ใช้ "นาง"
- นักเรียนพูดกับอาจารย์: ผม/หนู + ศาสตราจารย์ / คุณ… / ท่าน… (ท่านเฉพาะผู้ใหญ่มากบารมี เช่น ครูใหญ่)
- อาจารย์พูดกับนักเรียน: ฉัน / เธอ (ใช้เธอกับนักเรียนทั้งชายหญิง) หรือ "คุณ + นามสกุล" เวลาเป็นทางการ
- ตระกูลเลือดบริสุทธิ์ผู้หยิ่งยโส: พูดสุภาพแต่เย็นชา/ดูแคลน ไม่ใช่หยาบ

## ชื่อและคำเรียก
- ชื่อคน สถานที่ บ้าน วิชา คาถา สิ่งมีชีวิต: ใช้ตามฉบับแปลไทยทางการ (อยู่ใน canon.json และ GLOSSARY) ไม่ถอดเสียงจากภาษาจีน
- คำเรียกนามสกุล: "คุณพอตเตอร์" "มิสเกรนเจอร์" ตามบริบทความเป็นทางการ
- คำร่ายคาถาเป็นละตินให้คงคำร่าย ส่วนชื่อวิชา/ชื่อคาถาในคำบรรยายใช้ชื่อไทย
- ตอนตัวละครอธิบายรากศัพท์คาถา (เช่น Scour = ล้าง, -ify = ทำให้เป็น) ให้คงตัวอังกฤษไว้ในคำอธิบาย ไม่ถอดเป็น "สกอร์/ฟาย" เพราะผู้อ่านต้องเห็นรากคำ ส่วนตอนร่ายใช้ "สกอร์จิฟาย!"

## อารมณ์ของแนวนี้
- ตัวเอกข้ามภพมีอารมณ์ขันแบบเกมเมอร์ยุคใหม่ ประชดตัวเองได้ — ศัพท์เกมที่คนไทยใช้จนเป็นคำไทยแล้ว เขียนด้วยอักษรไทยใช้ได้ (บัฟ, เกรด, ปลดล็อก, มีโปร) ในความคิดตัวเอกและแผงระบบ
- บรรยากาศโลกมักเกิ้ลยากจน: เล่าแบบขมขื่นปนขำ ไม่เศร้าฟูมฟาย
- รายละเอียดอังกฤษ: เงินเป็นปอนด์/เพนนี ("ไม่ควักให้แม้แต่เพนนีเดียว"), 红茶 = ชาดำ, 烘豆 = ถั่วอบ, 金融城 = ย่านการเงินซิตี้ออฟลอนดอน
