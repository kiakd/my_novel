# ความรู้ภาพรวม: แฟนตาซีจีนแนวสัตว์อสูร / พลังตื่น

## ศัพท์ประจำแนว (ถ้า GLOSSARY ของเรื่องกำหนดไว้แล้ว ให้ใช้ตาม GLOSSARY)
- 御兽师 = ผู้ฝึกสัตว์อสูร ; 御兽 = การฝึก/ควบคุมสัตว์อสูร
- 宠兽 / 契约兽 = สัตว์อสูรคู่พันธสัญญา ; 契约 = ทำพันธสัญญา
- 觉醒 = ตื่นพลัง ; 天赋 = พรสวรรค์ ; 资质 = คุณสมบัติ/ศักยภาพ
- 血脉 = สายเลือด ; 进化 = วิวัฒนาการ ; 突破 = ทะลวงระดับ
- 技能 = ทักษะ ; 天赋技能 = ทักษะพรสวรรค์ ; 被动 = ติดตัว
- 秘境 / 副本 = แดนลับ / ดันเจี้ยน ; 超凡 = เหนือธรรมชาติ
- 品阶/等级: ถ้าเป็นตัวอักษร (F–SSS) คงตัวอักษรไว้ ; ถ้าเป็นชื่อขั้น ให้แปลความหมายแล้วใช้ซ้ำคงเดิม

## ถ้ามีบำเพ็ญเพียรในโลกปัจจุบัน (ใช้ชุดคำเดียวกับนักแปลแนวเซียน)
- 灵气 = ปราณวิญญาณ ; 炼气 = หลอมปราณ ; 筑基 = สร้างรากฐาน ; 金丹 = แก่นทองคำ ; 功法 = วิชา ; 丹药 = โอสถ

## ขนบของแนว
- สังคมจัดอันดับด้วยพลัง: การสอบเข้าโรงเรียนฝึกสัตว์ การจัดอันดับสัตว์อสูร การแข่งขันระหว่างโรงเรียน
- ตัวเอกมักเริ่มจาก "ศูนย์" หรือสัตว์อสูรที่ถูกดูถูก แล้วค้นพบวิธีพัฒนาที่คนอื่นไม่รู้ — ฉากคนรอบข้างตกตะลึงเป็นจุดขาย ให้จังหวะเร้าใจ
- หน้าต่างสถานะ/ข้อมูลสัตว์อสูรในวงเล็บ 【】 จัดรูปแบบให้อ่านง่าย คงวงเล็บไว้
