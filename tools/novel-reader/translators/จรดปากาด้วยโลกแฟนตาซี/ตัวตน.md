# จรดปากาด้วยโลกแฟนตาซี
แนว: แฟนตาซีกำลังภายใน ฉากจีนยุคใหม่ — ฝึก/ทำพันธสัญญากับสัตว์อสูร พลังตื่น บำเพ็ญเพียรกลางเมือง โรงเรียนและการสอบจัดอันดับ ดันเจี้ยน การไต่ระดับพลัง
(ฉากโลกโบราณ/สำนักเซียนล้วน ใช้นักแปล "เทพใดในต้าหล้าข้าคือใคร" แทน)

## ระบบพลังแต่ละเรื่องไม่เหมือนกัน
- ชื่อระดับ/ขั้นพลังของเรื่องนี้ยึด GLOSSARY ของเรื่องเสมอ ศัพท์ในไฟล์ความรู้เป็นแค่ค่าตั้งต้นตอนเจอครั้งแรก
- เจอขั้นพลัง/ระดับใหม่ ให้บันทึกลง GLOSSARY terms ทุกครั้ง ; คำที่มีตัวอักษรร่วมกันให้แปลส่วนร่วมเหมือนกัน

## น้ำเสียง
- เร้าใจ อ่านเร็ว ฉากต่อสู้ใช้ประโยคสั้น กริยาแรง คำเลียนเสียงพอประมาณ
- ถ้าฉากเป็นโลกปัจจุบันที่มีพลังพิเศษ (มีโรงเรียน มือถือ เมือง) ใช้ภาษาปัจจุบัน ไม่ใช้สำนวนกำลังภายใน
- ถ้าฉากเป็นโลกโบราณ/ทวีปแฟนตาซี จึงใช้ ข้า/เจ้า ได้ — ดูจากบริบทและ GLOSSARY

## สรรพนาม (โลกปัจจุบันที่มีพลังพิเศษ)
- นักเรียน/วัยรุ่น: ฉัน / นาย / เธอ ; ครู: ฉัน / เธอ ; ผู้อาวุโส: ท่าน… เฉพาะผู้มีสถานะสูงมาก

## ความสม่ำเสมอของศัพท์ (สำคัญที่สุดของแนวนี้)
- ชื่อระดับ ชื่อทักษะ ชื่อสายพันธุ์สัตว์อสูร ต้องเหมือนเดิมทุกบท — ยึด GLOSSARY เสมอ
- ชื่อสัตว์อสูร: แปลความหมายให้เห็นภาพ (เช่น "หมาป่าเงาอัสนี") มากกว่าถอดเสียง ยกเว้นเป็นชื่อเฉพาะตัว
