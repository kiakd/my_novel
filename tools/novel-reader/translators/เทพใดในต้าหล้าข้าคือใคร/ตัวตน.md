# เทพใดในต้าหล้าข้าคือใคร
แนว: บำเพ็ญเซียน/กำลังภายในในโลกโบราณ — สำนัก ศิษย์ ผู้อาวุโส ขั้นพลัง โอสถ สมบัติวิเศษ ฝ่ายธรรมะ-ฝ่ายมาร

## น้ำเสียง
- สำนวนนิยายกำลังภายในแปลไทย: ขรึม มีภูมิ แต่ยังอ่านลื่น ไม่ใช้ศัพท์วัยรุ่น/ศัพท์ปัจจุบัน (ยกเว้นตัวเอกข้ามภพคิดในใจ ใช้ภาษาปัจจุบันได้เล็กน้อยเพื่อความขำ)
- ฉากต่อสู้: ประโยคสั้น กริยาแรง ชื่อกระบวนท่าเป็นภาษาไทยที่เห็นภาพ

## สรรพนาม
- ทั่วไป: ข้า / เจ้า ; สุภาพต่อผู้สูงกว่า: ข้าน้อย (在下/晚辈) + ท่าน…
- ผู้มีสถานะสูงพูดถึงตัวเอง (本座/本尊/老夫): ข้า (หรือ ตัวข้า/ข้าผู้เฒ่า ตามอายุ) — ให้เห็นความถือตัว
- คำเรียก: 师尊/师父 = ท่านอาจารย์ ; 师兄/师姐 = ศิษย์พี่ ; 师弟/师妹 = ศิษย์น้อง ; 前辈 = ท่านผู้อาวุโส ; 道友 = สหายเต๋า ; 长老 = ผู้อาวุโส ; 掌门/宗主 = เจ้าสำนัก

## ระบบพลังแต่ละเรื่องไม่เหมือนกัน — กฎสำคัญ
- ชื่อขั้นพลัง ชื่อสำนัก ชื่อวิชา ของเรื่องนี้ ให้ยึด GLOSSARY ของเรื่องเสมอ
- ตารางในไฟล์ความรู้เป็นเพียง "ค่าตั้งต้น" ตอนเจอคำครั้งแรก — เจอขั้นพลังใหม่ ให้บันทึกลง GLOSSARY terms ทุกครั้ง บทต่อไปจะได้ใช้คำเดิม
- คำที่มีตัวอักษรร่วมกัน ให้แปลส่วนร่วมเหมือนกัน (เช่น 命灯/命牌/命火 → …ชีวิต ทั้งชุด; ชื่อย่อของสำนักต้องแปลให้เห็นว่าเป็นสำนักเดียวกับชื่อเต็ม)
