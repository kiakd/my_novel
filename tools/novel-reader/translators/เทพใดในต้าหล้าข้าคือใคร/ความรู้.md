# ความรู้ภาพรวม: ขนบนิยายบำเพ็ญเซียน (ค่าตั้งต้น — GLOSSARY ของเรื่องมาก่อนเสมอ)

## ขั้นพลังที่พบบ่อย (แต่ละเรื่องอาจตั้งเอง/ลำดับต่างกัน)
- 炼气/练气 = หลอมปราณ ; 筑基 = สร้างรากฐาน ; 金丹 = แก่นทองคำ ; 元婴 = ทารกวิญญาณ
- 化神 = แปลงวิญญาณ ; 炼虚 = หลอมความว่าง ; 合体 = รวมกาย ; 大乘 = มหายาน ; 渡劫 = ข้ามทัณฑ์สวรรค์
- 境/境界 = ขอบเขต ; 层/重 = ชั้น ; 初期/中期/后期/圆满 = ขั้นต้น/กลาง/ปลาย/สมบูรณ์
- 突破 = ทะลวงขั้น ; 瓶颈 = คอขวด ; 走火入魔 = ธาตุไฟเข้าแทรก

## สิ่งของและพลัง
- 灵气 = ปราณวิญญาณ ; 灵根 = รากวิญญาณ ; 灵石 = หินวิญญาณ ; 丹药 = โอสถ ; 法宝 = สมบัติวิเศษ ; 法器 = อาวุธวิเศษ
- 功法 = วิชา/คัมภีร์ฝึก ; 神通 = อิทธิฤทธิ์ ; 阵法 = ค่ายกล ; 符箓 = ยันต์ ; 储物袋 = ถุงเก็บของ
- 寿元 = อายุขัย ; 天劫 = ทัณฑ์สวรรค์ ; 洞府 = ถ้ำพำนัก ; 秘境 = แดนลับ

## โครงสร้างสำนัก
- 宗/宗门 = สำนัก ; 殿 = ตำหนัก (ใช้ "ตำหนัก" กับ 殿 ทุกที่ในเรื่อง) ; 阁/楼 = หอ ; 峰 = ยอดเขา…
- 内门/外门 = สำนักใน/สำนักนอก ; 内门弟子 = ศิษย์สำนักใน ; 记名弟子 = ศิษย์ในนาม ; 亲传弟子 = ศิษย์สายตรง ; 杂役 = ศิษย์รับใช้
- 正道 = ฝ่ายธรรมะ ; 魔道/魔门 = ฝ่ายมาร/สำนักมาร ; 散修 = ผู้บำเพ็ญอิสระ

## ขนบของแนว
- ผู้แข็งแกร่งคือผู้ถูกต้อง ลำดับอาวุโสสำคัญมาก การไม่เคารพผู้สูงกว่าคือเรื่องใหญ่
- แนว "苟" (หลบซ่อนเอาตัวรอด): ตัวเอกระวังตัว คิดคำนวณในใจเยอะ — ความคิดในใจให้ลื่นและมีอารมณ์ขันแห้งๆ
