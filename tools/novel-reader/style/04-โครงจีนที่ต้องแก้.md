# โครงสร้างจีนที่มักหลุดมาในคำแปล → ภาษาไทยที่ควรเป็น

| โครงจีน | แปลตรงตัว (เลี่ยง) | ไทยที่เป็นธรรมชาติ |
|---|---|---|
| 不仅…还/而且… | ไม่เพียง…ยัง… (ทุกครั้ง) | นอกจาก…แล้วยัง… / ทั้ง…และ… / ไม่ใช่แค่…แต่… |
| 起着…作用 | มีบทหยวน/มีผลกระทบ… | มีบทบาท… / เป็นตัวชี้ขาด |
| 被… | ถูก… (แม้เรื่องดี) | เรื่องดี → ได้รับ/ได้ ; เปลี่ยนเป็นประธานขึ้นก่อน |
| A的B的C的D | …ที่…ที่…ที่… | แตกเป็น 2 ประโยค |
| 一边…一边… | ด้านหนึ่ง…อีกด้านหนึ่ง… | …ไปพลาง…ไปพลาง / พลาง |
| 就在这时 | ก็ในเวลานี้เอง | ทันใดนั้น / ขณะนั้นเอง |
| 不由得/忍不住 | ไม่อาจ…ได้ | อดไม่ได้ที่จะ… / เผลอ… |
| 只见 | เพียงเห็นว่า | ก็เห็น… / (ละไว้ บรรยายภาพเลย) |
| 说道/道 | กล่าวว่า (ทุกบรรทัด) | ละไว้ หรือ ว่า/บอก/ถาม/ตอบ ตามอารมณ์ |
| …诞生了 | …ได้ถือกำเนิดขึ้นแล้ว (กับคน/ตำแหน่ง/สถิติ) | …มาแล้ว / เกิดขึ้นแล้ว / …คนใหม่คือ… |
| 朝…的方向看去 | มองไปยังทิศทางของ… | มองไปทาง… / เหลือบไปทาง… |
| 映入眼帘 | สะท้อนเข้ามาในกรอบสายตา | ก็เห็น… / …ปรากฏตรงหน้า |
| 多了一个… | มี…เพิ่มขึ้นมาหนึ่ง… | จู่ๆ ก็มี…โผล่มา / มี…มาเพิ่มอีก |
| 不是没有… | ไม่ได้ไม่เคย… (ปฏิเสธซ้อน) | ก็เคย…อยู่เหมือนกัน / ใช่ว่าจะไม่เคย… |
| 那位老人/此人 | ชายชราผู้นั้น / บุคคลผู้นี้ (ฉากปัจจุบัน) | ตาแก่คนนั้น / ผู้เฒ่าคนนั้น / คนคนนี้ (ผู้นั้น ใช้ฉากย้อนยุค) |

## คำทักทาย/ประโยคชีวิตประจำวัน (ห้ามแปลตรงตัว — ใช้คำที่คนไทยพูดจริง)
| จีน | แปลตรงตัว (ห้าม) | ไทยที่พูดจริง |
|---|---|---|
| 早/早啊/早上好 | เช้า! | อรุณสวัสดิ์ / หวัดดีตอนเช้า / มาแต่เช้าเลยนะ |
| 你(们)早 (ทักตอบ) | พวกคุณเช้า | อรุณสวัสดิ์ (ครับ/ค่ะ) / หวัดดี |
| 哈喽/嗨 | — | ฮัลโหล / หวัดดี / ไง |
| 吃了吗 | กินแล้วหรือยัง (ในฐานะคำทัก) | กินข้าวหรือยัง / ไปไหนมา (เป็นคำทักเฉยๆ) |
| 辛苦了 | ลำบากแล้ว | เหนื่อยหน่อยนะ / ขอบคุณมากนะ |
| 慢走 | เดินช้าๆ | กลับดีๆ นะ |
| 眼睛一亮 | ตาเป็นประกาย (ห้วนๆ) | ตาลุกวาว / ดวงตาเป็นประกายขึ้นมาทันที |
| 听到声响，…一看 | ได้ยินเสียง หันไปมอง (วลีเรียงกัน) | พอได้ยินเสียง…ก็หันไปมอง |

## ห้ามเรียงวลีห้วนๆ ที่ขาดคำเชื่อม
ต้นฉบับจีนชอบต่อวลีด้วยจุลภาคติดกัน 3–4 ท่อน แปลออกมาต้องร้อยเป็นประโยคไทยด้วย พอ…ก็… / แล้ว / จน / ทันที
- ✗ "ได้ยินเสียงเคาะ เขาลุกขึ้น เดินไปเปิดประตู"
- ✓ "พอได้ยินเสียงเคาะ เขาก็ลุกขึ้นเดินไปเปิดประตู"
(ตัวอย่างแต่งขึ้นเอง)

## สำนวนจีน → สำนวนไทยน้ำหนักเท่ากัน (ไม่ต้องมีหมายเหตุ — สำนวนจีนที่ไม่มีคู่ไทยให้คงภาพจีน + หมายเหตุ [^n] ตามกฎหลัก)
- 惨不忍睹 = แย่จนดูไม่ได้
- 小菜一碟 = เรื่องกล้วยๆ
- 儿戏 = เรื่องเด็กเล่น
- 一箭双雕 = ยิงปืนนัดเดียวได้นกสองตัว
- 目瞪口呆 = ตาค้างอ้าปากค้าง
- 如释重负 = โล่งอกเหมือนยกภูเขาออกจากอก
- 心惊肉跳 = ใจหายใจคว่ำ
- 胡编乱造/捕风捉影 = ปั้นน้ำเป็นตัว
- 生意兴隆/财源滚滚 = ขายดีเป็นเทน้ำเทท่า
- 引狼入室 = ชักศึกเข้าบ้าน
- 屈指可数/寥寥无几 = นับนิ้วได้ / มีอยู่จำกัดจำเขี่ย
- 差点/几乎要… = …อยู่รอมร่อ / เกือบจะ…
- 冰清玉洁 = บริสุทธิ์ผุดผ่อง
- 拥挤不堪 = แออัดยัดเยียด
- 目瞪口呆/哑口无言 (หลายคนพร้อมกัน) = ตกตะลึงพูดไม่ออกไปตามๆ กัน
(เพิ่มคู่ใหม่ได้เรื่อยๆ — ไฟล์นี้ถูกส่งให้โมเดลตอนเกลาทุกครั้ง)
