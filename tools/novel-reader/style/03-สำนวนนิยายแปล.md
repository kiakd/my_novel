# สำนวนนิยายแปลไทยที่อ่านลื่น
(สรุปจากนิยายแปลที่ผู้อ่านชอบ — ตัวอย่างในไฟล์นี้แต่งขึ้นเอง)

- หนึ่งย่อหน้า = ประโยคที่จบความในตัว ไม่ค้างกลางประโยค ย่อหน้าสั้นได้แต่ต้องครบความ
- ปฏิกิริยาสั้นๆ แยกเป็นบรรทัดเดี่ยวคุมจังหวะ เช่น "ชายหนุ่มนิ่งไปครู่หนึ่ง" / "เธอหัวเราะเบาๆ"
- สลับชื่อตัวละครกับ เขา/เธอ พอๆ กัน และละสรรพนามเมื่อบริบทชัด
  "เขาเงยหน้า เขามองออกไป" → "เขาเงยหน้าขึ้นมองออกไป"
- ฉากปัจจุบัน/ตะวันตก ใช้ "เธอ" กับผู้หญิง ("นาง" ใช้ในฉากย้อนยุค/กำลังภายใน)
- 你 ในคำบรรยายที่หมายถึงคนทั่วไป → "ใคร" / "คนเรา" / ละไว้ ห้ามเป็น แก/นาย
  (ต้นฉบับแบบ "ถ้าปิดประตูดัง พี่เลี้ยงจะคิดว่า你มีปัญหากับเธอ" → "…จะคิดว่ามีใครไม่พอใจเธอ")
- บทพูดยาวที่แทรกท่าทาง ให้แยกท่าทางเป็นประโยคบรรยายก่อน/หลัง แทน "…กล่าว" ซ้ำๆ
  ลดคำว่า พูด/กล่าว — ถ้ารู้ว่าใครพูดอยู่แล้วไม่ต้องใส่
- ข้อความระบบในวงเล็บ 【】 คงวงเล็บและรูปแบบไว้
