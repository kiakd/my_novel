# สำนวนนิยายแปลไทยที่อ่านลื่น
(สรุปจากนิยายแปลที่ผู้อ่านชอบ — ตัวอย่างในไฟล์นี้แต่งขึ้นเอง)

- หนึ่งย่อหน้า = ประโยคที่จบความในตัว ไม่ค้างกลางประโยค ย่อหน้าสั้นได้แต่ต้องครบความ
- ปฏิกิริยาสั้นๆ แยกเป็นบรรทัดเดี่ยวคุมจังหวะ เช่น "ชายหนุ่มนิ่งไปครู่หนึ่ง" / "เธอหัวเราะเบาๆ"
- สลับชื่อตัวละครกับ เขา/เธอ พอๆ กัน และละสรรพนามเมื่อบริบทชัด
  "เขาเงยหน้า เขามองออกไป" → "เขาเงยหน้าขึ้นมองออกไป"
  ⚠ ละสรรพนามได้ แต่ห้ามละคำเชื่อม — ประโยคต้องยังอ่านเป็นภาษาพูดไทยที่ครบ ไม่ใช่วลีห้วนๆ เรียงกันเหมือนโน้ตย่อ
- บทพูดสั้นๆ (คำทัก คำตอบรับ คำอุทาน) ต้องเป็นคำที่คนไทยพูดจริงในสถานการณ์นั้น — ดูตารางคำทักทายในไฟล์ 04
- ฉากปัจจุบัน/ตะวันตก ใช้ "เธอ" กับผู้หญิง ("นาง" ใช้ในฉากย้อนยุค/กำลังภายใน)
- 你 ในคำบรรยายที่หมายถึงคนทั่วไป → "ใคร" / "คนเรา" / ละไว้ ห้ามเป็น แก/นาย
  (ต้นฉบับแบบ "ถ้าปิดประตูดัง พี่เลี้ยงจะคิดว่า你มีปัญหากับเธอ" → "…จะคิดว่ามีใครไม่พอใจเธอ")
- บทพูดยาวที่แทรกท่าทาง ให้แยกท่าทางเป็นประโยคบรรยายก่อน/หลัง แทน "…กล่าว" ซ้ำๆ
  ลดคำว่า พูด/กล่าว — ถ้ารู้ว่าใครพูดอยู่แล้วไม่ต้องใส่
- ข้อความระบบในวงเล็บ 【】 คงวงเล็บและรูปแบบไว้

## ความคิดในใจ (เสียงของตัวละครเอง) — ทำให้อ่านมีชีวิต
ใช้กับทุกนักแปล: สรรพนามและคำลงท้ายในความคิดให้ตามช่อง self ใน GLOSSARY ก่อนเสมอ ถ้าไม่มีจึงดูจากฉาก (ฉากปัจจุบัน ฉัน/ผม, ฉากกำลังภายใน ข้า)
- ต้นฉบับที่เป็นความคิด (心想/暗道/心道/暗忖 หรือบรรทัดความคิดลอยๆ) → เขียนเป็นเสียงในหัวของตัวละคร **บุรุษที่ 1** ไม่ใส่เครื่องหมายคำพูด
  ถ้าบริบทชัดอยู่แล้วว่าเป็นความคิดของใคร ให้ตัด "เขาคิดในใจว่า" ออกได้ แต่ต้องคงการแบ่งย่อหน้าเดิม ห้ามแยกย่อหน้าเพิ่ม
  ✗ เธอคิดในใจว่า "เขาคงไม่ได้โกหกหรอกมั้ง"
  ✓ เขาคงไม่ได้โกหกฉันหรอกมั้ง?
- ความคิดใส่คำลงท้ายแบบพูดจริงได้เต็มที่: เนี่ยนะ?, เชียวเหรอ, แฮะ, ล่ะมั้ง, สินะ, ว่าแล้วเชียว, ไม่ใช่หรือไง
  ✓ นี่มันจะบังเอิญเกินไปแล้วไหม?
  ✓ ว่าแล้วเชียว ต้องมีอะไรไม่ชอบมาพากลแน่ๆ
- คำบรรยายรอบๆ ยังเป็นบุรุษที่ 3 ตามปกติ สลับกับความคิดได้โดยไม่ต้องมีคำเกริ่น
(ตัวอย่างแต่งขึ้นเอง)

## ต่อท้ายบทพูดด้วยท่าทาง ไม่ใช่ "กล่าว"
- “…” + ชื่อ/สรรพนาม + ท่าทางหรือน้ำเสียง: “ไม่เอาหรอก” เขาส่ายหน้า / “ก็ได้” เธอยักไหล่ / “จริงเหรอ?” เด็กชายเลิกคิ้ว
- ถ้าจำเป็นต้องมีคำพูดนำ ให้ใช้ บอก/ถาม/ตอบ/เสนอ/แย้ง/พึมพำ ตามเจตนา แทน "กล่าว/พูดว่า"
- ท่าทางนำหน้าบทพูดได้: เธอยกมือขึ้นโบก “ไว้เจอกันนะ”
(ตัวอย่างแต่งขึ้นเอง)
