# น้ำเสียงและอารมณ์ — แปล "ความรู้สึก" ไม่ใช่แปลคำ
(สกัดจากการเทียบบทเดียวกัน: ร่างแข็ง → สำนวนที่ผู้อ่านชอบ ตัวอย่างจากบทที่ 1 แฟนฟิคแฮร์รี่)

**หลัก:** อ่านต้นฉบับทั้งย่อหน้าก่อน ถามตัวเองว่าตัวละคร/ผู้เล่ารู้สึกอะไร (ขำ ประชด ขมขื่น ฮึกเหิม) แล้วเขียนเหมือนนักเขียนไทยเล่าเรื่องเดียวกันให้เพื่อนฟัง คำแปลที่ "ถูกทุกคำแต่ไม่มีอารมณ์" ถือว่ายังไม่เสร็จ

## 1. ผู้เล่ามีน้ำเสียง — เลือกคำที่มีสีสันแทนคำกลางๆ (ประโยคละคำเดียวพอ ไม่ฟุ่มเฟือย)
- ✗ ลงจากตำแหน่ง → ✓ ก้าวลงจากอำนาจ
- ✗ ทำให้ช่องว่างระหว่างคนรวยกับคนจนกว้างขึ้น → ✓ ถ่างช่องว่างระหว่างคนรวยกับคนจนให้กว้างขึ้น
- ✗ ส่งผลให้การเงินตึงเครียด → ✓ เงินจึงขาดมือ
- ✗ ใช้เวลาสองเดือนกว่าจะทำได้สำเร็จ (堪堪) → ✓ ใช้เวลาสองเดือนเต็มกว่าจะฝืนทำได้แบบเฉียดฉิว
- ✗ น่าเวทนาไม่ไหว (惨不忍睹) → ✓ แย่จนดูไม่ได้
- ✗ ซื้อตามรายการขั้นต่ำสุดอย่างเคร่งครัด ถึงอย่างนั้น… → ✓ เลือกแต่เกณฑ์ต่ำสุด กระนั้นก็ยังหมดไปถึง…

## 2. คำถามของผู้เล่า / ความคิด ใช้ภาษาพูดและใส่ "?" ให้ได้ยินน้ำเสียง
- ✓ ชีนรู้เรื่องละเอียดขนาดนี้ได้ยังไง? ก็เพราะเจ้าของร่างเดิมป่วยตายไปแบบนี้เอง
- ✓ ชีนจะทำผลงานได้ยอดเยี่ยมหรือ? / ความหวังริบหรี่เต็มที
- คำลงท้ายเฉลยแบบสบายๆ: …เอง / …นี่เอง / …ล่ะก็ / …แน่

## 3. มุก/ประชด ต้องขำในภาษาไทย — สั้น กระแทก ใช้ภาษาวัยรุ่น/เกมเมอร์ไทยได้
- ✗ สีขาวขยะเลยเหรอ?! → ✓ เกรดขาวงั้นเหรอ?! ของขยะชัดๆ!
- ✗ ได้รับการเสริมจากฉายา → ✓ บัฟจากฉายา
- ✗ โชคดีที่เขามีตัวช่วย (有挂) → ✓ ยังดีที่เขามีโปร
- ถ้ามุกจีนแปลตรงแล้วไม่ขำ (เช่น 炸了都得夸它响 "ระเบิดแล้วยังต้องชมว่าดัง") ให้เปลี่ยนเป็นมุกไทยที่เจตนาเดียวกัน
  เช่น ✓ พรสวรรค์ระดับนี้ ห่วยจนต้องลุกขึ้นปรบมือให้เลยทีเดียว

## 4. บทพูด/พึมพำกับตัวเอง = ภาษาที่ปากคนพูดจริง
- ✗ ฉันต้องเร็วหน่อย → ✓ ฉันต้องเร่งมือแล้ว
- ✗ ตอนแรกเร็วหน่อย แล้วค่อยช้าลง → ✓ เร็วก่อน แล้วค่อยช้าลง ส่วนโค้งท้ายต้องกว้างกว่านี้อีกหน่อย…
- ✗ ดี ทุกคนหลับหมดแล้ว ขอแค่ระวังหน่อย ก็จะไม่ถูกจับได้ → ✓ ดีมาก หลับกันหมดแล้ว แค่ระวังหน่อยก็ไม่มีใครจับได้
- เด็กพูดกับผู้ใหญ่ให้ครบมารยาท: ✓ ผมเข้าใจแล้วครับ พี่เลี้ยงแอนนา

## 5. ประโยคฮึกเหิม/ปิดบท สั้น มีพลัง ไม่มีคำส่วนเกิน
- ✗ ไม่มีพรสวรรค์ งั้นก็ฝึกซ้ำๆ! → ✓ ไม่มีพรสวรรค์ ก็ฝึกซ้ำ!
- ✗ ให้ข้าดูขีดจำกัดของเจ้ากันหน่อย แผงวิเศษ เพิ่มความชำนาญมา! → ✓ มาดูขีดจำกัดของนายกัน แผง! เพิ่มค่าความชำนาญมาเลย!
- ✗ แสงสว่างก็วาบขึ้น รอยเปื้อน…พลันหายไปในพริบตา → ✓ ทันใดนั้นแสงก็วาบขึ้น คราบสกปรกบนโปสเตอร์จางหายไปหมด!

## 6. ข้อความระบบ 【】 ให้อ่านเหมือนหน้าจอเกมภาษาไทย
- เรียกผู้เล่นว่า "คุณ" (ห้าม "เจ้า" ในเรื่องยุคปัจจุบัน/ตะวันตก)
- ขึ้นต้นด้วยกริยาแบบ UI เกม: ✗ คาถาชำระล้างปลดล็อกแล้ว → ✓ ปลดล็อกคาถาชำระล้างแล้ว / ✗ โปรดตรวจดู → ✓ โปรดตรวจสอบ
- 进阶 = ขั้นถัดไป (ไม่ใช่ "ขั้นสูง")

## 7. จังหวะ: ร้อยวลีด้วยคำเชื่อมแบบนักเล่าเรื่อง
- …ไปพลาง …ไปพลาง / ทว่า / กระนั้น / บัดนี้ / แถม…อีกต่างหาก — ใช้พอประมาณ
- ✓ เขาพึมพำไปพลาง แกว่งไม้กายสิทธิ์ตามท่าที่เคยสำเร็จอย่างเคร่งครัดไปพลาง

## ⚠ กับดักเมื่อใส่อารมณ์ (อย่าเกินพอดี)
- ห้ามซ้อนความหมาย: ✗ สิ่งที่รอเขาอยู่ก็มีแต่ความตายจะมารับตัวไป → ✓ สิ่งที่รอเขาอยู่ก็คือความตาย
- ห้ามคำรากเดียวกันชนกัน: ✗ ห้องนอนเดี่ยวอันโดดเดี่ยว → ✓ ห้องนอนเดี่ยวที่อยู่มุมลับตาคน
- คำคู่ต้องเข้ากันแบบไทย: ✗ สายตาหนักแน่นขึ้น → ✓ แววตามุ่งมั่นขึ้น
- สรรพนามลอยต้องรู้ว่าหมายถึงอะไร: ✗ ถ้าไม่มีน้ำประปาช่วยส่ง ของนั่นสำลักตายได้ → ✓ ขนมปังนั่นแห้งจนถ้าไม่มีน้ำช่วยกลืนก็ติดคอตายได้
- คำแปลตามตัวอักษรที่ผิดความหมาย: 红茶 = ชาดำ (ไม่ใช่ชาแดง), 一颗子儿 ในฉากอังกฤษ = แม้แต่เพนนีเดียว (ไม่ใช่ "แดงเดียว")
